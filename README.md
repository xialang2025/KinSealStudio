## 使用

1. 新建或打开 `.ksp` 工程，从工具箱或“添加”菜单创建静态文本、位按钮、字按钮、指示灯、功能按钮；确定属性后在画布拖框。双击或右键属性可重开。开关家族共享四页属性，字/功能按钮的指示灯页为空，功能按钮按下效果使用隐藏状态1。
2. 系统图库包含5647张图片，目录按原生两个根、71个可见分类显示，支持PNG及KVG/SVG预览和使用；工程图库支持图片导入与内嵌。少数原资源缺少引用图片，界面会给出提示。
3. “工具 → PLC连接设置”配置连接，外部地址保存为 `@com1:4x_bit12.03` 等格式。地址族按照各协议的原生进制和分段语法校验；未恢复的族明确禁用。
4. 宏源代码在按钮属性中编辑。真实设备宏需完整ARM SDK；通过“工具 → ARM宏工具链设置”选择，或设置 `KINSEAL_ARM_SDK` 环境变量。环境变量优先，其次使用保存路径，最后检查应用目录的 `arm-sdk`。便携包不捆绑专有SDK。
5. 点击“下载工程”会先编译并验证全部段，再打开USB。数据及提交获应答后发送重启命令，最后需核对屏端显示与触控行为。右键“模拟状态”只用于编辑外观预览。
6. 普通保存使用 `.ksp`。受支持的原厂 `.sm` 可导入编辑；“文件 → 导出原厂工程”生成原厂源文件，不能把源工程和设备下载包 `.kns` 混用。

## 当前设备编译范围

- 单个800×480画面、1至8种语言、1至100个文本、位按钮、字按钮、指示灯及功能按钮。位双态ON→OFF，字按下效果OFF→ON，单态保留OFF；每种语言保存独立状态图。多语言标题及有显现条件的文本使用type28动态记录。
- 功能按钮提供18功能与全部类型；OFF→隐字OFF（可选）→隐藏ON（可选），同文时共用一套图片。原厂禁用宏，不将设备本地字符字节描述为完整Unicode。
- 字按钮支持设置常数、数值输入、密码输入、加、减、递增绕回、递减绕回，使用独立的type10 subtype1记录。输入/密码/常数只写主地址，四种算术操作加入必要的外部读取扫描。
- 置位、复位、点动、交替，位/字监视，双态与单态指示灯，两态文本闪烁，3D及透明标志，显现/触控位与等级及数值条件，按压时间，互斥的位/字通知。
- 宏使用真实SDK编译、链接并提取RAW；24字节SetLB1样本与原厂逐字节一致。运行包、变量包及宏引用在USB前校验。
- PLC设备编译目前只开放已核定的默认Modbus RTU COM1、站号1/节点1，包含对应读取扫描表。其它PLC地址可按已恢复语法编辑保存，尚未恢复的设备驱动配置会在USB前拒绝。

当前会拒绝存在透明区域的按钮覆盖下层动态按钮、动态文本与其它控件重叠的组合；图片自身Alpha也计入检查，完全不透明图片保留已有重叠能力。其它PLC配置的实际通信，以及权限、通知、宏、闪烁等运行语义的实机验收仍未完成。USB应答、源文件复开和单元测试分别记录，不互相代替。

原厂源工程支持单态/双态切换和宏源码新增、修改及名称绑定。源码改动后导出的`.sm`按原厂规则标为未编译；在原厂程序中应先对宏“全部编译”再生成设备文件。本版独立下载会使用所选SDK重新编译，不依赖原厂缓存。

```text
KinSealStudioLite.exe --project-capabilities input.ksp
KinSealStudioLite.exe --migrate-project input.ksp output.ksp
KinSealStudioLite.exe --inspect-native-source input.sm fields.json
KinSealStudioLite.exe --compile-project input.ksp output-directory
KinSealStudioLite.exe --export-native-project input.ksp output.sm
KinSealStudioLite.exe --download-project input.ksp
```
