- 语言轴：单对象，1/2/4/8种已登记语言，每种语言文本均为相同的 `AB12`；1对象1语言与对象轴共用基线。

## 2. 操作、时钟及资源采样

| 操作 | 实际入口与计时范围 |
|---|---|
| 加载校验 | `--validate-project input.ksp`：读取、模型校验、退出 |
| 加载与保存 | `--migrate-project input.ksp output.ksp`：读取、校验、QSaveFile原子保存、退出；再比较全部已提供字段 |
| 原厂源导出 | `--export-native-project input.ksp output.sm`：现有受限源编码、原子写出、退出；仅此静态文本切片 |
| 设备编译 | `--compile-project input.ksp output-directory`：现有C门禁、生成设备文件、退出；未下载 |
| 离线启动 | `--simulate-offline input.ksp empty-events.json output.json`：加载、runtime.start、零事件、最终首帧、runtime.stop、输出、退出 |

时钟为 `time.perf_counter_ns()`，Windows实现 `QueryPerformanceCounter()`，单调且不可调整，报告分辨率100ns。耗时包含CreateProcess、Qt启动、操作、退出，以及至多一次实际轮询间隔的退出检测延迟；不将它标作纯函数耗时。Windows10 19045、AMD64、8逻辑CPU、Python3.11.2，同机顺序运行3次，未清空操作系统文件缓存，系统负载未控制。运行前物理内存总量、可用量、CPU及C/Z卷容量写在manifest的 `environmentBefore`，并不是运行中空闲内存采样。

每个owned进程请求20ms轮询一次，采集当前WorkingSet、PagefileUsage、自有TEMP逻辑字节及自有命令输出树逻辑字节。r2共1201次资源采样，实际最长间隔62.8644ms，包含调度与采样开销。磁盘是采样所见的逻辑字节峰值，不能当作真实瞬时峰值或卷分配空间峰值。

`kernelPeakWorkingSetBytes/kernelPeakPagefileBytes` 使用Windows `GetProcessMemoryInfo` 中内核维护的本进程生命期峰值，区别于 `sampledWorkingSetPeakBytes`。105次内存查询均无错误。240s仅为防挂终止保护，未设性能通过秒数阈值；尚无原厂同机对照或产品可接受阈值。
