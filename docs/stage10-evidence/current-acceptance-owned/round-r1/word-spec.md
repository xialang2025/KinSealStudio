### 1.1 帮助文档中的定义 [H]

- 定义：字按钮可以对连接设备的数据寄存器进行设置常数、数值输入、密码输入、数值加、数值减、对寄存器的数值加减运算等操作。
- 操作类型七种语义（帮助正文；设备运行语义 [待验]）：
  - **设置常数**：触摸后给字地址写入所设置的常数值（例：字地址 LW10，设置常数 1024；帮助属性图 [assets/29](字按钮复刻手册.assets/29-帮助-设置常数示例.png)）。
  - **数值输入**：触摸后弹出键盘，用键盘向字地址输入数值（帮助流程图：数值输入 → 触摸按钮弹出 MIN/MAX 键盘 → 输入 1024 写入 LW10，[assets/30](字按钮复刻手册.assets/30-帮助-数值输入流程.png)）。
  - **密码输入**：与数值输入功能相同，仅输入时显示 `****` 且**没有小数位**（帮助属性图 [assets/31](字按钮复刻手册.assets/31-帮助-密码输入流程.png)）。
  - **数值加**：设置数据类型、写入地址和最大值；每次触摸在原值基础上加常数值，不超过最大值（帮助属性图 [assets/32](字按钮复刻手册.assets/32-帮助-数值加流程.png)）。
  - **数值减**：设置数据类型、写入地址和最小值；每次触摸在原值基础上减常数值，不低于最小值（帮助属性图 [assets/33](字按钮复刻手册.assets/33-帮助-数值减流程.png)）。
  - **递增绕回**：设置最大值、最小值和常数；每次触摸按常数递增，达到最大值后回到最小值重新累计（帮助例：LW0，常数 100，最小 0，最大 1000，到 1000 后回 0）。
  - **递减绕回**：同上按常数递减，达到最小值后回到最大值（帮助例：LW0，常数 100，最小 0，最大 1000，到 0 后回 1000）。
- 帮助数据类型范围表 [H]：

| 位长 | 类型 | 范围 |
|---|---|---|
| 16位 | 16位整数 | -32768 ~ 32767 |
| 16位 | 16位正整数 | 0 ~ 65535 |
| 16位 | 16位BCD码 | 0 ~ 9999 |
| 32位 | 32位整数 | -2147483648 ~ 2147483647 |
| 32位 | 32位正整数 | 0 ~ 4294967295 |
| 32位 | 32位BCD码 | 0 ~ 99999999 |
| 32位 | 32位浮点数 | -9.9e16 ~ 9.9e16 |

## 2. 控件家族与入口

字按钮属于“开关”家族。工具箱（右侧“工具栏／控件”面板，见 [assets/24](字按钮复刻手册.assets/24-V5.1-画布创建与状态栏.png) 右侧）第一、二行提供 6 个图标 [V]：

| 图标文字 | 内部对象名 [B] |
|---|---|
| 位按钮 | `btn_switch_bit` |
| 字按钮 | `btn_switch_word` |
| 指示灯 | `btn_switch_Lamp` |
| 功能按钮 | `btn_switch_Fun` |
| 画面按钮 | `btn_switch_Screen` |
| 多态按钮 | `btn_switch_Mstate` |

**六个入口共享同一个属性对话框**，只是打开时锁定的类型不同、窗口标题不同：从“字按钮”图标打开的窗口标题为**“字按钮”** [V]。“通用设置”页顶部有 6 个单选（位按钮/字按钮/画面按钮/功能按钮/多态按钮/指示灯，两行三列，容器 `RedioGroup`，对象名 `radio_bit`/`radio_word`/`radio_scene`/`radio_function`/`radio_indicator`/`radio_Mstate` [B]），实测从“字按钮”入口打开时“字按钮”单选呈选中且灰显（锁定），点击其他单选不会切换类型 [V]（[assets/01](字按钮复刻手册.assets/01-V5.1-通用设置默认.png)）。本文只展开字按钮类型；其他类型的专属字段见各自手册。

## 3. 用户的完整操作路径

### 3.1 新建控件

1. 打开工程和画面。在右侧工具箱点击“字按钮”图标（内部名 `btn_switch_word`）[V]。
2. 点击后**立即弹出标题“字按钮”的属性对话框**，初始显示“通用设置”页；对话框尺寸约 836×616（含自绘标题栏，标题栏区域属于窗口客户区）[V]。默认内容见 [assets/01](字按钮复刻手册.assets/01-V5.1-通用设置默认.png)：字地址 `LW0`、数据类型 `16位整数`、操作类型 `设置常数`、常 数 `1`，预览为 OFF 状态方形按钮。
3. 配置地址、操作类型、宏指令与四个页签。点击“确定”后对话框关闭，鼠标进入画布拖框模式（按住左键拖拽绘制）[V]。
4. 在画布上拖出矩形，松开完成控件绘制；控件默认显示 OFF 状态外观，生成后处于选中态（8 个控制点）[V]（[assets/24](字按钮复刻手册.assets/24-V5.1-画布创建与状态栏.png)，示例位置 左244.0 上112.0，宽120.0 高60.0 为本次拖框结果，非默认值）。
5. 画布矩形决定控件位置和宽高。

### 3.2 修改现有控件

- 画布上左键**双击**已存在的字按钮，重新弹出“字按钮”对话框并回填已有值（实测把“常 数”改为 999 → 确定 → 双击重开，回填 999）[V]（[assets/25](字按钮复刻手册.assets/25-V5.1-双击重开回填999.png)）。
- 画布右键菜单首项“属性”也可打开同一对话框；菜单结构与位按钮/静态文本一致：属性／控件(K)▶／剪切 Ctrl+X／复制 Ctrl+C／多重复制 Ctrl+P／粘贴 Ctrl+V／删除 Del／全选 Ctrl+A／对齐▶／层次▶／组合▶／图像比例▶／网格／模拟状态▶ [V]（[assets/27](字按钮复刻手册.assets/27-V5.1-画布右键菜单.png)）。

### 3.3 对话框公共部分

窗口标题“字按钮”；左上四个页签：**通用设置／指示灯设置／外观设置／权限设置** [V]；右侧独立“预览”框（白色底，内嵌按钮外观区，显示当前“选择状态”的外形与文字）[V]；右下“确定／取消／帮助”三按钮（容器 `buttonBox`）[B][V]。

- **确定**：新建时进入画布拖框阶段；编辑时提交修改并关闭 [V]。
- **取消**：编辑状态下放弃本次改动。实测：双击打开已有控件 → 看到“常 数”为 999 → “取消” → 再次双击，999 保留（取消只丢弃**本次**改动，上一次确定已入库）[V]（[assets/26](字按钮复刻手册.assets/26-V5.1-取消后重开保持999.png)）。
- **帮助**：按钮存在 [V]；原厂 CHM 有对应页面（`Switch/字按钮.html` 与 `Switch/functionnodes/bytebutton.htm`）[H]；点击后是否直达该页未实测 [待验]。
- **预览**：状态 0 显示 OFF 灰面按钮；“选择状态”切到 1（需先勾选“按下效果”，见 §6）时显示橙色 ON 按钮 [V]（[assets/38](字按钮复刻手册.assets/38-V5.1-外观-状态1按下外观.png)）。

## 9. 复刻实现的数据与交互约束

每个字按钮对象至少应保存以下独立状态：

```text

      字地址（默认 LW0）；数据类型（七项，默认16位整数）；

        设置常数: 常数(1)
        数值输入: 最小值/最大值/总位数(5)/小数位(0)（随数据类型重置默认）

        数值加:   常数/最大值
        数值减:   常数/最小值
        递增绕回: 常数/最小值/最大值
        递减绕回: 常数/最小值/最大值
      宏指令开关；宏索引
```

## 10. 必须执行的验收矩阵

1. 工具箱六个开关图标分别打开标题为对应类型名的同一对话框；“字按钮”入口的单选锁定行为一致；默认值（LW0／16位整数／设置常数／常数1／状态0 OFF／switch_OFF.kvg／透明度255／按压时间255）与本手册一致。
2. 操作类型下拉七项及顺序（设置常数/数值输入/密码输入/数值加/数值减/递增绕回/递减绕回）与 §4.3 字段显隐矩阵；数据类型下拉七项及顺序（16位正整数/32位正整数/16位整数/32位整数/16位BCD码/32位BCD码/32位浮点数）与默认值重置表；密码输入无小数位。
