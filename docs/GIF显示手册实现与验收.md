## 字段及事件映射

| F／EV／AC组 | 原生字段／事件 | 实现与边界 |
|---|---|---|
| F-C10-GIF、EV-C10-GALLERY | 工程图库唯一选图、添加／批量添加／删除、确认／取消 | 独立原始GIF池；子事务确认才回填，关闭父属性或取消放置均不提交资源。Lite以文件名及内容哈希生成本地键，未恢复原厂内部ID／独立描述。 |
| F-C10-PLAY、EV-C10-RUN | 运行测试／停止运行 | QBuffer＋QMovie实际试播，暂停保留当前帧，继续恢复播放；运行状态不写KSP。 |
| F-C10-BIT | 受位控制、控制位、有效状态 | 默认关闭／LB0／1；逐级启用，禁用后保留草稿；仅验证启用地址的Bit角色。 |
| F-C10-VIS | 单列显现及位／等级／字控制 | 使用现有权限编辑器，等级1..8，5种字类型及6种比较符；禁用值完整保存。等于／不等于误差UI复用现有组件，未据此宣称GIF原厂专属补证或设备组合语义。 |
| EV-C10-PLACE、EV-C10-EDIT | 属性确认→拖框，双击回填，确定／取消 | 一个项目事务；图库与对象一起进入撤销／重做；无图确定继续保持窗口打开。 |
| AC-C10-PC、AC-C10-KSP | 画布／试播／保存重开／混合工程 | 画布默认首帧、拉伸并裁切；schema12严格原始字节保存；10类混合工程重开与原始字节比较通过。 |

新增`GifDisplayProperties`保留动画键、原始字节、独立播放位与完整显现属性。`HmiProject.animations`与PNG-only `pictures`分离；闲置动画池亦使用schema12。低版本标记不得携带GIF属性或动画池，未知／缺失字段、非法类型、非规范Base64、损坏帧均拒绝，失败不改输出。

本地资源保护上限：单GIF 1 MiB、最大4096×4096、512帧、累计解码64 MiB、资源池256项／32 MiB。它们是Lite限制；原厂1M提示仅有静态证据，未把这些边界宣称为原厂实测。

资源API覆盖活动／非活动页、显式animation引用、同名不同字节的分离、重命名／替换／删除保护及跨工程复制。按名称及原始字节识别绑定；图片池不接收GIF扁平化。窗口的实际排版已人工对照截图，未宣称逐像素相同；原厂帮助按钮行为未恢复。
