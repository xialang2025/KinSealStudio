## 2026-11-27　V122 原厂表格源读写

Lite 现在可以打开、新建和修改源类型 36 的纯图像表格。修改行列、边线、填色和位置后，导出器同时更新属性和画布用的矩形及线段缓存。静态表格可与已有源控件一起保存在 SM 中。原厂含动态行列地址、未映射的触控/显现/通知条件、缓存与属性矛盾的表格会返回具体原因。[实现](../src/native_table_source.cpp.inc) · [源格式第 4.7 节](文件规则/SM源工程格式规范.md#sm-table)

| 私有区相对偏移 | Qt4 字段及可编辑范围 |
| --- | --- |
| +0、+2 | 两个大端有符号 16 位整数，分别为行数、列数，各 1～30 |
| +4、+5、+6 | 依序为轮廓线、内部水平线、内部垂直线的开关。仅开启轮廓时仍只有一个矩形缓存 |
| +7、+18、+29 | 依序为背景、轮廓线和内部网格线的 QColor，每个占 11 字节。安装原件对话框将边框、线色按钮保存在 UI 成员 +0x50、+0x60，确认路径分别写入表格成员 +0x140、+0x150，源写入器 0x84CFCC 以此顺序输出 |
| +40、+42 | 两个大端有符号 16 位整数，分别为内部线型、底色 Alpha。修改底色 Alpha 同步更新矩形缓存的画刷颜色，轮廓及内部线保持不透明 |
| +44 起 | 行地址开关及变长地址，随后是列地址开关及变长地址。静态样本的开关为 0，休眠地址原字节保留 |

缓存第一个子图元恒为 `0x1000F` 矩形，之后依次为水平线 `HLine1…`、垂直线 `VLine1…`，两者均使用 `0x10011`。按独立开关生成行数减一／列数减一条内部线。顶点以矩形局部坐标和双精度间距保存，场景平移单独保存。原厂 200×100、三行两列的水平线纵坐标分别为 33.333333333333336 和 66.66666666666667，垂直线横坐标为 100。外框始终使用矩形的线型字段，内部线型可以独立设为透明。
