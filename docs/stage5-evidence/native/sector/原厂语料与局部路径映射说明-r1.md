# 固定角度扇形：原厂语料与独立全帧差分（2026-11-14）

本批 27 份正式原厂编译全部与独立候选的完整 768000 字节 RGB565 帧相等，包含 15 个 canonical、13 个独立场景。生产接入、产品回归与最终 gate 验收由主任务继续执行。本批没有操作 USB 传输，也未修改生产代码、测试或 Git。

## 源与实际进程

输入是阶段4保留的 `sector-default.sm`，SHA 为 `b2dc8286626c78b72c93bafb7d4556551a5aa4ccf5518c1a5571191320f7e274`。先只读 scene-read 确认源只有唯一 root，bbox 为 `[100,100,200,200]`，没有旧文本污染，因此没有执行删除或伪造隔离源。

实际启动 29 个自有原厂 helper：27 个正式有效编译、1 个只读源检查，以及 1 个实际编译成功但绑定未通过的 odd-r1。所有 helper 均正常返回并完成自有进程清理，`ownedProcessTerminated=true`；既有 helper 的 finally 使用自有进程终止清理，这不代表原厂应用自然退出。

正式索引为 `valid-target-index-r1.json`，源/原厂段重新校验结果见 `corpus-audit-r1.json`。每份分别保留原输入 SHA 与真实 `input-native.sm` 编译输入 SHA，不忽略原厂确认/保存后的源规范化变化。

## 局部路径和变换的真实语义

原厂扇形采用局部 8 元素路径，不能按椭圆的单位矩阵假设处理。默认 item 与 painter 的真实矩阵均为 `[1,0,0,1,100,100,0,0,1]`，即局部路径后应用整数场景平移。首次默认真实编译发现该事实后停止批次，明确采用已观测的平移契约后才继续；没有改写原始观测冒称单位矩阵。

每项有效目标同时保留：

- 实际 itemTransform、painterTransform、原始局部 pathstream 及 SHA；
- 局部 8 元素、显式映射后的 scene 8 元素与独立 scene pathstream SHA；
- 实际原始 sceneBoundingRect 与相对整数框的差值；
- 独立 Qt6 的局部构造、整数平移、真实 26.6 元素比较结果。

只接纳线性部分为单位矩阵且 tx/ty 精确等于整数 bbox x/y 的平移；任何其它矩阵仍拒绝。独立路径从局部 rect `(0,0,w,h)` 开始，`moveTo(center)` 后 `arcTo(45,90)`，再用整数 `QTransform.map` 映射到 scene。路径类型序列严格为 `0,1,2,3,3,2,3,3`，保留隐式填充闭合；没有增加第9个描边闭合元素。

原厂实际 painter 为 QPixmap 800×480、hints=3、黑色 pen、width=0、SquareCap=16、BevelJoin=64；pen style 按每个 0/1 状态核对。线填状态从原厂 `m_LineType`、`m_Pattern` 属性框读回，确认后先保存再编译，以免“编译之前要保存当前工程”模态阻断。

## odd-r1 绑定失败与 r2 重采

`sector-odd-create-r1` 的原厂创建、保存、编译均成功，但属性确认后 Qt 的 sceneBoundingRect 报告宽高 `200.99999999999997`，先前脚本用浮点精确相等比较 201，故绑定失败。该轮 raw、源、编译段及失败进度清单完整保留，没有计入正式 27 份。

后续明确限定 scene bbox 归一到整数框的误差上限为 `1e-8`，并逐项保留 raw bbox/差值，使用全新 `sector-odd-create-r2` 与 `sector-odd-reopen-r2` 重采。该容差仅用于 Qt 场景 bbox 的浮点回算，不用于原厂像素、源 SHA、变换、26.6 路径元素或 RGB565 全帧比较。

## B/S/M 和复现依据

`B-S-M-sector-cell-area-r1.json` 中 B 保留原厂文件大小与 SHA，S 对27份均验证 PicLen=2400、无 ControlPara/ControlPixel、动态图像字节/数量及 SheetControlCount 为0。M 从独立 Qt6 路径/曲线展开输出，在 256 子像素格点用独立 Python 面积积分重算 mask；没有再次降到26.6。重算结果与独立 C++ mask 全部相等。

候选先按对象顺序在 RGB32 中白填再黑边，每项使用 `D(v)=(v+(v>>8)+128)>>8`，源/背景贡献分别修正后相加，最终只量化一次 RGB565。完整帧与每份原厂 LZO 解码结果逐像素比较，27/27 均为0差。源码中的历史曲线交叉项、叶中点与已有定点细分规则保持不变。

三次同源新进程逐原厂文件的不稳定区全部列在 B/S/M 的 `B_repeatDifferences`，一律保留 `unknown_no_ignore_mask`，没有忽略字节区或像素补丁。

采样/优先比较/正式分析配方、场景 JSON 和日志的精确副本在 `source-driver/`。独立 CLI 输出和完整路径等 gzip 回解核验后保留在 `independent-paths-r1/`，分析中间文件回执见 `independent-temp-cleanup-r1.json`。完整原厂 raw、源、段与 native runtime 的最终归档/清理由主任务统一执行。
