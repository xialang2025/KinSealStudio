# 共用 Frida 展开副本清理（2026-11-14）

清理范围是当前任务 `temp` 下名称严格匹配 `frida-[32位十六进制]` 的143个自有展开目录。本项是多批调查共用的临时工具清理，单独记账，不并入扇形856个原厂 runtime 文件的清理数字。

实际删除1716个文件（1287个DLL、429个EXE），共7865664664逻辑字节，并用非递归空目录删除移除572个目录。全部143个目标目录已不存在；占用或其它跳过项为0。其它临时项 `qgrayraster.o` 保留，C盘、原厂安装、增量构建和用户目录未作为删除目标。

逐文件完整SHA核对后，1716个文件只有9种唯一字节序列，共55004648字节；每种唯一字节保留一份确定性gzip于 `unique-bytes/`，压缩合计23159772字节。所有gzip均回解核对SHA，删除前原生PowerShell再执行全部文件/归档/路径/活跃进程preflight，随后按明确白名单逐个 `Remove-Item -LiteralPath` 删除。没有跨shell拼接删除命令，也没有递归删除目录。

本归档用于诊断工具重现，不是产品runtime依赖。安装包身份为Frida17.6.2；安装 `_frida.pyd` 的118009344字节SHA为 `b6ebfdfa62c29dbbab1e8f2647dfed75edd90761d31585dacaff4a22735ffcf2`，与wheel RECORD一致。安装文件只读，保留身份与既有METADATA、RECORD、WHEEL、licenses/COPYING、frida/__init__.py原始字节/文件头及逐项SHA，见 `installation-metadata/` 和 `cleanup-plan.json`。
