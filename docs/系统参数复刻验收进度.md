# 系统参数复刻验收进度

按取证目录的 01 至 06 顺序验收。共 28 个编号节点，地址输入在第 01 章另行核对。各章存在历史实现，仍需按本轮原厂取证逐项复验。

## 01 工程树与连接

| 取证编号 | 已验证 | 待验证 |
| --- | --- | --- |
| 1 设置 | 工作流回归核对系统树定位 | 折叠、滚动和选择恢复 |
| 2 连接设置 | 只有 COM2 配置的 KSP 重开后，COM1 为空，COM2 显示 Modbus_RTU | 切换机型后的端口和驱动目录、原厂源中的实际协议回读 |
| 3 COM1 | 可从工程树打开串口窗口，回读 COM1 默认值，COM2 的修改保持独立 | 同原厂逐字段对比保存、确认帮助入口和实际 PC 会话选择 |
| 4 Modbus_RTU | 独立「协议」窗口，COM2 改名和超时变更可取消或保存重开，COM1 保持原值。被引用协议拒绝删除，可删除同端口未引用实例 | 原厂协议实例和自定义参数完整导入导出，各驱动分支与恢复默认对照 |
| 5 COM2 | 空端口可打开。19200 波特率和 PC COM11 取消不生效，确认后可保存重开，恢复默认回到 9600 和 PC COM2。新增默认 Mitsubishi_Fx3U／站号 0，原 Modbus_RTU 保留，两者重开后各有独立 ID | 原厂串口导入导出、台架通信、多驱动设备编译 |
| 地址输入 | 四行键盘可录入、清除、后退、确认和离开，27 项 Windows 回归通过 | 原厂 RWI、0–65535 范围、不同调用方与实物设备编码 |

串口覆盖写入 KSP。原厂串口头需要逐字段保存差分，其中 COM1／COM2 基线的 `.1` 和 `.3` 共变，现有样本无法区分设备口和 PC 在线模拟口的槽位。校验、数据位、停止位及 422 编码也缺直接差分。确认非默认配置后，设备编译与源导出在前置检查中停止。涉及串口的实物结果待台架验收。
