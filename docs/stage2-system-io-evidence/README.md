# HMI 状态和 PLC 控制原厂差分

2026-11-23 使用原厂 V5.1 和 AMT070W124-L800X480R 单画面工程，在私有 Windows 桌面保存两个首行的单项变体。地址通过原厂地址输入窗口选择。分别重开 HMI 状态和 PLC 控制后，当前画面序号回读 LW321，控制画面切换回读 LW789。程序及私有副本校验值、所有源文件字段差分和编译文件校验值见 [原始差分记录](amt070-system-io-data.json)。

## 原厂源文件

| 操作 | 源文件字段变化 |
| --- | --- |
| HMI「当前画面序号」开启 | `config.13c.0` 从 0 变为 1 |
| HMI「当前画面序号」选 LW321 | `config.140.0` 字符串从 LW0 变为 LW321，`.3` 从 0 变为 100，`.4` 数字字符串从 0 变为 321 |
| HMI「当前画面序号」关闭 | `config.13c.0` 从 1 变为 0，保留 LW321 的地址记录 |
| PLC「控制画面切换」开启 | `config.188.0`、`config.18c.2` 和 `config.18c.6` 均从 0 变为 1 |
| PLC「控制画面切换」选 LW789 | `config.18c.0` 字符串从 LW0 变为 LW789，`.3` 从 0 变为 100，`.4` 数字字符串从 0 变为 789 |

六份实际保存的 `.sm` 均经结构读取至文件末尾。每组除表中列出的字段外，其余字段字节相同。

## 原厂离线编译

六种条件各重复两次。原厂「离线模拟」入口重新写出 4998 字节的 `SysPara.dat`，编译日志显示成功。私有目录没有模拟程序，编译后未启动模拟子进程。取证没有使用下载入口、USB 或 PLC。

| 单项变化 | 样本中随操作稳定改变的 `SysPara.dat` 字节 |
| --- | --- |
| HMI「当前画面序号」开启，地址 LW0 | 偏移 352 从 `00` 变为 `01` |
| HMI 地址由 LW0 设为 LW321 | 偏移 358 从 `00` 变为 `64`，偏移 364–365 从 `00 00` 变为 `41 01` |
| PLC「控制画面切换」开启，地址 LW0 | 偏移 752 从 `00` 变为 `01`。偏移 757 同时从 `5F` 变为 `57`，该字节的含义待确认 |
| PLC 地址由 LW0 设为 LW789 | 偏移 758 从 `00` 变为 `64`，偏移 764–765 从 `00 00` 变为 `15 03` |

观察到的两字节值与 321、789 的小端编码一致。完整字段位宽和运行时解释仍需核对。两组 `AddrPara.dat` 和画面段在比较中逐字节相同。部分系统段和报警段字节随重复编译波动，完整比较表保留在 JSON 中。条件内两次相同的字节也可能随编译次序变化，未直接归因给相关选项。

这里验证了 AMT070W124-L800X480R 的两个内部字地址首行。其余行、外部 PLC、AMZ070W01、实际状态输出、PLC 控制行为，以及 Lite 写回、编译和实屏验收仍待验证。
