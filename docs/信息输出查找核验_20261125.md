# 信息输出窗口的查找与定位依据

对象为 V5.1 标准版原厂可执行文件 `KinSealStudio5.1.exe`，SHA-256 为 `305592b4e4bc1b15a707c7bc832c31f27ca0958b97f9c79a5b50ac6df49e907c`。以下为该文件首选虚拟地址上的静态分派和 Qt 调用记录。

| 路径 | 原厂行为 |
| --- | --- |
| 宏查找 `0x481C08` | 查询对话框返回 Accepted 才清表，取消保留旧结果。`0x481E29` 勾选视图动作，`0x481E57` 设置单列。`0x481F7B` 调用使用位置查询。按顺序写入查询说明、命中项和计数。无命中使用“没有找到对应的脚本 !”。 |
| 宏扫描 `0x47F304` | 代码查询场景里的控件宏名，可见名称比较与“任意”条件。全局、初始化宏列表按序形成“第…个全局宏”和“第…个初始化宏”。使用位置通过 QStringList 传递。此路径未见向主窗双击表登记定位记录。 |
| 地址查找替换 `0x4A5008` | `0x4A56A0` 对话框确认后，`0x4A62F3` 重置行到图元的映射，`0x4A654F` 清表。新结果有“正在查找”“位置”“替换”、零命中及末行统计。`0x4A6C71` 在表中插行，`0x4A6D45` 以后为命中的图元写入当前输出行和图元、画面信息。 |
| 双击 `0x4470FC` | 单元格存在时，以行号查找关联记录。存在图元且目标页有效时，`0x4472D6` 设置场景、`0x447316` 清空原选择、`0x44732C` 选中目标。其他行刷新当前场景和窗口标题。 |

Lite「宏查找」的查询按钮查实际调用。全范围含全局和初始化计划，当前画面和选中控件范围仅查该范围内的对象。调用检查复用模型的 `macroBindable`，读取位按钮、字按钮的共用字段以及滑动开关、下拉框的独立字段和活动开关。画面、灯、功能、数值等对象的休眠宏名可在原有查找对话框中查看。普通源码定义或某行代码含相同字符不会增加使用次数。双击信息窗内的宏结果、起始和汇总行保留当前对象。原有查找对话框的「定位」支持源码定位。[调用索引与查询](../src/stage2_global_tools.cpp) · [模型绑定范围](../src/macro_workspace.cpp)

Lite「地址查找替换」增加独立的「查找」。只填写查询地址即可得到零个或多个结果，复用地址替换的字段范围、连接目录和地址等价判断。「预览」后确定替换，成功提交工程后向信息窗发布旧值、新值和命中数量。查找、替换中的控件行可双击切到画面并选中对应控件。配置行及汇总行只显示文字。查询或替换对话框取消保留已有输出。[主窗口接线](../src/main_window_workflow.cpp)

原厂地址对话框还含“文本内容”“没有找到文本”等分支。本次核验了地址查找替换及其信息输出。跨语言文本替换仍待独立验证。
