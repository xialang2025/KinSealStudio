2026-11-25，北京时间。按 90 项阶段主任务和 41 类控件与图形对照原厂资料、源代码与现有验收范围。新修复项逐项执行对应回归。

本机原厂 V5.1 x86 PE 的 SHA-256 为 305592b4e4bc1b15a707c7bc832c31f27ca0958b97f9c79a5b50ac6df49e907c，中文 CHM 为 f87f031d82b199d8c66de7240ee07e1553f136358ea842e5c34e0f10e80171a1。REA 识别同一 x86 PE。采用可追溯的原厂动作槽、帮助、截图、保存样本、编译包与现场回执。桌面功能、源互通、设备编译、实际传输和屏幕交互分别判定。 [原厂取证](系统参数功能与界面取证/) · [历史任务全量台账](../design_plan/未完成任务总台账.md) · [本轮未闭合清单](V5.1功能未闭合清单_20261125.md)

## 已修复差异

| 功能 | 原厂依据和本轮实现 |
| --- | --- |
| 标准/画面工具栏 | 原厂 action_36 和 action_37 分别作用于 standardToolBar 和 mapToolBar，槽入口 0x4079A0、0x407938。Lite 的视图命令、右键菜单和可见状态联动。 |
| 平移 | 原厂 0x4081E0 切换橡皮筋选择与手形拖动。Lite 平移时走视图滚动，返回选择工具后恢复原有编辑。 |
| 反选 | 原厂 0x40D854 暂时排除已选对象，再按页面矩形重新选择。Lite 核验空选、全选和锁定对象的选择关系。 |
| 三个报警入口 | 原厂添加菜单 action_waring、action_conalarm 分别进入位与条件报警。父节点新增报警登录在 0x4271AE 接 tree_digitAlarm()。Lite 直接复用报警属性、帮助、取消与提交事务。 |
| 单普通页 SM 页号 | 原厂单页的 page.head.19 为 000，三页夹具第三页为 009，页尾仍按集合索引编码。以原厂单页样本的末位单字节变体核对导入、KSP、逐字节源写回和设备守卫。 |
| 离线只读数值 | 原厂中文 CHM 离线示例包含数值监视和输入。Lite 增加已支持读值类型的本地 LW 只读路径，实测由字按钮触发读数帧变化。 [原厂离线模拟档案](系统参数功能与界面取证/离线模拟截图/) |
| 模拟权限 | AMT/AMZ 原厂实验对照支持启用条件取交集、空条件放行。Lite 补位、字、等级权限和比较容差。受控回调检查读值失效、异常空响应及捕获取消。 [原厂按钮规格](<控件功能逻辑--固件/按钮/按钮控件功能逻辑与复写规格.md>) |
| 图表属性圆弧 | 原厂图 15/16 显示圆弧模式隐藏圆环透明度，默认 0°/360° 属性预览为空。Lite 同步这两项行为并保留环形草稿。 [原厂图表截图](../design_plan/图表复刻手册.assets/) |
| 时间属性预览 | 原厂 Qt 观察记录中，仅显示时间的 HH-MM-SS 含前导空格。Lite 复现该格式，日期混排和全禁用仍经回归。 |
| Windows 并行构建 | 从实测 DLL 占用恢复 Qt 增量部署，给共享工作流测试补齐图库对象资源。 |

## 实际验证

原厂单页编号用实时 CLI 验证。旧版能读单字节变体但省略了页号。新版将 009 保留为 KSP 整数 9，导回的 SM 与输入逐字节一致，能力报告给出源导出候选和设备拒绝。归档原厂多页夹具仍通过结构读取和完整字节恢复。

控件回归在私有测试目录内读入 Git 保留的原厂夹具。应用在没有开发工具路径的 Windows 环境启动，本地帮助校验 155 个命令，AMZ 静态样例编译及验包成功，10 个设备段与上版 Lite 逐字节一致。真实触摸屏和实际 PLC 的已验范围沿用历史回执，本轮只增加 PC、SM 与离线验包证据。

本机程序位于 `build/amz070w01r/KinSealStudioLite.exe`，SHA-256 为 `a9c887259a013355b3054a93d53b19f86a3a770f96da5ec4843294fa464a94c3`。构建使用当前工作区，含已有本地代码。提交只包含本轮修改及报告。
