# 文件菜单「辅助功能」核验

## 原厂界面与行为

核验对象为 V5.1 标准版 `Installed/KinSealStudio5.1.exe`，SHA-256 为 `305592b4e4bc1b15a707c7bc832c31f27ca0958b97f9c79a5b50ac6df49e907c`。下列地址为该 PE 文件的首选虚拟地址。菜单取自[原厂菜单快照](main-window-evidence/native-shell.json)。本次窗口和行为证据来自原厂程序的静态代码、Qt 元对象和安装自带的 `language.ini`。当前普通 Windows 访问令牌直接启动该 EXE 返回 740，原厂窗口的运行截图和逐像素比对仍待有合适权限的桌面会话复核。

| 原厂入口或函数 | 可复核的结果 |
| --- | --- |
| `action_Auxi` → `on_openAuxiDlg()`，`0x4095E4` | 打开模态 `ProjectSetDlg`。点取消结束对话框。点确定且保存成功后，外层根据自动保存勾选状态停止或重新启动计时器。 |
| 构造 `0xB59AB4`、UI 初始化 `0xCEE1C8` | 设计尺寸为 428 × 466，单页「自动保存设置」。上方是启用自动保存及分钟数，下方是可勾选的「启用自动备份工程」，包括两种备份方式、原组态或自定义路径、浏览目录、命名示例、备份数量和蓝色覆盖提示。 |
| `0xCEEF4B`、`0xCEF432`、安装版 `language.ini` | 自动保存间隔 3–60 分钟，默认 3。备份数量 3–20 份，默认 5。两项开关初始关闭，初始方式为点击保存，默认使用原组态目录。 |
| 自动保存开关 `0xB571B4`、目录切换 `0xB599F4`、浏览 `0xB58C18` | 点击自动保存使“点击保存时备份”重新选中，并根据勾选状态启用“跟随自动保存时间备份”。点击自定义目录启用浏览。目录选择器取消时保留已有文本。 |
| 确认 `0xB58EF8` | 自动保存或自动备份选中时，弹出“不建议使用该功能，是否取消设置”。该问题的「确定」清除两个开关并继续提交，「否」保留用户所选。启用备份且使用不存在的自定义目录会再次提示并保留对话框。 |
| 全局保存 `0xB591E2`–`0xB59491` | 写入 `display/bAutoSave`、`display/AutoSaveTime`、`autoSaveProInfo/IsBakup`、`BakupMode`、`BakupPath`、`BakupTotals`、`BakupFilePath` 共七个键。后五个键均在 `autoSaveProInfo` 组中。 |
| 定时和备份 `0x4752D1`、`0x4B75A4`、`0x4B44EE`、`0x4B1E64` | 超时连接到 `createsavedlg()`。成功写入工程后，检查“启用自动备份”并复制刚保存的工程。按完整工程名生成 `工程-bak1.sm` 等编号文件，选第一个空号，数量达到上限时使用最早修改的备份位置。 |

原厂备份方式有一个容易误判的行为。Qt 元对象分派 `0xC57EFF` 将 `onChangedBackupMode(int)` 交给 `0xB57198`，该槽直接返回。模式值会持久化并在重开时回显。已核到的主窗手动保存和定时保存共用同一写入入口，写入成功后的备份条件读取 `IsBakup`。Lite 保留两个单选项及这一共同触发条件。

## Lite 的持久化和文件规则

- 设置属于电脑上的编辑器用户。Lite 在现有的 `KinSealStudioLite/Editor` 用户设置中持久化同名七个键。取消保留原设置和运行中的定时器。接受后新间隔立即生效。
- 已有路径且有已提交修改的 `.ksp` 工程在定时到期时走与菜单保存相同的工程写入流程。未命名工程保留待存编辑，下一次手动保存选择路径。模态编辑、画布拖动或待放置控件、正在下载期间，定时器等待下一个周期。
- 点击保存和另存为会备份成功写入的 `.ksp`。显式导出原厂源工程成功会备份输出的 `.sm`。副本扩展名跟随实际文件，例如 `生产线.v2-bak1.ksp` 或 `生产线.v2-bak1.sm`。Lite 打开原厂工程后的常规保存仍沿用现有另存为工作流。
- 使用原工程路径时，每次保存都根据目标文件解析目录，可覆盖「另存为」切换工程目录的情况。自定义路径在确认时和实际备份时均检查有效性。
- 数量限制仅对当前完整基础文件名、扩展名和正整数编号匹配的常规文件生效。符号链接、其他工程、名称相似的附注文件独立保留。备份通过同目录锁和原子文件替换写入，完成写入后才清理因调小数量而多出的旧份数。主工程与备份独立报告结果。备份路径被移动或变为不可写时，刚保存的主工程仍保持可读。
- 这是桌面文件保存功能。启用或更改这些设置不会改变下位机编译段、HMI 运行参数或 USB 下载内容。

实现见 [辅助功能](../src/auxiliary_settings.cpp)、[主窗口保存和定时器](../src/main_window.cpp)、[菜单接线](../src/native_shell_ui.cpp)。

## 验证范围

独立 Qt 6.12 离屏实跑已核对默认值，取消后重开，勾选后的两种二次确认回答，自定义路径无效时继续编辑，以及修正目录后的持久化。对同名工程连续生成六份不同字节，设置上限三份后恰好保留最后三份内容。相似名称的附注文件仍可逐字节读回。

菜单集成用例 `auxiliarySaveBackupsThroughMenu` 从 `action_Auxi` 打开实际对话框，使用正常保存动作和缩短到 10 毫秒的 Qt 定时器事件驱动写入，重开保存文件、备份及独立编辑器实例。用例还覆盖显式导出 `.sm` 后源与副本字节相同、自定义目录移走后的主工程持久化和无文件名的待存编辑。Qt 6.12 离屏运行通过，含初始化和清理共 3 项通过、0 失败。测试源码见 [工程工作流回归](../tests/stage2_workflow_tests.cpp)。
