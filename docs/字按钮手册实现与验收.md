# 字按钮手册实现与验收

本轮依据[字按钮功能与交互复刻手册](../design_plan/字按钮功能与交互复刻手册.md)，为目标屏 AMT070W124-L800X480R 扩展字按钮。修改标记为 `//20261109-6`。本文件随最终验证结果更新；界面、源工程、设备编译、USB传输和现场触控分别记录。

## 编辑与保存

字按钮沿用开关家族，新增独立字操作记录，复用位按钮的外观、显现、触控、通知、按压时间、图库、宏与画布编辑。两个控件的操作索引独立保存，不互相解释。

- 添加菜单、画面工具栏和工具箱均提供“字按钮”；确定属性后在画布拖框创建，双击或右键属性重新编辑。
- 七个数据类型依次为 U16、U32、I16、I32、BCD16、BCD32、FLOAT，默认 I16、LW0、设置常数1。
- 七个操作依次为设置常数、数值输入、密码输入、数值加、数值减、递增绕回、递减绕回。切换数据类型或操作后使用手册实测默认值；数字输入与密码输入按手册分别显隐小数位。
- 指示灯页为空，不启用位按钮的指示灯和双态监视。常态和按下态草稿独立保留，按下效果关闭时只用常态；开启后可编辑状态1，状态1不开放两项复制。
- 选择通知字时取消并禁用通知位；位按钮原有通知交互保持原样。权限复用五种数值类型、六个比较符及误差配置。
- `.ksp` 中出现字按钮即写入 schema6；旧版编辑器会拒绝此版本，避免静默丢失字操作。剪切、复制、撤销、重做保留全部属性。
- 32位主地址占两个字，地址拾取、属性确认和设备编译均检查完整跨度。LW4095为本版32位内部地址的最后合法起点，LW4096仍适用于16位。

本版编辑保护为总位数1..10、小数位0..9且数字输入的小数位须小于总位数。整数/BCD/浮点的可表示范围依据手册帮助表设置；这些保护不应被解释为原厂全部可编辑上限已实测。

本版后台Windows界面：[通用设置](../artifacts/word-button/general-default.png)、[常态外观](../artifacts/word-button/appearance-state0.png)、[按下态外观](../artifacts/word-button/appearance-state1.png)、[通知字权限](../artifacts/word-button/permission-word-notice.png)。这些截图在独立Windows桌面生成，未激活用户桌面。

## 源工程与设备记录

Qt源工程中，字按钮使用 type10 的 subtype1，与640字节设备记录不是同一种格式。新工程使用独立的原厂字按钮源种子；既有源的未修改元数据保存在快照。源工程的单态列表无法完整保存未使用的另一态编辑草稿，需用 `.ksp` 保留。

设备记录已定位的字专有字段：

| 偏移 | 类型 | 内容 |
| --- | --- | --- |
| 0x103 | u8 | 按下效果 |
| 0x106 | u16 | 开关子类型1 |
| 0x110 / 0x114 | u32 | 总位数 / 小数位 |
| 0x118 / 0x11c | u32 | 操作 / 数据类型 |
| 0x120 / 0x128 / 0x130 | f64 | 常数 / 最小值 / 最大值 |
| 0x138 | 36B | 字操作主地址 |

上述设备数值为小端；原厂源工程则使用大端Qt typed流。设置常数、数值输入和密码输入只写主地址；四种算术操作读取当前值。U32/I32/BCD32/FLOAT传输两个字，其余传输一个字。

未开放的隐藏标志和额外地址不能从非零残留字节推断为启用功能。原厂构造存在未初始化字段；本版设备编译将无效区域规范置零，比较时区分活动字段与残留字节。

## 本轮验证记录

- 字按钮窗口独立离屏测试：57通过、0失败，含49种类型/操作组合、草稿、复制、通知、权限和地址边界。
- 原厂源流独立测试：24通过、0失败，包含此前21项回归及字按钮往返、新建混合工程、状态列表增减与类型/操作矩阵。
- 完整 `Build.ps1` 已通过。主集成离屏36通过、0失败、1字体后端跳过；同套后台Windows测试37通过、0失败、0跳过。字窗口测试在后台Windows亦57通过，实际Windows字体显示已检查。
- 字按钮专用设备记录测试56通过，含49种组合、共享头、外部地址回调、按下帧宽度和失败事务。新增帧解码测试确认字按钮OFF→ON顺序，位按钮回归继续保持ON→OFF。
- 六份产品样例均完成原生源导出、重新导入和设备再编译；宏样例调用实际ARM SDK编译，未把源码字符串写入设备冒充机器码。
- 原厂离线编译49种组合后，与本版 `.ksp` 直接编译和本版导出 `.sm` 再编译结果分别按操作、类型、地址、几何映射对照。各49记录、665项活动字段比较均零差异，休眠字段、原厂残留字节和无监视区不参与等同声明。
- 构建期间Z盘耗尽导致Build脚本和两份测试源写入失败，已从任务基线和成功工具补丁记录完整恢复；业务源码未受损。恢复后独立源测试及界面测试通过，最终构建仍需重新验证。

原厂产品源编译的七操作按下效果产生14张图，各控件依次为OFF灰图和ON橙图；数值输入和密码输入未新增键盘专用文件。此项证明编译文件布局，不代表屏端键盘执行已经通过。原厂UI勾选按下效果的额外自动化采样未稳定成功，不将未勾选的样本计为按下效果证据。

## 证据来源与限制

本轮原厂编译使用沙箱私有副本，其SHA-256为 `38100bf47294342119560dadfbd6a35d6ab51180c0eeaf4b7b21517bea20ed89`；安装原件SHA-256为 `305592b4e4bc1b15a707c7bc832c31f27ca0958b97f9c79a5b50ac6df49e907c`。两者同为18682368字节，只有文件偏移0x7c4..0x7c6三字节不同：55 89 e5被替换为b0 01 c3。只读恢复反编译确认这是启动时管理员令牌检查，私有副本使其返回true；字按钮写入器、图片写入器、数据及资源区未修改。本轮未触发UAC或改变用户输入桌面，也不声称对未修改安装原件完成动态运行。

格式证据来自普通Ghidra静态分析、私有进程运行、原厂离线文件和本版测试；本会话没有REA MCP，不将这些记录称作REA Evidence。原厂构造中未初始化的额外地址和隐藏标志，在本版独立设备记录中置零，未凭随机非零值开放未知功能。

调查目录为工作区 `.scratch/kinseal-wordbutton-20261109/`。原厂与产品对照见 `device-analysis/native-product-comparison.json`，源码交接见 `source-analysis/source-codec-handoff.json`，完整构建见 `build-complete-check2.log`，后台Windows结果见 `private-windows-tests.log` 和 `word-ui-windows-tests.txt`。
