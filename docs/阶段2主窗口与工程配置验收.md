# 阶段2：主窗口与工程配置实现、验收及边界

本轮版本0.9.0，修改标记`20261110-7`。正式程序在`dist/KinSealStudioLite-Stage2-0.9.0/KinSealStudioLite.exe`。关机要求保持取消。本文只把实际实现和实际执行的检查列为通过；阶段2整体仍有配置、源和设备运行缺口。

## 已实现的工作流

- 文件：三步新建工程向导，上一步保留输入，取消不建文件；先完整解析打开目标，再处理当前未保存工程；保存／放弃／取消；保存失败或另存取消阻止关闭。保存同一目标后重新读取，避免采用提示前的旧工程。`.ksp`保存与`.sm`导出有独立扩展名守卫；最近10项保留完整路径。
- 命令：菜单和工具栏共享QAction与启用条件；原生稳定命令ID、`Ctrl+P`属性、`Ctrl+T`文本一览、`Ctrl+U`地址一览。文本和数字输入框内的复制、剪切、粘贴、删除及撤销保持局部操作。无工程时禁用编辑、页面／语言选择与下载，视图开关和打开／新建仍可用。
- 页面：真实标签、下拉框、对象树和系统树按稳定ID切换；普通页和窗口新增、改名、复制、删除；窗口默认240×180。启动页和编辑页、启动语言和编辑语言独立。复制重建页／对象／组／内部引用身份；删除启动页或被引用页会阻止。普通窗口的背景、位置、关闭按钮及全局编号尚未在新模型中实现。
- 撤销：最多100条完整工程历史，包含隐藏页面、宏、图片和配置；保存点独立，撤销离开保存点变脏，重做回保存点清脏。导航和语言编辑选择不算内容修改；比较按图层稳定排序，保留同层相对顺序。
- 全局工具：控件／文本／地址一览、宏查找，支持全工程／当前页／选中对象范围和稳定结果定位。宏源码结果打开只读源码并定位行。地址替换先预览，再整体校验、一次提交；检查类型、协议、连接ID、完整跨度、过期预览和重复目标。未知扩展、宏字符串、未恢复地址字段不做猜测替换。
- 系统参数：屏保0..60分钟（默认1）、闪烁1..50×0.1秒（默认10）、触摸声（默认开）、默认等级1..8（默认1）、LW进制（默认十进制），支持草稿、取消、`.ksp`保存和重开。严格五键类型及范围校验；默认不额外创建节点，已有节点恢复默认仍保留身份／扩展。原生源快照工程只读。**这是UI／保存切片，LW地址编辑显示尚未跟随Hex参数改变；含系统节点工程在源导出和设备编译前明确拒绝。**
- 帮助：F1打开本地专题文档；全局工具保留来源、位置及拒绝原因。

## 原厂行为与协议证据

取证脚本、原始UI枚举、截图、单字段源、13组编译结果见[native证据目录](stage2-evidence/native/)。生产实现未引用未知外部“参考程序”目录。

1. 原厂新建向导3步：型号／名称／路径／方向，通信连接，上电Logo。最后一步的Logo和普通启动页分别建模。原厂默认型号AMZ070W01；新软件仅开放已验证AMT070W124-L800X480R、水平800×480，属于明确产品范围差异。原厂向导Logo时间1..60秒；独立Logo编辑窗时间50..99000毫秒，两者不可混用。
2. 旧已验证`CodexProbeTest.sm`通过原厂Logo窗口确认“不需要开机Logo或动画”。新向导沿用此默认；开启Logo／动画仍不可选。新noLogo向导源与旧seed有未恢复字段差异，不能宣称二者字节相同。
3. 系统源单字段差分：屏保`config.head.5`（BE i32），闪烁`config.head.6`（BE i32），触摸声`config.head.8`（byte），默认等级`config.head.14`（BE i32），LW进制`config.flags.1`（byte）。详见[精确差分](stage2-evidence/native/system-source-differences.json)。这些源映射尚未接入新软件的系统参数序列化。
4. 同一原厂进程13次真正重编译（基线2次、每单字段各2次、还原基线），每次检查新mtime和编译成功。4998字节SysPara中稳定观察：屏保1→2对应byte3的1→2；闪烁10→11对应byte4的10→11；等级1→2对应byte22的1→2；触摸声开→关对应byte8的0→1。Hex开关未找到排除重复噪声后的稳定SysPara变化。121个非确定字节单列，不纳入语义映射。**这里只确认测试值关联，字段宽度、完整取值域和固件消费者仍未证明。**完整比较见[重复编译差分](stage2-evidence/native/system-compile-comparison.json)。
