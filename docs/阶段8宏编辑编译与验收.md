## 2. 普通源码工作区与持久化事务

实现位于`src/macro_workspace.*`。只接受`SourceKind::Ordinary`；地址变量和未恢复调度格式不通过普通`.c`导入/导出入口。读取清单不生成稳定ID；成功的新增/更新/重命名等事务才补齐缺失ID，并保留既有ID。复制获得独立ID，名称变化保持源身份。

名称是区分大小写的Unicode显示键，允许1..256个QString字符，首尾不能有空白，禁止控制字符并要求UTF-8往返无损；不把宏名当C函数标识符。复制名使用`_copy`、`_copy2`等首个空闲键，属于Lite规则，未冒充原厂后缀策略。新建/复制限制普通宏总数≤100；原模型允许的101..128条既有宏仍可列出、修正、重命名和删除，不能新增至更大数，设备编译仍最多100条。

普通源码按UTF-8内容字节限制1MiB；拒绝NUL、无损编码失败及正文起始BOM。导入字节严格校验UTF-8，API提供Allow/Reject/Require三种BOM策略；导出显式选择是否发BOM，最多为1MiB内容加3B BOM。工作区编码API不主动替换换行，GUI源码由Qt文本编辑器输出，不据此宣称原厂换行字节等价。读取、校验和文件写入失败均保留旧工程/旧输出。产品文件入口采用明确`.c`过滤和原子写出，不把普通源码文件、KSP JSON和原厂SM互相改扩展名当作互通。

重命名检查全部页的11类序列化名称载体，包括活动和休眠字段：位按钮、字按钮、指示灯、功能按钮、画面按钮、多态按钮、多功能按钮、数值控件、ASCII控件、滑动开关和下拉框。稳定ID引用保持身份，旧名称字段同步迁移。删除遇任何活动/休眠名称引用、通用稳定ID入边或未知不透明源消费者均拒绝，不通过清空禁用字段绕过保护。对不透明原厂源快照不擅自改写。

`macroBindable`开放位/字按钮、滑动开关和下拉框四类当前绑定家族；指示灯、功能按钮及其它未核类型保持禁用。保留的禁用宏名用于持久化/引用保护，不代表该控件可执行宏。管理源码与允许绑定、设备编译和设备执行分别判断。

## 3. 产品编辑器和线程生命周期

`MacroManagerDialog`拥有完整脱离主工程的草稿。切换宏前校验当前源；输入无效时保留文本并恢复原选择，避免切换后误覆盖另一宏。新建、整宏复制、重命名、删除、UTF-8导入导出、撤销/恢复及查找都在草稿内操作。保存经`commitProjectDraft`形成一次主工程历史事务；取消不改变主工程dirty和撤销栈。

主窗口采用堆上模态对话框，并用`QPointer`检查主窗口和对话框存活。SDK编译在独立QThread中运行；worker仅拥有冻结输入、结果和共享取消标志，不持有QWidget。编译时冻结编辑操作，停止按钮只设置取消标志；取消或关闭等待本次拥有的编译任务退出后再丢弃工作区，避免运行中的QThread被析构。编译成功提示仍明确“尚未下载或运行”，不把工作区编译结果直接写入设备。

本批UI采用Qt源码编辑区和明确的整工作区事务；原厂完整QScintilla编辑行为、全部工具栏排列、宏查找/使用一览、导入导出格式、调度和变量表编辑仍有差异。最终宏UI采用r3的48项测试身份；主任务已实际查看后台widget截图[宏编辑器](stage8-evidence/windows-r3/macro-editor.png)、[函数库](stage8-evidence/windows-r3/macro-library.png)，确认源码、库、输出、变量范围、编译、保存/取消可见且未叠放。截图仅来自owned widget，r3只增加测试截图，不改变生产逻辑或测试条数。

## 4. 零变量ADS编译与报告契约

`compileDeviceMacros(project,sdk,package,error,options,report)`新增六参数API，旧四参数入口继续兼容。输入宏集合先冻结，所有宏成功且临时目录回收确认后才发布完整package、MarcoRun/MarcoVar及索引。失败或取消不替换调用方旧包；独立失败报告不得别名`package.compileManifest`。

调用链仍为armcc→armlink→fromelf，目标ARM920T。实现接受`AMT070W124-L800X480R`、`AMZ070W01`两键的既有内存配置，其它型号拒绝；本轮已跑样例以manifest的targetModel为准，不推广为所有AMT/AMZ型号已验。AXF须ELF32 LE ARM、入口Macro_Entry在RO首地址，RW/ZI在每宏1024B槽；RAW不能是ELF，单RAW≤65535B，含头总包≤0x20000B。RO首`0x80520400`，后续加alignUp(rawLen,`0x400`)；RW=`0x80440000+index×0x400`。仅零地址变量宏生成每宏904B全零MarcoVar，未知调度flag不制造。

默认单进程30s、调用总120s、启动5s、终止确认等待2s，单进程输出256KiB、调用累计1MiB。取消、阶段/总超时、输出洪泛和工具失败保留首错，并终止拥有的SDK子进程。操作系统若未确认终止，QProcess析构可能额外等待；限时参数不构成不可超过的墙钟返回保证。报告单列清理是否完成，不隐藏失败。
