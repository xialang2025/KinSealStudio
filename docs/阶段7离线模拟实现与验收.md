## 3. Lite运行器的启动与内存规则

实现位于[simulation_runtime.h](../src/simulation_runtime.h)与[simulation_runtime.cpp](../src/simulation_runtime.cpp)。它是独立值拥有者，没有QObject、计时器、驱动、进程或物理I/O依赖。

1. `start()`先完整验证模型和能力；失败保留现会话，成功复制工程并清零两类存储区、设用户等级0、选择启动语言。工程快照不接收运行值回写。
2. 只接受一个800×480普通画面，启动页必须是该活动页。`nativeSourceSnapshot`非空、活动全局配置、多页/窗口/键盘页和未支持对象在启动前拒绝并列名。
3. LB、LW各4097项，合法索引`0..4096`；复用`plc_address`按位/字角色及跨度解析。外部地址、`@connection:...`、角色错配与跨尾访问拒绝。
4. 七种字类型依模型顺序为U16、U32、I16、I32、BCD16、BCD32、F32。32位低字优先，F32为IEEE binary32。非法BCD、NaN/Inf、整数溢出、浮点溢出/下溢和不合法输入均拒绝，失败不改内存或调用者输出。
5. `startupLanguage`非空时采用它，空时取`languages.first()`；不把编辑器`activeLanguage`当启动语言。启动等级固定0。

零初值、0..4096容量、32位低字优先、等级0、边界绕回、事件先后均是明确的Lite规则。原厂尚无同一刺激的独立观测，不能将这些默认写成原厂事实或原固件一致性结论。

## 4. 对象动作、权限和事务顺序

| 对象/操作 | Lite规则 | 拒绝或待恢复 |
|---|---|---|
| 静态text | 语言、可见性及公共静态文字渲染 | 状态内嵌文字独立权限未接入 |
| bit switch | 动作0置位、1复位、2点动、3交替；press执行 | 按压阈值、闪烁及原厂精确时序 |
| word switch | 赋值、加/减、增/减绕回、数值/密码输入 | 整数字非零小数缩放；越过配置上下界拒绝，绕回直接跳min/max是Lite规则 |
| lamp | 位、字位和多态监视；状态不在声明范围时`visualState=-1` | 不用状态0掩盖无效监视值 |
| function | 仅function8注销等级、function13语言切换 | 其它function按名称在启动前拒绝 |

普通动作在press事务执行；一次只拥有一个按压/输入，重复press拒绝。点动位由该交互拥有，release、移出、cancel、stop、权限丢失均强制清false。数值/密码press只建立pending，release后UI请求输入，submit才写入及发通知；非法输入保持pending，可纠正或取消；取消不写值。

一次动作的目标写、位通知、字通知、语言/等级变化先对候选内存完成全部检查，然后整体提交。动作地址与通知地址重叠，包括跨字重叠，拒绝；失败不留下部分写。权限只实现单个bit/level/word条件，字比较enum顺序`< > == <> <= >=`。多条件AND/OR、enabled但没有活动条件、非零容差和独立状态文字权限均拒绝。等级侧栏是测试刺激，不是用户认证。

宏绑定允许保存，启动警告和`macro-skipped`事件明确说明不执行；初始化/周期/事件宏没有调度特例。活动采集、报警、历史、配方、资料传输等全局配置均在启动前拒绝；当前没有扫描时钟、闪烁调度或配置持久化。这是有界能力门禁，不能据“没有执行宏”关闭完整S07-04。

## 5. UI与PC帧生成规则

实现位于[simulation_window.cpp](../src/simulation_window.cpp)及[main_window_simulation.cpp](../src/main_window_simulation.cpp)。原生工具菜单两个真实QAction已接入。离线入口enabled为`hasProject && !downloadInProgress`。

离线启动从当前编辑数据复制快照，无需保存。`SimulationWindow`为同进程独立顶层QDialog，不是原厂独立EXE。重复启动显示已有会话并提示；关闭后可从最新编辑数据重新启动。模拟期间编辑工程的内容、dirty及路径保持隔离；父窗关闭和owner销毁清理会话。是否与原厂保存流程一致仍留待补证。

`simulationFrame()`固定生成800×480、`ARGB32_Premultiplied`的QImage，浅蓝底；按layer稳定排序，同层保留插入顺序，统一裁剪。文字复用`static_text_renderer`，其它对象复用`bit_button_renderer`及lamp状态。PC QImage步长不套用设备奇数宽RGB565规则，未新增设备像素编码。

可见对象从上向下命中；顶部不可触摸对象不会穿透到底层执行。模拟viewport不编辑/选中/移动工程项。`visualState<0`不画该对象，不以状态0掩盖错误。move-out、focus loss、UngrabMouse、WindowDeactivate、close及destructor都解除点动。析构先禁callback并销毁viewport，再停止runtime，避免清理回调访问失效对象。

松开后才弹数值/密码输入；非法输入显示原因并允许重试或取消。modal过程中用QPointer防owner被删除后访问。侧栏可读/写内部地址、选择位/七种字类型、设等级0..8及退出；这些是模拟调试刺激，未经认证的真实登录功能未实现。

在线菜单当前只显示范围说明：无Connect按钮、无真实端口连接。原厂状态帧尚不可用，因此本批PC帧及命中回归不构成原厂像素差分，更不关闭HMI E。

## 6. CLI、输出和有界诊断

实现位于[simulation_cli.cpp](../src/simulation_cli.cpp)。输入为Lite JSON工程，不直接消费原厂16文件模拟输入契约。

```text
KinSealStudioLite.exe --simulation-capabilities 工程.ksp
KinSealStudioLite.exe --simulate-offline 工程.ksp 事件.json 输出.json
```

`--simulation-capabilities`成功生成报告时`ok=true/exit0`表示报告成功；是否支持必须读取报告顶层`supported`及`errors`，不能只看进程退出码。

事件JSON为array，支持`press(id)`、`release(inside)`、`cancel(reason)`、`stop(reason)`、`level(value)`、`write-bit(address,value)`、`write-word(address,type,value)`和`input(value)`。工程≤16MiB，事件文件≤1MiB且≤1024项。type为前述0..6整数，字值为string，位值为bool。

每项trace保留状态及ARGB32帧SHA，去除重复events/warnings；trace累计≤8MiB，最终输出≤16MiB，能力报告≤1MiB。runtime事件最多512条；能力错误最多128条，id/property/message分别限256/128/1024字符；宏绑定warning最多128条、宏名截128字符，另有通用边界说明。

输出必须独立`.json`，不得覆盖工程/事件输入，包括别名/硬链接；允许原子替换不相干既有输出JSON。使用QSaveFile提交，失败保留旧输出，停止runtime并输出简短错误，不再次打印超限trace。输出记录源和事件身份、关闭前最终PNG base64、`stateBeforeStop`与`finalState`，末尾显式stop。包含`hardwareIo=false`和`hmiBehaviorConfirmed=false`。

存在密码输入控件时，CLI导出snapshot去掉LB/LW并标`memoryValuesOmitted`，含value的事件遮盖；不导出可能暴露输入的原始events digest，改用`eventsIdentity`。runtime原始`snapshot()`仍用于内部诊断并含真实内存，调用者不能将其当成已遮盖导出。

## 7. Modbus RTU回放边界

[simulation_modbus_transport.cpp](../src/simulation_modbus_transport.cpp)只接受注入的open/write/read/close callback，没有串口、USB、socket、PLC profile或原厂驱动后端，也没有连接runtime地址银行。

功能码1读线圈、3读保持寄存器、5写单线圈、6写单寄存器；station为1..247，地址是PDU零基offset，不把40001或原厂地址族推成映射。队列默认32、允许1..1024；timeout默认1000ms、允许1..60000ms，均为产品采用值。RTU帧间隙由调用者的明确frame边界/回放endOfFrame提供。

完整CRC、站号、功能、长度、字节数、写echo校验后才发布values。错帧、短写、超时、异常、断开、重入保留首错，关闭端点并丢弃未发送队列；无自动重试。已尝试发送的写可能已到从站，不能承诺远端回滚。报告scope为`controlled-modbus-rtu-replay`，`physicalEndpointUsed/hardwareTransferVerified/hmiBehaviorVerified=false`。

97项回放通过不关闭S07-05。真实在线仍需要端口配置、PLC身份与地址映射、runtime扫描/写队列、取消/重连及端口释放的实际集成证据；HMI T/E独立保留。
