# 阶段1源格式安全与保全切片

日期：2026-11-10。修改标记：`//20261110-5`。本分工负责 S01-04/05 的源 codec、源回归与最小语料；不修改工程模型、设备协议正文或阶段状态。生产修改为 `src/native_project_codec.cpp/.h`；测试为 `tests/native_project_codec_tests.cpp`。

## 已完成的支持边界

| 层 | 本次结果 | 边界 |
|---|---|---|
| 文件头与归档 | 继续区分头识别、原 SHA 归档恢复、完整结构检查 | 头正确不代表主体可编辑；归档恢复不代表可下载 |
| typed 结构 | 完整读取 version122、AMT 指定型号、已恢复 page 列表与五类控件；检查 EOF | 多页是只读结构能力；未知顶层类型/子图元继续拒绝，不跳过透传 |

| 单页语义互通 | 五类既有源读写继续保留；导出完成后重新语义读取再提交字节 | 新模型多页、非普通页、配置/引用、无映射画面扩展等明确拒绝 |
| 启动语言 | 显式登记名称优先；空串保留已支持快照中的原选择或新工程首语言 | 当前写回已恢复字段组合；原厂 0/1 分离组合仍保守拒绝，见下文 |
| 未映射值 | 未改 span 保留在完整快照，单态/按下态/同文仍由五类专有规则处理 | 原厂不能由当前模型表达的活动值继续拒绝或整源归档 |

第一页面沿用 `page.*` 和 `object[i].*`，后续页面使用 `page[1].*`、`page[1].object[i].*`，防止字段注册表重名覆盖。语义导入在读取活动模型前检查页面数为1；语义导出、设备默认配置助手及启动语言助手也分别守住单页边界，合法多页快照不能装进单页 K 模型后偷渡到后端。

启动/页面名称组合检查是当前受限互通策略，不能倒推为原厂所有合法文件的共同不变量。KSP 的 project/page/macro 稳定 ID 属于编辑身份，本切片不声称 `.sm` 重导后保留这些自定义 ID；配置节点和显式引用未恢复时不会因删除 JSON 的 `pages` 比较项而被静默忽略。

## 安全读取与事务

- 64 MiB 源文件、1 MiB 单 QString 字节、每集合原有限额继续保留；额外限制总 typed 字段262144个，并按剩余字节约束集合长度。这些是 Lite 资源保护，不是原厂上限。
- QString 长度按 UTF-16BE 字节检查，奇数、超限及超剩余文件均拒绝；null 与非 null 空串、opaque QString/字节不作全局归一。
- 所有写入仍来自 typed span。导出先检查活动模型能力，生成局部结果，再完整解析并转换回受支持语义，成功后才替换调用方字节。
- 大型真实源的自产休眠诊断超过128条时，显示127条及一条明确的剩余数量汇总。完整源快照和全部原始值不截断；没有放宽 KSP 对外来警告数量的保护。真实67控件功能矩阵专门回归该边界，并与独立规格逐项核对功能类型。
- 原快照的损坏、版本/类型未知、活动宏元数据不能表示、语言组合不在当前支持范围时均拒绝。快照结构检查不是来源认证；整源归档的原 SHA 核对与语义编辑保全是不同能力。

## 两个必须保留的原厂反例

English 产品输入原本两字段均为1。原厂中文编辑态回存 r1 后，`system.identity.16` 为0而 `config.290.0` 为1；文件可被原厂重新打开。实际把原厂语言组合框选成 English 后回存 r2，两字段均为1，当前受限语义解码成功。因此不能仅凭这组样本宣布两字段在所有状态都同义，也没有为通过测试撤销现有守卫。r1作为完整结构可读、语义拒绝、整源可恢复的反例保留。

宏产品输入有 `SetLB1` 源码和绑定。原厂属性窗口显示宏组勾选但禁用、列表为空；接受属性并保存后，活动宏名变为 null，而历史源码仍名为 `SetLB1`。当前 codec 明确拒绝这种不能表达的活动绑定。正向宏事务测试使用单独标为产品输入的源；16字节MD5缓存是显式人工注入，用于证明未编辑保全、改源码后清旧缓存，不能证明本轮运行过原厂宏编译器。
