## 2. 八元素路径与填充/描边闭合语义

独立路径按`moveTo(rect.center()); arcTo(rect,45,90)`生成，共8元素：圆心move、到45°端点的连线及到135°端点的两段三次弧。默认外接框`100,100,200,200`，中心`200,200`；原厂实际编译保留的是局部8元素path，painter的线性变换为单位、平移为bbox的`100,100`，不是整个矩阵identity。原始local path与transform分别保留，另显式映射到scene后比较；默认独立Qt6路径与已映射原厂路径的26.6元素完全相等，不重写原始观测成全局路径或identity。

填充按路径fillRule隐式闭合至圆心；描边保留原8元素路径，不主动`closeSubpath()`增加第九元素/末端径向边。两者不能混成一条强制闭合路径。默认NoPen意味着没有描边层，不能凭默认相等推导lineStyle1或粗边径向闭合已核；这些必须由正式线/填变体证明。

原厂默认实际绘制为QPixmap800×480、NoPen、renderHints3；本轮候选白填、Alpha255。与椭圆hints11等记录分家族保存，不以“都用曲线”取代实际观测。原厂路径仅作为诊断对照输入，生产必须从独立模型重建，不能拷贝原厂pathstream或已编译帧。

## 3. 默认1像素差异的定位与精确D函数

[默认舍入专项](stage5-evidence/native/sector-rounding-20261114/默认扇形舍入排查与候选规则.md)及其`sector-rounding-r1.json`保留两种路径来源与两种舍入式：独立Qt6 `arcTo(45,90)`、保留原厂8元素路径加真实平移。两者的独立细分/面积积分对公开Qt4诊断覆盖均0差异；旧混色各差1像素，正确混色各完整768000B相等。原始失败没有被覆盖。

正确每项整数函数为`D(v)=(v+(v>>8)+128)>>8`，先对原v右移，再加128。旧式`D_old(v)=(v+128+((v+128)>>8))>>8`不可互换。每通道分别计算源、目的贡献再相加：`out=D(source*alpha)+D(destination*(255-alpha))`；白源255的源项恰为alpha，黑源项0。

差异点设备坐标`(268,126)`、coverageAlpha11；背景红197的目的分子`197×244=48068`，新式188、旧式189；加白源项11后为红199或200，跨过565阈值。新候选RGB`199,223,255`得到`0xc6ff`，旧候选`200,223,255`得到`0xceff`。这些RGB值为候选整数运算结果，不伪称直接读取到原厂未量化RGB32。

两条正确默认帧及原厂完整SHA256均为`73653ee69d44d72a4ab9c6547c817423bdfae1e0c5da44b12da347caa5fe0251`。同一覆盖图仅改D顺序即消除单像素，无须改路径、硬编码某像素或增加忽略区。只核了默认200正方形、line0/fill1，不能推导平移、奇数尺寸、其它开关、描边、多对象或贴边已通过。

## 4. 候选细分、覆盖和补片规则

复用已证独立定点曲线几何：有限非负控制点→26.6截断→控制点量化extent选择`16<<adaptation`及`32<<adaptation`阈值→保留历史XY交叉项和绝对场景位置依赖的深度选择→乘4进入256子像素格→整数de Casteljau二分→每叶输出`(a+3b+3c+d)/8`中点及终点。输入512、输出4096、深度8为明确资源上界，整段先验预算，超限拒绝，不裁短路径。
