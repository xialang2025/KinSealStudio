# 全局宏与初始化宏原厂离线对照

2026-11-23，使用原厂 V5.1 在独立 Windows 桌面操作 AMT070W124 测试工程副本。安装目录主程序 SHA-256 为 `305592b4e4bc1b15a707c7bc832c31f27ca0958b97f9c79a5b50ac6df49e907c`。用原厂「全部编译」先生成普通宏，再通过「离线模拟」触发工程编译并截取 `compile/`。测试未向触摸屏、PLC 或固件发送命令。 [普通宏基准工程](../tests/fixtures/native-source/bit-analysis/macro-bound-product-seed.sm) · [原厂界面取证](系统参数功能与界面取证/05-宏指令.md)

## 候选与保存

- 同一工程里未编译的 `SetLB1` 两窗均不可选。宏编辑器运行「全部编译」并生成 `SetLB1.bin` 后，两窗候选均出现 `SetLB1`。保存编译状态并以独立进程重开后，候选仍然可用。
- 两窗均允许重复添加同一个宏。全局实例分别保有自己的频率、次数和受控地址，初始化列表能保留两行同名实例。
- 内层新增确认后，全局管理器的「确定」、初始化管理器的「退出」及两个管理器右上角关闭按钮均保留列表变更。随后按主窗保存，独立进程重开复核列表。
- 全局宏输入频率 300 和次数 3、启用受控 LB17 时，管理器显示 `SetLB1 | 30000 | 3 | 是 | 位地址 | LB17`。第二条同宏使用默认值，显示 `SetLB1 | 100 | 0 | 否 |  | `。
- 原厂地址键盘默认内部存储器和 LB，显示十进制、`0~4096`，输入 4096 能回填 `LB4096`。同一键盘还列出 `LW_Bit` 和 COM1，选择 `LW_Bit` 时显示 `0.00~4096.15`。本次只验证 LB17 的调度产物，尚无 LW_Bit、COM1 和边界地址的运行证据。

## 原厂源工程

用 `--inspect-native-source` 逐字段对照版本 122 的 Qt 数据流。计数及 i32 为大端。字符串为 Qt4 QString。

| 字段 | 观测值或规则 |
| --- | --- |
| `system.174.count` | 初始化行数。1 行为 1，重复添加后为 2。 |
| `system.174[i].0/.1` | 宏名、入口名，实测为 `SetLB1` 和 `MACRO_MAIN`。 |
| `system.178.count` | 全局行数。各行按管理器顺序保存。 |
| `system.178[i].head` | `qqibi`，依序为宏名、入口名、频率输入值、受控布尔值和 0。示例频率保存为 300。 |
| `system.178[i].address` | 受控 LB17 时九字段为 `"LB17", 0, 0, 100, "17", "LB", 0, 1, ""`。未受控默认项为 `"LB0", 0, 0, 0, "0", "LB", 0, 1, ""`。 |
| `system.178[i].tail` | 两个 i32。受控 LB17、3 次时为 `1, 3`，未受控、默认次数时为 `0, 0`。界面只有受控类型和地址字段。 |
| `system.194.count`、`history.1981f8.count` | 两项均为 0。脚本定义独立保存在 `history.1e4`，样本均为 1 条定义。 |

## 设备产物

`SysPara.dat` 为 4,998 字节。以下偏移相对文件起点。源频率 300 编译后为单字节 44（`0x2c`），位于全局记录的频率位，源工程仍可保留 300。多字节值采用小端。

| `SysPara.dat` 位置 | 原厂样本实测 |
| --- | --- |
| `0x528` | 全局项数。基准 0，单条 1，重复宏双实例 2。 |
| `0x52c + 12*i` | 行起点。宏编号位于行偏移 `+0`，频率字节位于 `+1`，执行次数位于 `+8` 的 i32。两个全局实例均引用编号 0，频率分别为 44 和 1，次数分别为 3 和 0。 |
| `0x82c`、`0x844 + i` | 初始化项数、各项宏编号。单条 SetLB1 样本为 1 和编号 0。 |
| `0x882 + 40*i` | 受控记录起点。受控 LB17 的 `+0` 为 1，`+6` 为 100（十六进制 `64`），`+12` 的 u32 为 17。无受控项这三个值均为 0。 |
| `0x82e` | 无调度基准和单条非受控样本均为 1，只有初始化的样本为 0。待确定此字节的含义。 |

两种调度在同一空白页工程中均调用 `SetLB1` 时，原厂日志同时识别全局和初始化调度，只编译一条脚本。空白页有 `MarcoRun.dat` 1,048 B、`MarcoVar.dat` 904 B、`SheetPara.dat` 72 B 和 `SheetPixel.dat` 3,655 B。工程内含位按钮的对照样本另生成 `ControlPara.dat` 640 B、`ControlPixel.dat` 7,200 B，空白页产物中没有这两个 Control 文件。

## 原厂重开 Lite 导出工程

用原厂 V5.1 在独立 Windows 桌面打开 Lite 写回的 `lite-schedules.sm` 副本。全局宏管理器仅有一条 `SetLocalBit10 | 30000 | 3 | 是 | 位地址 | LB17`，初始化宏管理器仅有一条 `SetLocalBit10`。导出工程 SHA-256 为 `9a96bdac5f6831f65465f5f189b74076bee4cff57d0c2433c11473cc7563a597`，核对前后原文件与副本内容一致。此轮验证覆盖原厂工程读取及调度列表显示，宏编译与设备运行由上文各场景分别说明。
