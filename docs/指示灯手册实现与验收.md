# 指示灯实现与验收（0.6.0）

修改标记：`//20261109-8 add / change`。目标型号：`AMT070W124-L800X480R`，单画面800×480。完整构建及本轮USB结果在文末记录。

## 实现范围

添加菜单、工具箱与画面工具栏的“指示灯”入口，使用“位指示灯”属性窗口，初始停在指示灯设置页。保留双态位地址、字地址的0..15位监视，以及多态U16/U32、2..32状态的监视。指示灯没有操作地址、触控权限和按压时间；显现条件复用已恢复的公共记录。

四页属性、确定后拖框、取消、重开、复制、历史与各状态预览均复用现有编辑路径。多态第2状态以上具有独立文字与图片外观，所有状态共享终端3D和透明效果。新工程使用schema7，保留schema1..6的兼容加载。系统图库继续使用5647张资源及既有透明绘制。

独立编译器产生原生type10/subtype4的640字节控制记录、只读地址扫描、各语言状态图片及工程快照。`.sm`有独立typed读写，使用真实原厂指示灯seed；不会借用位按钮子类型伪装指示灯。无需原厂程序参与正常编辑和下载。

## 原厂证据补充

手册早期合成鼠标调查中无法确认的项目，本轮通过原厂Qt属性、真实点击保存的`.sm`、原厂离线编译以及RGB565解码重新核实：

1. 双态与多态的“与操作地址相同”均为禁用；宏指令组、通知组也为禁用。新程序保持这些禁用状态，编译时拒绝人为启用的数据。
2. 真实点击多态组后状态数范围为2..32，外观索引为0..N−1。只设置Qt checked属性得到的残留上限256不能作为功能范围。
3. 默认位监视存储bitIndex=0；新建界面显示禁用的15。真正切为字监视且未改字位时可存15；用户修改后的位号独立保存。
4. 双态图片为ON→OFF；多态图片为状态0→N−1。语言在外层。双态闪烁会紧随对应状态增加无字帧；多态闪烁不增加帧，原厂只保留前两状态的头标志，后续状态无独立设备闪烁标志。此项遵循原厂编译结果，不能据此声称所有多态文本均能实机闪烁。
5. 两组都取消只是对话框暂态。默认灯在原厂确定后落盘为mode2/U16/2状态；原厂reader对手工mode0还会归一为双态。本版确定时归一到多态，拒绝持久化或下载无监视的mode0。
6. 多态新扩展状态默认空文字、微软雅黑16、黑色居中、`switch_ON.kvg`、背景`#a0a0a0`、不透明255。
7. 显式状态数5→2→5会清除已删除的附加状态；仅切双态/多态则保留多态草稿。“使用同一段文字”是整个指示灯的开关，各状态仍有自己的文本；新增长状态继承开关，文本为空。
8. 原厂“不使用图片”保留路径，以源图片kind3及Rectangle预览子对象保存；有图为kind1及Pixmap。新源codec分别解析和重建这些结构，保留KSP原始草稿，拒绝未注册语言与未验证的其它控件源编辑。
9. 无图/同文组合已成功原厂复开并编译，矩形状态2及各状态独立文字已目视核对。同文模式原厂设备标志为0x1bc=1，只生成一套图片供所有语言共用；独立编译器采用相同图片数量和字节长度。

证据目录：工作区`.scratch/kinseal-lamp-20261109/`，含UI、source和device三个调查目录。安装原件SHA为`305592B4…`；私有运行副本SHA为`38100BF4…`，仅启动令牌检查三字节不同。所述运行证据来自该副本，未将其表述为未修改原件动态执行，也未将普通工具结果标作REA MCP Evidence。所有运行与截图均在私有桌面或离屏完成。

## 样例与现场核验

`samples/lamp/`包含双态位地址、双态字位、多态U16五状态、多态U32三十二状态、双语多态与显现条件、指示灯实机联调六份工程。

实机联调工程包含：LB0双态灯及切换LB0按钮；LW20的U16五状态灯及加1/归零按钮；LW30的U32五状态灯及置3/归零按钮。无需外接PLC即可操作观察。屏端应检查ON/OFF切换、状态0..4、U32置3及归零；显现和多语言另用相应样例检查。

设备ACK只证明数据段及提交获确认，不能替代屏端显示、触控激励、权限、语言和闪烁的现场观察。未获得实际反馈前不将它们标为全部实机通过。
