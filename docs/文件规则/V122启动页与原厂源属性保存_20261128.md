# 原厂 V122 启动画面、页面宏与源文件保存规则

## 页面和对象的界限

原厂页写函数位于 `KinSealStudio5.1.exe` 的 `0x00A61980`，本轮读取的安装原件 SHA-256 为 `305592b4e4bc1b15a707c7bc832c31f27ca0958b97f9c79a5b50ac6df49e907c`。下面的字节区间采用从零开始、右端不含的约定。

1. 普通页面数在 `project.pages.count`。`0x004B0216` 将每一张普通页交给页写函数。普通页结束时，`0x004B0378` 检查版本大于 101 和系统对象 `+0x184` 的开机页标志。`0x004B05D1` 将 `+0x18C` 的 QString 与空串比较。标志有效且字符串非空时，`0x004B0604` 另写一次完整页面，再写宏历史及工程尾部。在系统对象的写函数中，`0x00567D92` 与 `0x00567DA3` 分别写上述标志和字符串，对应 Lite 的 `system.tail.0` 和 `system.tail.1`。
2. 普通页面数和末尾的页映射保留各自原值。额外的启动页也有矩形、两种颜色、页名、三位页号、页面宏列表、子图元和层级。实测《写时间到PLC.sm》的普通页之后，`[1168793,1168980)` 是整张“启动”页，页号 `000`。同样的格式出现在官方 ASCII、HMI 保护、多语言、两份时钟工程及两份不同的七寸出厂组态中。
3. 每项页面宏以九字段地址开始，随后顺序为一个布尔、**三个**大端 32 位整数、两个 QString 和一个大端 16 位整数。原厂写入位置依次为 `0x00A61B4E`、`0x00A61B86`、`0x00A61BBE`、`0x00A61BF6`、`0x00A61C2E`、`0x00A61C66`、`0x00A61C9B`、`0x00A61CD4`。旧版多读一个整数，会吃掉第一个 QString 的长度，后续报错出现在字符串中间。
4. 七寸出厂组态还有同为类型 10、预览子图元数为二的对象。预览组按实际计数、子类型和层级递归读完，再进入公共控制字段及类型私有记录。原厂工程的权限、显现、地址、预览缓存和私有记录均保留在原流中。完整画布导入还要通过每个对象到可编辑模型的映射。

## 从界面打开和编辑

“打开”、最近文件和文件关联入口优先载入可编辑画布。一个原厂工程包含暂时不能投影到画布的记录时，Lite 在验证整个文件并通过原厂文件口令后显示源工程窗口。窗口列出普通页和独立启动页，可以编辑工程名、各页根对象的移动锁和 Z 层级，并保存或另存。工程名只替换 `trailer.settings.1` 的文件名部分，目录和原扩展名保留。移动锁写一个字节，Z 写八字节 big-endian binary64。各根的类型和 Z 分别取自该根的头和末尾。Qt 空 QString 与长度为零的非空 QString 保留各自的原始编码。

一次保存先按原字段的起止位置拼出完整候选数据，再从文件签名解析至 EOF，最后用 QSaveFile 提交。原路径文件在窗口打开后如被其他程序修改，源工程窗口提示外部变化。载入被截断的工程或重复提交同一图元的索引时，现有目标内容保留。新源码测试对一份原厂报警显示工程实测全文件还原、工程名变长再复原、单个图元改层级和移动锁、截断输入及真实对话框保存。[原厂控件回归夹具](../../tests/fixtures/native-source/retained/alarm-display.sm)

`startup-with-page-macro.sm` 为受控组合回归件。基础文件是仓库内空白 V122 工程，开机标志、名称和整张启动页取自官方时钟示例，非空页面宏行取自 36,211,621 字节的官方出厂工程 `page[4].94[0]`。组合文件长 3,440 字节。回归同时检查两页可枚举，关闭选择标志但仍强行附加同一记录时读取失败。[组合夹具](../../tests/fixtures/native-source/retained/startup-with-page-macro.sm)

## 在命令行复核

```powershell
.\KinSealStudioLite.exe --inspect-native-source 输入.sm
.\KinSealStudioLite.exe --resave-native-source 输入.sm 副本.sm
.\KinSealStudioLite.exe --resave-native-source 输入.sm 改名.sm 新工程名称
.\KinSealStudioLite.exe --migrate-project 输入.sm 可编辑.ksp
.\KinSealStudioLite.exe --export-native-project 可编辑.ksp 导出.sm
```

前三个命令用于结构检查、全文件保留和原位字段编辑。后两个命令检验画布模型及其回写能力。受保护的工程请从界面输入原厂工程口令。设备编译另行验证系统配置、目标型号、控件及资源映射。
