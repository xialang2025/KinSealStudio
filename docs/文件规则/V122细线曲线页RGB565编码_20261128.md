# V122 曲线页的细线与 RGB565 编码

原厂保存后的曲线对象可以由多条独立线段构成。原件 `870b51a7…` 包含从 (100,150) 到 (200,50)、再从 (200,50) 到 (300,150) 的两段黑线。源工程为 3470 字节。此前 Lite 与原厂的页帧有 597 个像素不同。本轮用同一工程重新独立编译，整幅 800×480 页帧及对应压缩文件均通过字节对照。

## 从工程坐标到页帧

1. 受控图元的线宽为 1 像素、线型为实线、颜色为不透明黑色，`endCap` 和 `endArrow` 都为 0。每一对端点作为独立的平端线段绘制。两段相交处依照源文件顺序合成两次。
2. 将中心线沿法线向两侧各偏移半个像素，得到四角。对于斜线，按 Y 从上到下分别扫描左右两条边。每条边从首个相交行开始累加横坐标，横坐标、斜率、反斜率与像素内的边交点用 16.16 定点数表示。
3. 取像素单元落在线带内的面积。一个完整像素的面积值为 65536。截取三角形、梯形时，面积乘法在定点网格上取整。将面积乘 255 并除以 65536，向下取整得到覆盖度。水平和垂直的整数端点线段分别覆盖中心线上下或左右半格，每侧覆盖度为 127。
4. 对斜线，二进制浮点精度影响转换成 16.16 的最后一位。原厂绘图库在 x87 的 64 位有效数字模式运行。推导斜率时顶角 Y 仍使用扩展精度，左右角参与减法的 X 和左角 Y 已暂存为 binary64。独立实现明确保留该精度顺序。用相同的原厂绘图库将 x87 改为 53 位有效数字，冻结工程的右斜线末端有 8 个像素改变。
5. 在 RGB32 内对当前下层颜色执行黑色覆盖混合。色道乘积 `v = 原值 × (255 − 覆盖度)`，结果为 `(v + (v >> 8) + 128) >> 8`。默认页底使用原始 RGB (197, 222, 255)。逐段叠加后，取 R、G、B 的高 5、6、5 位，按小端序写出 RGB565，再从整幅页帧生成 `SheetPixel.dat`。直接向 16 位画布绘制会过早丢失颜色低位。

## 适用范围

本组字节结论覆盖单页内、有一像素边界余量、默认黑色实线与整数端点。贝塞尔段、小数端点、彩色或虚线、不同线帽和画布边界裁剪仍走通用绘制路径。具有相同 RGB565 值的自定义底色可能在首次降色时丢失不同的 RGB32 低位，此类重叠画面的逐字节结果仍需独立原件核验。
