## 字距怎样进入页图

Windows 上的简单拉丁字形采用原厂 Qt 4 使用的 TrueType 水平字偶距表。24 像素的微软雅黑在本机 GDI 上测得完整字格高 31。比例分母为字体每 em 单位数乘 64 后整除字格高。每对相邻字形先按这个分母把设计字距换成带六位小数的定点值，再按 Qt 的像素舍入规则与当前字形前进量累加。居中和右对齐都使用这次计算的行宽。最后按 RGB565 量化，再压缩整页。

已对照的路径使用单一字体和水平字距表。遇到字体回退、连字、双向文字、自适应或专用文字样式时，Lite 使用通用排版。这些情况还需要相应原厂样本。[绘制实现](../../src/native_text_kerning.cpp.inc)

## 动态文字的渐变和单字形

双语控件需要生成独立状态图。对不透明的水平渐变，Qt 4 把 1,024 个调色板位置映射到控件宽度。宽度为 W 时，第一个像素的 24.8 定点采样坐标为 floor(1023 × 128 / W)，步长为 floor(1023 × 256 / W)。每列的调色板序号由采样坐标加 128 后右移 8 位得出。首末色的权重为 0 和 256，中间序号 i 的背景色权重为 floor((2i + 5) / 8)。前景、背景按各通道混合后截断到 RGB565。

含单个拉丁字形的行也需要 GDI 的上升部和完整字格高度，否则字形纵向位置可能差一个像素。冻结的干净 Git 源及保留本机编辑器改动的发布构建均用原厂压缩帧复验了这两项。两份双语叠放样例各有两个下层帧及两个上层帧。[单字、叠放、工作缓冲与反例](V122双语静态文本叠放与独立帧_20261128.md)
