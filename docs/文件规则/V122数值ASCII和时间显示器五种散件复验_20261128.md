# V122 数值、ASCII 与时间显示器的页面、图帧和地址文件

Lite 可以从单个本地数值显示器、ASCII 显示器或时间显示器的 SM/KSP 生成五种原厂格式散件。原厂 V5.1 的六份不同 SM、十二次编译均有完整散件可核对。60 次整文件比较全部逐字节相同。原始设备工程使用 AMT070W124-L800X480R；对 RGB565 页图和帧的解码复验使用 AMZ070W01 原固件的 ARM 指令。[逐文件摘要、字段与负例回执](样例/V122数值ASCII和时间显示器五种散件复验_20261128.json)

```powershell
.\KinSealStudioLite.exe --compile-native-value-display-parts 工程.sm 新散件目录
```

该入口支持默认背景的 800×480 单一普通页 000、一个完全位于屏内的整数坐标控件，以及不透明纯色背景。数值和 ASCII 的地址限本地 LW。源工程中未映射到编辑器的显示属性、连接和页面样式均参与检查。Lite 工程可直接修改控件尺寸、背景色及页名。数值控件还可修改高限和低限两张帧的颜色。命令在目标卷暂存并一次性发布整组散件；目标目录已存在或素材超出范围时，已有内容保持原样。[散件生成代码](../../src/native_value_display_payload.cpp.inc)

## 五种散件的编码

| 散件 | 独立生成规则 | 六份原厂源的实测尺寸 |
| --- | --- | ---: |
| `SheetPixel.dat` | 建立 800×480 的小端 RGB565 页图，顶行和最左列为黑色，其余 382,721 个像素为 `C6FF`。本组动态显示器的文字和底色均由设备运行时合成。使用项目自有 LZO1X 编码器压缩 | 3,655 B |
| `ControlPixel.dat` | 每张图以控件宽×高生成同色 RGB565，单独压缩并按 32 B 对齐。数值依次写常态、高限、低限，ASCII 与时间各写常态一张。用与原厂相同的已核工作缓冲规则补齐帧尾 | 数值 576 B，另两类 192 B |
| `PicLenPara.dat` | 包含三组 200 页的 LE32 数组。页 0 的有效槽位在 0、800、1600，分别写压缩页图长度、图帧总对齐长度、图帧数。2,400 起每帧写三个 LE32，分别为 0、对齐长、实际压缩长 | 数值 2,436 B，另两类 2,412 B |
| `AddrPara.dat` | 本组所有活动读写与监视使用 HMI 本地地址，200 页地址表全零 | 200 B |
| `SheetPara.dat` | 生成一份普通页记录，控件数 1。在偏移 7 写本机代码页编码的 40 字节页名槽，48/50 写宽高，56 写源刷新值，60–67 填四个未启用动作索引 `FFFF`，68 写控件所有图帧的解压总字节数 | 72 B |

默认控件均为 200×100。每张图压缩前 40,000 B，压缩后 185 B，对齐后 192 B。两个字号和两种语言配置下的背景帧相同。数值三帧色值分别为 `A51F`、`07FF`、`F800`。这些值来自对属性颜色进行 RGB565 量化；原厂图像只参与结果对照。页表的偏移 59 在本次十二个原件中均为零，其他工程已有非零反例。[普通页参数字段](V122普通画面SheetPara编码与对齐字节_20261128.md) · [先前的数值固件对照](../控件功能逻辑--固件/显示与交互控件/数值显示.md)

## 修改后重算与固件复验

三类控件分别改为 133×61，修改纯色背景、字号及中文页名。数值控件同时修改高限、低限颜色。在带原生快照的 KSP 及从同一模型移除快照后的 KSP 中，六次生成的每张图均由 AMZ070W01 固件的解码函数 `0x800AB414` 完整解压，逐像素核对颜色，另核对帧索引、页名和解压总长度。还分别把三类控件的背景色、尺寸、字号和页名改动写回 SM，从保存的 SM 重开执行同样核验。数值高低限颜色的 KSP 改动和这项 SM 回写分别测试。透明度改为 128、原 SM 保留字段被改成未知组合、目标已有同名目录，共九个负例均拒绝。[离屏与固件专项脚本](../../tests/verify_native_value_display_parts.py)

## 640 字节 ControlPara 的已知字段与历史差异

该入口生成的五件覆盖页面与图像。完整可执行控件仍需 `ControlPara.dat`。专项脚本从当前导入模型计算下列字段，比较十二份原件，合计 704 个字段字节全部相同。每条数值记录的比较覆盖 89 B，ASCII 覆盖 47 B，时间覆盖 40 B。

| 控件 | 覆盖的设备字段，偏移为十六进制 |
| --- | --- |
| 公用 | `00` 类型。三个原厂类型依次为 `0C/10/11`；`04–0B` 几何；`0C–13` 本页未压缩的前置图帧长度与当前控件的总解压长度 |
| 数值 | `11E` 私有几何，`128` 字号索引，`12A/12C/12E` 总位数、小数位、数值类型，`138/13C/140/144` 字色、底色、高限色、低限色，`148/150` 双精度增益和偏移，`168/170` 输入上/下限，`178/250` 两个本地地址描述符的空间、类型字节与数值地址 |
| ASCII | `11C` 私有几何，`128` 字号索引，`12A` 字符数，`130/134` 字色和底色，`138/1A4` 的两个本地地址描述符的空间、类型字节及数值地址 |
| 时间 | `108/109/10A` 日期、时间、星期三个显示开关，`10E` 私有几何，`118` 字号索引，`11A/11C` 日期和时间格式，`120/124` 字色及底色 |

原厂默认 SM 对每类控件均有三次编译归档，输入 SM 逐字节相同。以首次记录为参照，另两次的完整 `ControlPara.dat` 有以下差异。每对不同的具体偏移和每份原件的摘要保存在回执。

| 同一默认 SM | 第二次与首次有差异的字节 | 第三次与首次有差异的字节 |
| --- | ---: | ---: |
| 数值 | 47 | 53 |
| ASCII | 84 | 82 |
| 时间 | 111 | 134 |

这些反例表明，仅提供 SM 无法指定三份历史控制记录中的哪一份。精确重放其中一次需要对应的原厂编译会话状态。独立设备编译还需确认哪些残留位置由固件忽略，以及输入、键盘、字库、条件显现和权限分支所消费的字段。完整工程入口继续给出控件设备编码诊断。本轮没有写屏，现场读值、编辑、键盘与 RTC 效果仍待实机核验。[时间控件固件路径](../控件功能逻辑--固件/显示与交互控件/时间显示.md) · [ASCII 控件固件路径](../控件功能逻辑--固件/显示与交互控件/ASCII显示.md)
