# V122 指示灯的矢量图、文字与设备图像

冻结的 11 个原厂单灯工程共 38 帧、291,600 个 RGB565 像素。修复前 56,671 个像素与原厂不同。两个设备编译入口都复现了 37 帧，以及 11 份完整的 `PicLenPara.dat` 和 10 份完整的 `ControlPixel.dat`。同一份工程的两个入口分别计验，以上分母只计一次。[逐工程原件与输出 SHA-256](样例/单灯渐变与固件原厂逐帧复验_20261128.json)

## 从原厂图元到状态帧

1. 在当前活动的状态中取原工程的图片、文字、语种和闪烁设置。两份原厂默认图片 `switch_ON.kvg` 和 `switch_OFF.kvg` 是 SVG 矢量图。现有资源的完整字节可以分别在 V5.1 原厂 EXE 的文件位置 `0xCA32F1` 和 `0xC8D1BB` 核对。位于资源库的同一张图片也按相同规则处理。
2. 对这两张图的拉伸模式，读取自身的 `viewBox`、矩形、顶点和渐变。先把顶点投影到当前设备图像尺寸，再按 1/64 像素网格截取。量化两端后再算矩形的宽高。冻结的 120 × 60 样例要求四条外缘取整数网格线之前的一个子像素，边缘仍由画面背景参与合成。
3. 从 SVG 保存的渐变色标生成 1,024 项色表，第 `i` 项在 `(i+0.5)/1024` 取样。位置介于两项色标之间时，把相对距离换算成四舍五入的 0 到 256 整数权重。每个 RGB 通道按加权和右移 8 位取整。首项、末项和色标范围外采用相应的端点颜色。适用的两份原厂矢量均为多色标、不透明渐变。
4. 将图案绘制到透明的预乘 RGBA 图层，然后按控件透明度铺到 32 位底图上，再绘制当帧文字、上层静态文本，最后转换为 RGB565。直接向 16 位表面绘制渐变会提前舍去颜色精度。直接对不透明底色画渐变也不能重现半透明边缘的舍入次序。
5. 两种状态的独立字体对照覆盖 16 像素宋体的 ON、OFF，以及 16 像素微软雅黑的 STATE 2。支持 GDI 字偶距的文本使用已有的原厂字体布局路径，为无字偶调整的多字符标签保留原按钮的基线。闪烁隐藏帧先清除本状态的文本，再使用相同的绘图、压缩和封装流程。
6. 每个状态帧仍按 RGB565 行顺序独立压缩。底图及之前状态在原厂压缩缓冲区中留下的尾部字节也属于整文件比较内容。[索引与 32 字节补齐规则](ControlPixel控件帧的32字节补齐_20261128.md)

## 原厂与设备读取的独立复验

编译源和参考图像都来自 Git 对象 `e3b72657` 中同一次原厂运行的封存目录。测试把相同的原厂 SM 分别交给 USB 散件入口和介质散件入口，比较完整图像与索引。另将每帧的有效压缩区交给封存的 AMZ070W01 固件解码例程，核对独立的 RGB565 输出和返回长度。固件 SHA-256 为 `7f625b7a967c1ecc0ff5db1fba4d6ed68cb1d9474216e87009395f1d53a88db5`。[复验脚本](../../tests/verify_native_lamp_artwork.py)

| 原厂工程 | 帧相同 | 整份图像 | 整份索引 |
| --- | ---: | ---: | ---: |
| 10 份 120 × 60 双态、多态、闪烁及字位指示灯 | 33/33 | 10/10 | 10/10 |
| 180 × 60 五状态共享文本指示灯 | 4/5 | 0/1 | 1/1 |

180 × 60 工程的第一个状态仍有两处边缘像素差异，局部坐标为 `(177,1)` 和 `(179,59)`，其余四帧整帧一致。两点都位于默认熄灯图的右边。该样例的帧索引和实际压缩总长度相同。独立查看四条外缘各自落到哪一格后，发现仅放宽右边缘可以消去这两点，同一设置会改变此前已全等的另外十份工程。原厂 `MainWindow::RenderWidget`（入口 `0x0048A830`）先为控件组调用 `sceneBoundingRect`，用整数大小建立图像，再在 `0x0048AC41` 调用 `QGraphicsScene::render`。额外用原装 Qt 4.6.3 的 SVG 项在独立场景中依次改变缓存模式、缩放与浮点边界，观察到边缘随着场景变换发生改变。现有 180 × 60 工程只找到一份完全相同的封存源，需要独立保存的同尺寸重开样例和额外尺寸、位置的原厂产物来确认通用坐标规则。

保留本机编辑历史的 EXE 和由干净源码构建的 EXE 分别跑过完整的 11 份双入口回归。两次得到的 22 组图像、索引哈希和固件解码计数全部相同。原厂 Qt 仅用于离屏对照，Lite 的设备编译使用本工程的矢量资源、Qt 6 和 Windows 字体。此次未执行实屏下载。
