# V122 启动图与普通画布互通

原厂的《ASCII显示元件》《与PLC时间同步》和《写时间到PLC》现在可在普通画布中打开、修改并保存。每份工程各含一张普通画面和一张独立的图片启动画面。改变普通画面的控件后，三份文件的启动图和启动页均保留原始字节。

## 启动页与资源

这三份工程的 `system.tail.0` 启用启动页。`system.194` 的唯一记录依次存入资源 ID、文件名、格式名、原图宽度、高度和 Qt QByteArray。资源 ID 同时出现在 `system.tail.1` 和 `startup.head.8`，图片大小为 800×480。数据区以标准 PNG 文件头开始。另一个实样《HMI保护》在相同位置保存 JPG，普通多页编辑仍有其他限制。

Lite 检查页数、启动页的长宽、背景方式、元件数、页级地址记录、三个资源 ID、声明尺寸和实际解码尺寸。满足这些条件的独立启动图跟随源快照原样保存。普通画面的元件块结束于 `startup.head.0`。替换该块后，解析器重新读取完整工程直到文件结束。

## 三类控件字段

| 项目 | 原始样本 | 编辑或投影规则 |
| --- | --- | --- |
| ASCII 尺寸 | 第三个 ASCII 文本预览尺寸为 179.20000000000002×82.4 | 画布的整数几何显示为 179×82。未修改的宽度或高度保留原始双精度数；单独改变某一轴只替换该轴对应的八字节字段 |
| FX3U 连接 | `system.16c[0].header.11` 为 COM1，协议型号、厂家、寄存器类型表以及两组时序字段相互吻合 | Lite 显示 COM1、Mitsubishi_Fx3U、默认站号 0。工程中对应的原厂连接记录保留原值。源地址的长度字段提供不了设备节点号，节点保持未知 |
| 外部数值显示 | 七个对象的监视地址依次为 D6 到 D0，地址私有结构的类型索引为 7，注册表的第 7 项正是 D | Lite 使用 `@com1:D6` 表示。同一接口内改寄存器号时写回私有地址全名、其编号、控件显示地址副本和文本预览。原生预览只显示 `D6`，私有文本使用 `[Mitsubishi_Fx3U]D6` |
| 日期和时间 | 私有标志 10、11、12 为 1、1、0；格式串和文本预览都为 `YYYY/MM/DD HH:MM:SS` | 画布同时启用日期和时间、关闭星期。日期、时间格式在各自的编辑器选项表中精确匹配 |

## 整文件对照

对照使用独立的 Python 大端浮点和 UTF-16BE 字符串编码，将请求的字段替换到原厂输入中作为预期输出。三份工程都先通过“原厂 SM → 普通画布 KSP → SM”的原样比较，再编辑、重开和再次保存。

| 工程 | 操作 | 整文件检查 |
| --- | --- | --- |
| ASCII显示元件.sm | 第三个 ASCII 控件的宽度改为 196 | 只替换一个八字节宽度，82.4 的原高度保持相同 |
| 与PLC时间同步.sm | 第一个外部数值显示的 D6 改成 D27 | 只替换四个已定位的 QString；其余普通元件、地址、启动页和图片均相同 |
| 写时间到PLC.sm | 同样将 D6 改为 D27 | 该工程也与独立构造的预期结果逐字节相同 |

这三次修改仅涉及源工程。原厂编辑器重新打开、设备编译产物对比及 PLC 实际通讯仍须独立验收。包含非空启动页元件、多普通页、旧版 V113 或其他未映射元件的工程继续按对应结构能力处理。[机器回执](样例/V122启动图普通画布实样复核_20261128.json) · [复验脚本](../../tests/verify_native_startup_canvas.py)
