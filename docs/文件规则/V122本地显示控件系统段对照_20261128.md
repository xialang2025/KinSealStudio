## 系统段逐字节核对

十份原厂 `SysPara.dat` 均为 4,998 字节。分别比对同配置的原厂表格，整文件差 122 至 158 字节。此前以 278 对相同 SM 的重复编译记录独立确定了 172 个发生变化的位置，另有完整 28 字节的本地时钟区。上述差异全部落在这 200 个位置中。其余 4,798 个位置，包括首 100 字节选项以及第 1,152 字节起的后半部分，十份均逐字节全等。设备的两组系统 I/O 行分别从偏移 352 与 752 起算。[同源编译可变位置](SysPara系统参数与编译时钟逐字节复核_20261128.md) · [AMZ 固件读取依据](AMZ固件与V122系统页地址和静态表格编译_20261128.md)

## 编译器如何判定本地设备配置

原有单一普通页、工程宏、宏调度和源系统配置检查继续生效。新增分支要求恰好一个控件，使用上述完整配置之一且通知、触控条件关闭。六个公用地址及下表列出的每个专有地址均检查连接号为 0、设备名为空、本地 LB/LW 类型和十进制寄存器编号一致，范围为 0–65535。隐藏的输入、限值和备用地址也计入检查。[配置判断](../../src/native_system_settings.cpp.inc)

| 原厂类型 | 私有地址字段 | 本轮检查的其他条件 |
| --- | --- | --- |
| 12，数值显示 | `display.17/23/24/28/35/36/56` | 输入宏关闭 |
| 16，ASCII 显示 | `display.13/15/21/40` | 输入宏关闭 |
| 17，时间显示 | V122 私有段没有地址记录 | 显现及触控条件关闭 |
| 35，消息显示 | `private.head.3` | 支持关闭显现及实测组合，即显现掩码 5、位状态 1、等级原始值 2 |

普通设备工程和离线散件两个入口合计验证 20 次。两者对十个原件均越过系统检查，随后提示控件类型尚待设备编码。旧版的十条系统配置拒绝来自同源 SHA 和同原厂目录的 248 工程基准回执。另做 14 个负例，分别覆盖外部连接、未恢复的配置变化、具名但不存在的输入宏、通知、触控和未经核实的显现组合。每次拒绝后均检查输出目录中没有半成品。两种候选构建均通过上述专项；本轮没有实屏操作。[专项脚本](../../tests/verify_native_local_display_profiles.py)

复验时从项目目录执行。脚本从 Git 版本 `e3b72657` 读取独立的原厂源与设备文件，用临时目录逐例运行，再自动清理。若带有先前全量差分 JSON，可以追加 `--baseline-receipt` 与路径，核验其源身份和原先的配置拒绝诊断。

```powershell
py -3 -B tests/verify_native_local_display_profiles.py build/amz070w01r/KinSealStudioLite.exe
```
