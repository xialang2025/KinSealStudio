# 阶段11逐项进度

本批按六项主任务推进，交付 **0.11.0 受限便携验证版**。版本、依赖盘点、白名单打包和离线帮助已经实现；最终包实际验证与发布身份见[部署验收](阶段11部署帮助与发布验收.md)及[机器进度](stage11-evidence/progress.json)。完整复刻、公开发行和安装器均未声明完成。

| 任务 | 本批完成范围 | 仍需完成的范围 |
|---|---|---|
| S11-01 版本和声明 | CMake、运行时和 Windows PE 版本统一为0.11.0；独立源码构建，源/资源、程序、帮助、样例和包文件分别冻结；保留历史版本。 | 全阶段能力仍按现有守卫限定；固件/唯一设备号及阶段10剩余观察未知，不能扩成完整支持认证。 |
| S11-02 依赖和许可 | 17组组件、22个运行库及64份许可文本逐项记录；包不附SDK、驱动、系统字体或原厂可执行程序；内嵌资源来源单列。 | 内嵌原厂资源权利依据、Qt对应源码与SBOM关系、D3D/Mesa适用条款；真实缺驱动/缺字体目标环境待验。 |
| S11-03 可重复打包 | 新建用户包白名单和逐字校验工具，拒绝覆盖旧目录；固定7份代表样例；最终包及重复包实际结果另存。 | 标准账户、真实只读安装权限、长路径、DPI/多显示器及独立干净Windows尚未全部验证；进程PATH隔离不能替代这些环境。 |
| S11-04 安装与升级 | 明确本版只提供便携目录，安装器/快捷方式/关联/驱动安装/自动升级与卸载均未提供；操作和恢复说明已写入用户说明。 | 如后续提供安装器，需另核原生行为、迁移/旧schema拒绝及专用沙盒卸载；不以便携通过关闭此范围。 |
| S11-05 本地帮助 | 8章用户帮助、128条显式命令路由、39条有限上下文；主菜单真实帮助入口、F1和WhatsThis、损坏/缺失提示与本地资源边界；最终29项Qt测试通过。 | 部分原有属性“帮助”按钮仍是简短提示；全右键/双击/嵌套字段/错误入口尚未逐项对账，不能声称全D/U闭环。 |
| S11-06 发布交付 | 实际构建/测试/包检查、只读复核、详细UI规则、协议边界、未完成台账与安全发布工具；Git提交/推送以回执为准。 | 上述环境/许可/全帮助与现场欠项仍开放；无签名、正式公开发行资格或完整设备验收。 |

本批不改设备编码、USB字节和下载引擎，没有新增控件，也没有操作USB或PLC。阶段10屏幕续测起点仍为 `S10-FUNC-LOCAL-1114`；语言/通知组合观察和第二次宏14恢复尚未执行。旧下载/现场结果只引用其原程序身份。
