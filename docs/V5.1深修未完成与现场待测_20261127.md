# V5.1 本轮未完成与现场待测清单

2026 年 11 月 27 日。目标屏为 AMZ070W01R，历史实测固件版本为 `122-2026.03.04`。按用户要求，手动触控、观察、断电和接线本轮暂缓。专用屏最后一次下载的是 `AMZ25-08 SCHEDULE`。

## 需要人在现场的项目

| 项目 | 已有证据 | 将来可用于判定的操作和结果 |
|---|---|---|
| 初始化宏 | 第八页已完成 USB 下载、提交与重启 | 同一页先清零 LB10，通电保持 0，再断电重启，读取是否回到 1。仅开机看到 1 无法区分之前普通宏留下的值。 |
| 全局宏 | 同页具备触发位 LB12 和独立观察位 LB11 | 关闭 LB12 并清零 LB11，约 5 秒仍为 0。打开 LB12 后观察 LB11 变 1。再次关闭并清零，确认保持 0。 |
| 外部 PLC 与触摸屏 | PC 软件从站验证了单站 RTU 的请求、应答、读回、异常及断开过程；历史屏幕按键页使用 LB/LW | 独立串口、站号、波特率及隔离的测试寄存器就绪后，在 HMI 和 PLC 两侧分别读值。验证线路、字序、超时与拔插恢复。 |
| 控件实屏显示及触控 | 七张历史测试页有现场反馈。QA 程序另验证 PC 模拟能力和设备包 | 对应设备编译器可生成的字段组合逐个下载。带权限、滚动、透明覆盖、不同字体、计时阈值及移出手势各取独立结果；二维码还需用另一设备实际扫码。 |
| 第 4 页文字基线 | 本轮第 4 页有两帧操作提示下移 1 像素，已用新旧渲染器分别重现 | 用原厂编译同文、同字号和同尺寸的文字，与解压图帧比较；新版屏显列入下次现场核验。[像素和输入](AMZ070W01R八页实物复验_20261125.md#2026-年-11-月-27-日第-4-页文字像素复核) |
| 值保持、上载和故障恢复 | 已核正常工程下载路径和软件模拟传输异常 | 可恢复专用工程与外部观察值就绪后，记录中断前后寄存器、历史及 RTC；原厂可编辑项目上载需核对提取后重开。 |
| 安装环境、介质、其他固件 | 本机现有 Qt 与 USB 环境可运行 | USB 驱动安装/卸载、介质启动、其他型号及长期运行仍需独立工况。固件升级按用户原范围暂缓。 |

历史八页的型号、包和现场答复见[实物复验](AMZ070W01R八页实物复验_20261125.md)。本轮重新编译的包与当时实际发往设备的包分别记账。

## 仍需开发或原版取证的功能

| 项目 | 缺少的实现或证据 |
|---|---|
| AMZ 原厂 SM 导出 | AMZ 模型的 KSP 保存、设备包和标准 SM 可编辑导出是不同入口。原版 AMZ 源的字段映射、原版重开与异构工程往返尚未完整。 |
| 独立设备编译 | 位、字、指示灯、功能按钮和静态文字已有受限编码。其他显示/输入控件、大部分活动配置、多页、子窗口、自定义键盘仍有设备记录、索引、地址和生命周期缺口。各个样例实际的首次拒绝原因见[本轮逐项报告](V5.1逐项深修与软件模拟复核_20261127.md)。 |
| 静态图形样式 | 已核部分普通实线、线宽、填充和半径；虚线、部分粗线、渐变、非默认圆角和其他超出参考样本的组合仍单独受限。 |
| 二维码设备生成 | 六份原厂样本可对照控制记录、长度和编码选项。缺不同基址、显现条件与动态字串的受控差分，还需用 Lite 包核对设备独立刷新与扫码。 |
| PC 模拟 | 图片定时换帧及静态闪烁、消息走马灯、输入型数值控件的键盘、滚动/历史/配方、跨页与窗口运行、任意宏的 PC 调度等仍有独立缺口。 |
| 其他 PLC 能力 | 139 份协议配置已经比对；尚有 35 个地址族缺原厂实测。单站标准 RTU 以外的私有协议、多站、外部点动、通知、加减与绕回等需分别验证。寄存器位读改写跨两次 RTU 事务，其他写入方在两帧间改变同一字的工况需专门验证。[协议和地址族清单](阶段9_PLC地址模板与通信实现.md) |
| 原厂桌面工作流 | 原厂上载数据、安装 USB 驱动、升级和升级底层仍有占位或暂缓。宏变量/导入导出、宏编辑器多草稿的原厂提交顺序、开机 Logo、资料传输、快捷键冲突优先级等仍有未核行为。各入口的绑定情况见[桌面矩阵](V5.1原厂桌面入口逐项矩阵_20261125.md)。 |
| 视觉与发布 | 各窗口同 DPI、主题、原版 Qt 下的逐像素和全部错误路径，独立干净 Windows 安装及性能验收仍待补齐。 |

历史独立问题保留原编号，见[未完成任务总台账](../design_plan/未完成任务总台账.md)和[上一轮未闭合清单](V5.1深度排查未闭合_20261125.md)。
