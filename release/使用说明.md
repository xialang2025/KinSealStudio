# KinSealStudio Lite 0.11.0 受限验证版

启动本目录的 KinSealStudioLite.exe，按 F1 或选择“帮助 → 帮助”打开本地用户手册。手册位于 help 文件夹，支持离线阅读；保持程序、DLL、插件和 help 的相对位置。普通编辑不要求安装 Qt、MinGW 或原厂软件，包内有运行库。

本包用于已有授权环境内的验证。内嵌原厂资源等分发依据仍待核，不能据此认定已具备公开再发行条件。许可证与组件来源见 licenses 文件夹和 release/stage11-dependencies.json。没有安装器，不修改系统PATH、文件关联、USB驱动或独立SDK；升级请放到新目录，保留旧包和用户工程。

先用 samples 的基础单页工程练习编辑和另存。当前设备编译限已恢复的AMT070W124-L800X480R、单普通页及默认Modbus连接组合；界面能编辑的控件和配置不都能编译。静态文字、位/字按钮、指示灯、功能按钮及受限静态背景的具体范围见本地帮助。多页、窗口、活动工程配置和未恢复组合会明确拒绝。

保存.ksp不等于原厂.sm导出；原生导出仅支持已恢复字段。压缩JSON快照不是原厂可编辑上载。上载协议、独立介质包生成和安装卸载流程未完成。新包编译或PC模拟成功不证明触摸屏已显示、触控、宏执行或PLC通信成功。

宏样例需外部有效ARM SDK和许可证，只支持现有普通零地址变量切片；包不附SDK。没有SDK仍可普通编辑。PC离线模拟不执行宏；PC串口工具需用户显式选专用端口并执行，工程画面自动扫描映射未开放，不能默认连接生产PLC。

工程、日志和临时物放到有写权限的位置。避免C盘临时空间不足，可在启动前把TEMP、TMP、TMPDIR及KINSEAL_MACRO_TEMP_ROOT设为有权限的Z盘目录；宏临时目录必须已存在且不得位于SDK内。不覆盖旧包，不把工程存放在计划替换的程序目录中。

字体来自Windows，包不安装字体；缺少请求字体可能发生回退，不能保证像素一致。`--release-info`只读报告版本、Qt和默认字体解析；`--help-catalog`检查本地帮助。Python仅用于可选的 `tools/package_stage11.py verify --package 本目录` 校验工具，启动编辑器不需要Python。

阶段10在场端点的局部结果继续保留原程序身份：位四操作、字选定状态、LB41显隐和出现后触控已观察；完整语言/通知、唯一硬件与固件、运行值保持、原生上载、真实PLC及长期运行未闭合。切勿把本次帮助和打包版本当作新设备T/E通过。当前测试屏的功能页剩余观察及第二次宏14恢复仍待执行。
