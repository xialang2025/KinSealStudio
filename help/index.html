本地手册适用于 KinSealStudio Lite 0.11.0 便携版。帮助可离线使用，不需要安装原厂软件或打开浏览器。

  1. 新建工程并确认型号、分辨率与连接。
  2. 新建或切换画面，放置控件，设置地址、文本和外观。
  3. 先保存 .ksp，再按当前支持范围导出原厂源工程或编译设备包。
  4. 下载后检查屏幕标识和实际触控。保存编译、传输和观察结果。

菜单中仍有范围提示入口。能编辑或保存某个控件，不代表该控件所有运行功能已经在实物上验证。

F1 打开当前窗口的有限上下文帮助；无法识别的窗口回到目录。原有部分“帮助”按钮仍显示该控件的简要说明。新帮助未覆盖所有右键、双击、嵌套字段和错误入口。

安装器、升级和卸载流程本版未提供；请保留完整便携目录。已有 USB 驱动和宏 SDK 为外部依赖，包内不自动安装它们。
