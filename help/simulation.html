离线模拟

“离线模拟”基于当前编辑内容建立独立快照。当前有限支持单个800×480普通画面、内部LB/LW和已支持基础控件及指定系统功能。点击操作、数值输入和内部地址观察只发生在模拟会话；关闭后运行值不保存回工程。

多页、外部地址、活动采集/报警/历史/配方及未核时序在启动前拒绝。宏不执行。PC首帧和操作测试不能替代真实触摸屏执行。

在线模拟

在工程的「设置 → 连接」配置 Modbus RTU、从站号和电脑的在线模拟端口。把控件绑定到该 PLC 连接。打开要模拟的 800×480 普通画面，点「工具 → 在线模拟」，选择电脑串口后点「连接 PLC」。

状态栏显示连接、读值及写入确认。支持基础位按钮、字按钮、指示灯、静态文本和只读数值显示。点击外部写入控件会发送 PLC 请求。画面值由 PLC 读回应答更新。在线运行使用工程快照，关闭后运行数据不保存回工程。

当前支持单站串口 Modbus RTU。0x 线圈、1x 离散输入、3x 输入寄存器、4x 保持寄存器可读取，另支持对应的寄存器位和双字监视。写入支持 0x 和 4x。外部点动以及还未接入的控件、配置和协议会在启动时提示。发生通讯错误后，核对连接与 PLC 状态，再点击「连接 PLC」。

PC 串口诊断

「工具 → 兼容工具 → PLC 串口诊断」用于手动执行单个 Modbus RTU 请求。选定电脑串口、参数、站号和功能后，以从 0 开始的 PDU 地址执行。PLC 实测使用可控从站和独立读回。
