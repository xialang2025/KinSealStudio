保存工程

日常编辑保存为 .ksp。当前程序接受 schema 1～12，写入版本随实际使用字段选择，不能手改版本号绕过未知字段检查。新字段可能使旧程序拒绝打开；升级前保留原文件并另存新副本。

多页、语言、连接、资源和宏等按工程模型保存；运行模拟中的数值不会自动写回工程。设备运行值保持与断电保持尚未闭合验收。

原厂 .sm 与设备文件

受支持的原厂 .sm 可导入编辑；“导出原厂工程”写原厂源格式的受支持范围。未知结构保留策略或拒绝提示以实际导入结果为准，不能把可打开的未知快照当作全部语义已经解析。

.ksp、原厂 .sm 和设备编译产物不是同一种文件。Lite JSON 快照不能改扩展名冒充原厂源工程。.kns 等设备文件按编译和传输入口使用。

修改宏源码后，原厂导出工程会按规则标记相关缓存未编译；应重新编译，不能把旧机器码与新源码混用。导出失败保留原 .ksp，不覆盖已知成功包。
