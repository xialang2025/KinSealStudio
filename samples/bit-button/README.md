# 位按钮样例（0.4）

这些`.ksp`工程可编辑、保存并离线设备编译。内部LB/LW样例可通过正式“下载工程”入口传输；实物运行结果需现场核对。下载会覆盖当前测试画面。

- 默认交替位按钮：LB0，交替，OFF/ON两态。
- 字地址监视与按压时间：点动，独立监视LW32第7位，按压时间50×100毫秒。
- 四种操作配置：四个按钮分别为置位、复位、点动、交替。
- 四操作实机验收：已传输测试屏的工程副本，交替LB0、置位/复位LB1、点动LB2，附四个标题；实际按下/松开和灯状态仍待确认。
- 双语位按钮：中文/English各保存STOP/RUN译文，设备图片按已保存语言顺序输出。
- Modbus-COM1：默认Modbus RTU COM1、站号1/节点1，交替外部0x0。仅作离线编译示例；使用前应确认实际PLC及通信环境。
- 图库PNG与SVG验证：0.4.1新增图库入口验证，OFF使用原生800×480启动背景PNG，ON使用原生空调SVG；可在编辑器模拟两态并离线编译，未向实物屏写入。

右键“模拟状态”只切换编辑外观。宏样例需完整ARM SDK；其它PLC驱动参数、动态控件重叠及未恢复的活动字段会在打开USB前拒绝。完整边界见部署包`docs/位按钮设备编译实现.md`。
