# 字按钮样例

这些工程使用 `.ksp` 版本6，适用于字按钮版。地址均为屏内 LW/LB，不需要外部PLC。

| 工程 | 用途 |
| --- | --- |
| 七种操作实机验收.ksp | 设置常数、数值输入、密码输入、加、减、递增绕回、递减绕回；各按钮使用独立LW地址，开启按下效果 |
| 七种数据类型.ksp | U16/U32/I16/I32/BCD16/BCD32/FLOAT，各自写入有代表性的常数 |
| 七操作七类型矩阵.ksp | 49种操作与数据类型组合，用于离线编译及原厂源工程往返检查 |
| 双语按下效果与闪烁.ksp | 中文/English两语言、常态/按下态及按下态文字闪烁；浮点输入保留两位小数 |
| 通知权限与按压时间.ksp | 首按钮按压1秒后置LB10，第二按钮通知LW200=7，第三按钮由LB10控制触控、LW200控制显现 |
| 字按钮宏绑定.ksp | 字按钮调用宏SetLocalBit10；编译此例需要设置真实ARM SDK路径，宏源码随工程保存 |

数值输入和密码输入调用屏端键盘；密码输入不提供小数位。画布“模拟状态”只预览外观，不会读写寄存器。USB传输结果与现场触控验收分别记录在字按钮验收文档中。
