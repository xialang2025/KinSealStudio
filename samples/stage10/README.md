# 阶段10内部地址验收样例

这些输入复用已实现控件和设备编码，无外PLC/活动系统配置；需在仓库内使用已发布阶段9程序及其既有能力门禁。每份源和实际契约SHA在 `docs/stage10-evidence/` 保存，不能以同名样例代替身份核对。

| 工程 | 刺激与独立观察 | 结果边界 |
|---|---|---|
| bit-lamp-local.ksp | LB0交替两次；LB1 SET/RESET；LB2 HOLD；3个同址独立灯 | 用户逐项确认，无宽度提示；移出/失捕获等未测 |
| word-lamp-local.ksp | LW20 U16常数0/1/4与五态灯；LW30 U32常数0/3与五态灯 | 用户逐项确认；不是完整数值读回/高字/字序或32态通过 |
| function-local.ksp | 中文/English语言切换、独立双语文本；LB41显现、LB40通知各有独立复位和观察 | LB41显现/隐藏和出现后触控已确认；两组语言/独立LB40通知余项待答，其他功能/权限/精确时序不继承 |

下载前核对当前页、USB端点及已知测试页恢复材料。首次初始化值不得猜为0，应先执行可见RESET。所有样例的现场执行都要另存真实回执及用户刺激/观察，不能用预览或USB ACK代替。

根目录中 `tools/make_stage10_samples.py` 首次生成前两份输入，`make_stage10_function_sample.py` 生成第三份；已存在文件时拒绝覆盖。`tools/run_stage10_samples.py prepare`在私有桌面调用实际校验/编译/验证/契约/截图，`download --case ... --prepared ...`只下载一个已冻结身份。必须使用未启用优化的Python；脚本显式拒绝 `-O`，避免assert门禁被跳过。

恢复输入为 `samples/stage6/macro-14.ksp`，使用已发布阶段6程序与外部ARM SDK；恢复只表示测试页重新下载及标识确认，不是屏内上载或运行值保持。完整结果与剩余项见 `docs/阶段10现场运行与性能验收.md` 和统一台账。
