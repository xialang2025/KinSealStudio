# 指示灯样例

使用0.6.0指示灯版打开，可修改、保存、导出原厂`.sm`和编译下载。样例目标均为AMT070W124-L800X480R。

| 工程 | 内容 |
| --- | --- |
| 双态位地址.ksp | LB0的OFF/ON监视 |
| 双态字位.ksp | LW10的第7位监视 |
| 多态U16五状态.ksp | LW20的0..4状态 |
| 多态U32三十二状态.ksp | LW30/LW31的0..31状态 |
| 双语多态与显现条件.ksp | 两语言、LB10显现、LW40多态 |
| 指示灯实机联调.ksp | 双态、U16/U32多态及本地按钮激励 |

实机联调中，点“切换LB0”观察双态灯，点“U16加1/归零”观察五状态，点“U32设置为3/归零”观察32位监视。下载回执与现场显示核验分开记录，详见[实现与验收](../../docs/指示灯手册实现与验收.md)。

双语显现样例由LB10控制，LB10=0时隐藏；可另放置一个地址为LB10的交替位按钮检查显隐。选择工程当前语言后保存、重新下载，可核对对应启动语言的状态文字。
