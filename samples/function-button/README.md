# 功能按钮样例

这些工程从新版模型直接新建，未携带原厂源工程快照。普通保存使用 schema8 的 `.ksp`；可通过菜单导出原厂 `.sm`，或直接独立编译、USB下载。

| 样例 | 内容 |
|---|---|
| 18功能与全部类型矩阵 | 60个按钮，18种功能、历史7类、配方13类、报警14类、两种语言、下载2类、键盘10键 |
| 系统功能18项 | 每个功能各一个按钮，便于核对功能顺序与属性回填 |
| 十键与Unicode字符 | 10种键盘键及 A、中、Ω 字符；需要在设备键盘输入场景验收 |
| 双语按下闪烁与无图 | 两种语言、按下效果、闪烁、同文、有图/无图及透明 |
| 权限通知与按压 | LB40通知、LW40通知、按压1秒、等级2触控、LB41显现条件 |
| 功能按钮实机联调 | 12个功能按钮加位按钮/指示灯/显现/按压控件，便于现场核对 |

实机联调：点击“系统设置”时应置通知位LB40，相邻灯用于显示该位；“系统时间”写通知字LW40=123。下方交替位按钮控制LB41，从而控制“LB41显现”按钮是否可见。按压按钮时间为10×100ms。

矩阵中的系统重启、触摸校正、USB/U盘下载方式等按钮会请求相应系统动作，请按要验收的项目操作。无线设置和背光调节按原生编码保留；原厂帮助对其支持有保留或冲突描述，实际设备表现需现场确认。USB传输成功只证明下载链路获应答。

功能按钮的宏指令与原生V5.1一样禁用。按下效果不增加可编辑状态，外观状态固定为0。

“ASCII/Unicode”沿用原厂名称；实际设备字符字段仅为Windows本地代码页的首字节。A、中、Ω用于对照原厂编码，不表示多字节汉字可完整输入到设备。
