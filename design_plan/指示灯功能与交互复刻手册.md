# KinSealStudio V5.1「指示灯」功能与交互复刻手册

版本：2026-11-09。目标是让另一个会话仅凭本手册实现指示灯控件的创建、属性窗口（四个页签，以「指示灯设置」为首页）、画布编辑、预览和权限体系。本文只描述**金玺 KinSealStudio V5.1**；界面证据来自原生程序的隔离桌面运行和随安装程序提供的中文帮助，未使用本项目的复刻版或“参考程序”作为行为依据。姊妹篇《位按钮功能与交互复刻手册.md》（同目录）描述了同一“开关”对话框家族的位按钮类型，两文大量共享实现，请对照阅读。

### 1.1 帮助文档中的定义 [H]

- 定义：位指示灯用来监视所连接设备的**位触点 ON/OFF 状态**，并在触摸屏上以相应的 ON/OFF 状态显示位触点的状态。
- 提示：**指示灯只有监视功能**（帮助原文，无操作/写入功能）。
- 操作路径提示：**“点击指示灯按钮会直接跳转至下图：指示灯设置”**——与 V5.1 实测的“打开即落在指示灯设置页”一致 [V]。
- 帮助属性图（assets/21，旧版界面）显示指示灯设置页分两组：**双态监视**（地址类型 位地址/字地址、与操作地址相同、监视地址、字的位）与**多态监视**（地址类型 字地址、与操作地址相同、监视地址、数据类型、状态组-状态数）；V5.1 实测结构与之一致，仅默认值有差异（见 §4）。帮助通用页旧图含“自动上传”复选框，V5.1 中不存在 [V]。
- 帮助配图中的设备端外观：圆形 OFF 指示灯（assets/23）。这只代表旧版帮助示例，不是 V5.1 编辑器的默认外观。

## 2. 控件家族与入口

指示灯属于“开关”家族。工具箱（右侧“工具栏／控件”面板）第一、二行提供 6 个图标 [V]：

| 图标文字 | 内部对象名 [B] |
|---|---|
| 位按钮 | `btn_switch_bit` |
| 字按钮 | `btn_switch_word` |
| **指示灯** | `btn_switch_Lamp` |
| 功能按钮 | `btn_switch_Fun` |
| 画面按钮 | `btn_switch_Screen` |
| 多态按钮 | `btn_switch_Mstate`（字符串表中为 `btn_switch_MultiState`/`radio_Mstate` 并存） |

**六个入口共享同一个属性对话框框架**（四个页容器 `BitWidget`/`Monitorwidget`/`ExteriorWidget`/`SecurityWidget` 在各类型间复用 [B][V]），只是打开时锁定的类型不同、窗口标题不同。exe 字符串含 `createbitlampbtndlg()`/`createpolylampbtndlg()` 与 "Bit Lamp"/"Poly Lamp" [B]，提示指示灯存在“位指示灯/多态(Poly)指示灯”两种监视形态，对应 V5.1 页面上的“双态监视/多态监视”两组选项 [V]。

从“指示灯”图标打开的窗口标题为**“位指示灯”** [V]（不是帮助旧图中的“开关”，也不是单纯的“指示灯”）。内部对象名 [B]：页容器 `Monitorwidget`、组 `group_bit`/`group_bit` 内 `comboBox_bitAddr`、`spinBox_bitIndex`、`label_2`（“字 的 位”）、`label_5`（“地址类型”）；信号/槽 `setMonitorAddr(int)`、`signalSetCheckSame(int)`、`setMonitorTitle(int)`、`on_group_bit_clicked(bool)`、`on_comboBox_bitAddr_currentIndexChanged(int)`、`slotBitLamp()`/`signalBitLamp()`。

## 3. 用户的完整操作路径

### 3.1 新建控件

1. 打开工程和画面。在右侧工具箱点击“指示灯”图标（内部名 `btn_switch_Lamp`）[V]。
2. 点击后**立即弹出标题“位指示灯”的属性对话框**，初始显示**“指示灯设置”页**（不是通用设置页）[V]（assets/01）；对话框尺寸约 836×616 窗口像素（含自绘标题栏；截图 BMP 里的客户区原点约等于窗口原点 +(8,31)）。这与帮助“点击指示灯按钮会直接跳转至指示灯设置”一致 [H]。
3. 默认内容 [V]（assets/01）：双态监视组勾选、地址类型 `位地址`、监视地址 `LB0`、“与操作地址相同”**不勾选**且地址字段可用、“字 的 位”显示 15（禁用）；多态监视组不勾选（`字地址`/`LW0`/`16位正整数`/状态数 2 全部禁用）；预览为 OFF 方形按钮。
4. 配置监视地址与四个页签。点击“确定”后对话框关闭，鼠标进入画布拖框模式（十字/拖拽绘制）[V]。
5. 在画布上按住左键拖出矩形，松开完成控件绘制；控件默认显示 OFF 状态外观（与位按钮 OFF 外观相同的方形灰面浮雕＋黑色 OFF 文字）[V]（assets/16）。
6. 画布矩形决定控件位置和宽高。

### 3.2 修改现有控件

- 画布上左键**双击**已存在的指示灯，重新弹出“位指示灯”对话框并回填已有值。实测回填：双态监视勾选、位地址、`LB0`、字的位 `0` [V]（assets/17）。**注意**：新建对话框“字 的 位”显示 15，但确定后保存并在重开时回显的是 0（见 §4.3）。
- 重开后仍先落在“指示灯设置”页 [V]。
- 画布右键菜单首项“属性”也可打开同一对话框（实测与双击等价，回填相同）[V]（assets/19）；菜单结构与位按钮一致：属性／控件(K)▶／剪切 Ctrl+X／复制 Ctrl+C／多重复制 Ctrl+P／粘贴 Ctrl+V／删除 Del／全选 Ctrl+A／对齐▶／层次▶／组合▶／图像比例▶／网格／模拟状态▶ [V]（assets/18）。

### 3.3 对话框公共部分

窗口标题“位指示灯”；左上四个页签：**通用设置／指示灯设置／外观设置／权限设置** [V]；右侧独立“预览”框（bmp 约 638,51–809,252，含“预览”标题，白色底，内嵌按钮外观区）[V]；右下“确定／取消／帮助”三按钮（容器 `buttonBox` [B]，窗口内坐标约 (482,565)/(563,565)/(644,565)，各 75×23）[V]。

- **确定**：新建时进入画布拖框阶段；编辑时提交修改并关闭 [V]。
- **取消**：编辑状态下放弃本次改动。实测：双击打开已创建控件 → 把“地址类型”改为“字地址” → “取消” → 再次双击，原值“位地址”保留 [V]（assets/20）。次要残留：取消前进入过“字地址”模式时，重开的对话框中“字 的 位”显示 15 而不是对象存储值 0（对话框状态残留，位地址模式下该字段禁用）[V]。
- **帮助**：按钮存在 [V]；原厂 CHM 有对应页面（`Switch/指示灯.html`、`Switch/functionnodes/Switch-zhishideng.htm`）[H]；两次实测点击后 10 秒内私有桌面未出现任何帮助窗口，点击行为 [待验]。
- **预览**：显示当前“选择状态”的外观：状态 0 显示 OFF 方形按钮；状态 1 显示橙色方形 ON 按钮 [V]（assets/03/04）。多态监视启用时预览未观察到即时变化（仍显示状态 0 外观）[V]。

### 3.4 页签切换实测坐标（自动化复刻用）

页签条 `qt_tabwidget_tabbar` 在窗口 BMP 坐标 (18,41)–(318,61)；四个页签文字（通用设置/指示灯设置/外观设置/权限设置）的中心横坐标约 **53 / 131 / 209 / 281**，点击纵坐标 51 [V]。当前页容器可用枚举识别：通用设置页可见容器名为 **`tab`**（Qt Designer 默认页名），其余三页为 `Monitorwidget`/`ExteriorWidget`/`SecurityWidget` [V][B]。

## 6. “外观设置”页（ExteriorWidget）

## 9. 复刻实现的数据与交互约束

每个指示灯对象至少应保存以下独立状态：

```text
几何：画面 ID，x，y，width，height，层次
类型：switch 家族类型 = 指示灯（通用页单选锁定，不参与序列化差异）
双态监视：启用（默认真）；地址类型（位/字，默认位）；
          与操作地址相同（默认假）；监视地址（默认 LB0/LW0）；字的位（对象存储默认 0）
多态监视：启用（默认假，与双态互斥）；地址类型（字，默认字地址）；
          与操作地址相同（默认假）；监视地址（默认 LW0）；数据类型（16位正整数/32位正整数）；
          状态数（默认 2，最小 2）
通用：宏指令开关；宏索引（位按钮共享实现，指示灯无地址/操作字段）
外观（状态0 与 状态1 各一份，同位按钮）：
        文本；字体；大小；对齐；粗体/斜体/下划线；文本色；文本闪烁；
        图库路径（switch_OFF.kvg / switch_ON.kvg）；终端3D按钮效果；使用透明效果；背景色；透明度
权限（仅显现列，无触控列、无按压时间）：
        显现（位控制:地址+显现状态1/0；等级控制:1–8 默认1；
        字控制:数据类型+字地址+比较符+比较值+误差）
        通知（通知位:地址+设置值；通知字:地址+数据类型+设置值）
```

关键交互顺序：点工具箱“指示灯”图标 → 弹“位指示灯”对话框（先落在指示灯设置页）→ 四页签编辑、预览实时更新 → 确定 → 画布拖框 → 双击/右键属性重开回填 → 修改确定更新画布与工程数据；取消丢弃本次修改 [V]。必须实现的联动规则：

1. 双态监视/多态监视**互斥**：勾选一方自动取消并禁用另一方；取消一方自动恢复勾选另一方 [V]。
2. 双态监视取消勾选 → 双态组内全部字段禁用；重新勾选恢复 [V]。
3. 地址类型 位↔字：监视地址 LB↔LW 前缀切换；“字的位”仅字地址时可用 [V]。
4. “字的位”新建对话框显示 15（禁用），确定写入 0；复刻时应以 0 为对象存储默认值、15 仅为设计期显示残留——或按“显示 15/存储 0”原样复刻并记录该怪癖 [V]。
5. 多态监视启用 → 多态组字段全部启用；“数据类型”下拉仅 16位正整数/32位正整数；“状态数”≥2 [V]。
6. 权限页单列：显现/通知两级复选框逐级启用；无触控列、无按压时间 [V]。
7. 外观页与位按钮同构（状态切换、复制按钮标签翻转、不使用图片禁用路径框等，见位按钮手册 §9）。

## 10. 必须执行的验收矩阵

1. 工具箱“指示灯”图标打开标题“位指示灯”的对话框，**首先显示指示灯设置页**；默认值（双态监视勾选／位地址／LB0／字的位显示15禁用／多态监视不勾选／LW0／16位正整数／状态数2）与本手册一致。

3. 地址类型下拉两项及顺序（位地址/字地址）；位↔字切换时 LB0↔LW0 与字的位启用；拾取按钮打开共享“地址输入”窗口。

7. 权限页：仅显现列+通知；受位控制勾选后地址与显现状态可用；无触控有效列、无按压时间（与位按钮的差异化验收点）。
