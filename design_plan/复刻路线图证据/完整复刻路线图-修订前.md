# KinSealStudio V5.1 完整复刻路线图

版本：2026-11-10（同日修订 A：补绘图对象族与表格控件工作流、真机台架前置）。目标：以《工具箱控件复刻总览.md》+ 30 份控件手册为行为依据，完整复刻原生软件（编辑器 → 工程格式 → 编译 → 下载 → 模拟 → 真机运行）。
基线事实：复刻工程 KinSealStudio Lite 0.6.0（Qt）已全链路打通 **静态文本、位按钮、字按钮、指示灯** 4 个控件（属性对话框/画布/设备编译/USB 下载到真机 AMT070W124-L800X480R 均验证）；系统图库 5647 张图片已完整索引；PLC 地址族与宏外部 ARM SDK 链路已有；原厂 `.sm` 部分导入/导出可用（schema6/7）。
**范围警告**：用户截图只覆盖工具箱滚动区前 11 行的属性控件；exe 证据（`btn_line/foldline/freeline/linecycle/rect/roundrect/elipse/polygon/arc/bitmap/table/start` + 中文串"直线连接线/曲线连接线/自由直线/表格"）证实还存在**矢量绘图对象族（≥10 种）与表格控件**，未在任何手册覆盖内，已列入阶段 0.5 清点与阶段 4J。

难度标记：★ 低 ☆ 中 ◆ 高 █ 极高（需真机/固件级逆向）。

## 建议的关键路径

0（含 0.5 工具箱全量清点——决定控件总数与 4J 范围）→ 1（数据层是所有控件的地基，1.2 透传可先行落地）→ 2.1–2.3（工程可管理）→ 4A/4B/4C（快速铺量）→ 5.1/5.3（随控件同步逆向）→ 4D–4J（重控件，4J 手册先行）→ 6/7/8（通信与模拟）→ 9/10（驱动与真机，0.6 台架就绪为前置）→ 11。
其中两条"硬骨头"建议最早启动预研：**5.4 编译产物 byte-diff**（它是验证一切编译正确性的标尺）与 **9.2 PLC 协议**（工作量最大、依赖真机联测资源）。
