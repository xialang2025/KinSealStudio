### 1.1 帮助文档中的定义 [H]

- 定义：图片显示器用于单幅/多幅图像显示；静态图片支持 jpg、png、bmp、jpeg。
- 多幅切换语义（帮助正文，设备运行语义 [待验]）：时间＝每隔设定时间轮播切换；数值＝监视字地址的值为几显示第几张；位＝只能两张，监视位 0/1 对应第一/第二张。
- 帮助（11.1 版页面）有“选择外部图片”按钮直接选电脑里的图片；V5.1 实测该按钮不存在，外部图片经工程图库“添加图片”进入后再选用（见 §6，以实测为准 [V]）。

## 3. 用户的完整操作路径

### 3.1 新建控件

1. 打开工程和画面。在右侧工具箱点击「图片显示」图标 [V]。
2. 点击后**立即弹出标题「图片显示器」的属性对话框**，初始“基本”页 [V]。对话框窗口约 795×578（自绘标题栏属于客户区；不同会话出现位置略有差异）。默认内容见 [assets/01](图片显示复刻手册.assets/01-V5.1-基本页默认.png)：显示类型=静态图片、状态切换条件不勾选（内容灰显）、总状态数 1、监视地址空、间隔时间 1、预览与提示右侧竖排。
3. 在“图片”页添加图片（见 §6）。点击“确定”后关闭对话框进入画布拖框模式 [V]。
4. **未配置任何图片时“确定”被拒绝**：弹出标题 KinSealStudio 的消息框“**状态没有选择图片!!**”（确定），对话框不关闭 [V]（assets/12）。
5. 在画布按住左键拖出矩形，松开完成绘制；控件把当前图片等比拉伸铺满矩形显示 [V]（assets/14，120×60 对象）。

### 3.2 修改现有控件

- 画布左键**双击**已存在的图片显示器 → 重新弹出“图片显示器”对话框并回填：显示类型、闪烁状态/状态切换条件勾选态、监视地址、图片列表与预览全部恢复 [V]（assets/15）。
- 画布右键菜单与通用画布菜单一致（属性／控件(K)▶／剪切／复制／多重复制／粘贴／删除／全选／对齐▶／层次▶／组合▶／图像比例▶／网格／模拟状态▶）[V]（assets/16）。

### 3.3 对话框公共部分

窗口标题“图片显示器”；左上三个页签：**基本／图片／权限设置** [V]；右侧竖排两个框：上“**预览**”（显示当前状态图片）、下“**提示**”（蓝字固定文案“**支持png、jpg、bmp格式图片**”）[V]；右下“确定／取消／帮助”（`m_okBtn`／`m_cancelBtn`／`m_helpBtn`）[B][V]。

- **确定**：校验通过后进入画布拖框（新建）或提交修改（编辑）；无图片时被拒（见 3.1 第 4 条）[V]。
- **取消**：放弃改动关闭 [V]。
- **帮助**：按钮存在 [V]；行为未实测（GIF 同款按钮在沙盒实测无窗口弹出）[待验]。

## 6. “权限设置”页（SecurityWidget）

```text
[ ] 显现
├─ [ ] 受位控制      地址: [LB0] [拾取]   显现状态: (•)1 ( )0
├─ [ ] 受用户等级控制  有效最低等级: [1 下拉，1–8]
```

默认全部不勾、字段禁用（浅蓝）[V]（基本同 GIF assets/02；本控件页同布局）。各字段默认值、下拉项与联动和《GIF显示功能与交互复刻手册》§5 一致（等级 1–8 默认 1；数据类型五项；比较符六项默认 `<`）[V]。`==`/`<>` 的“误差”行联动未在本页实测 [待验]（共用实现，参照位按钮推断 [B]）。

## 8. 复刻实现的数据与交互约束

每个图片显示器对象至少应保存：

```text
几何：画面 ID，x，y，width，height，层次
类型：静态图片 | 多幅切换
切换：条件启用（静态=闪烁状态开关）；时间|数值|位；
      监视地址（位/数值）；间隔时间（默认 1，x100ms）；总状态数（静态=1，多幅默认 2）
图片：S# → 工程图库图片引用（数量=总状态数；静态仅 1 张）
权限：显现（位控制:地址+显现状态；等级控制:1–8 默认 1；
      字控制:数据类型+字地址+比较符+比较值[+误差]）
```

关键交互顺序：工具箱“图片显示”图标 → 弹“图片显示器”对话框 → 图片页选系统图库/工程图库填 S# 行 → 基本 页选显示类型与切换条件（多幅切换联动总状态数/行数）→ 确定（无图被拒）→ 画布拖框 → 双击重开回填 → 取消丢弃 [V]。必须实现的联动：显示类型切换重建条件组（多幅=无复选框+数值单选出现+总状态数可编辑默认 2；静态=复选框回归）；位条件启用监视地址、时间条件启用间隔时间；总状态数驱动图片页行数；批量加/批量删启用起止位置；删除该状态图片需先选中行；确定前无图校验。

## 9. 必须执行的验收矩阵

1. 工具箱“图片显示”图标 → 立即弹“图片显示器”对话框；默认（静态图片/条件不勾/总状态数 1/间隔时间 1/预览提示框）与本手册一致。
2. 无图片点确定 → “状态没有选择图片!!”且对话框不关闭。
3. 多幅切换 → 三条件+总状态数 2 可编辑；位 → 监视地址 LB0 可用；总状态数改 3 → 图片页 3 行。
4. 工程图库添加 png/jpg/bmp → 列表回填+预览刷新；删除该状态图片（选中行）清空该行。
5. 系统图库窗口结构、工程图库窗口结构、监视地址拾取窗口。
6. 权限页：显现单列三条件、等级 1–8、数据类型五项、比较符六项。
7. 确定→拖框生成；双击重开回填（含闪烁状态勾选态与预览）；取消丢弃；右键菜单全项；状态栏“图片显示器”。
