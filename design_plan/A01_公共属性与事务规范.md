## 2. 控件变体必须显式声明

| 变体 | 权限/地址 | 外观/状态 | 宏、通知和按压 |
|---|---|---|---|
| 静态文本 | 只有显现；没有操作地址/触控列 | 多行文字、13样式、自适应、多语言 | 不增加触控通知或宏组 |
| 位按钮 | 操作、监视、显现、触控、通知职责分开 | ON/OFF图序以位按钮编译记录为准 | 允许范围看原手册与实现报告，不能套功能按钮的零按压限制 |
| 字按钮 | 字/双字操作与数据类型决定跨度 | 源/设备独立subtype1，设备两态图OFF→ON | 7操作×7数据类型；沿其宏和按压范围 |
| 指示灯 | 只监视/显现，没有操作地址和触控 | 双态位/字位；多态U16/U32、2..32；多语言在外层 | “与操作地址相同”、通知、宏禁用；编译拒绝人为开启 |
| 功能按钮 | 无操作地址；显现/触控扫描、通知写入分开 | UI状态0锁定，保留隐藏ON按下图；字符1 UTF16单元 | 宏禁用；两个复制按钮禁用；按压可为0..255×100ms |
| 其余26类 | 各自手册确认显示/触控/通知列，不因复用SecurityWidget自动显示全部 | 状态/语言/外观页可能不同，空页保留 | 各自证据决定；公共基类中存在字段不表示本控件允许 |

共用窗口接受“允许字段/页/状态/事件”的能力描述。状态值、显示模型、源记录和设备记录分别实现，避免一种bool或type索引承担多层含义。

## 3. 地址选择器与值类型

| 字段ID | 完整记录要求 | 生效与保存 |
|---|---|---|
| F-ADDR-CONNECTION | 工程连接稳定ID、协议profile、COM端口、站号/节点、型号可用列表 | 不把站号、节点、连接序号混为一值；重排更新引用 |
| F-ADDR-FAMILY | 内部/外部、地址族、位/字/双字、主/次进制和区段 | 过滤仅依据已知能力；保留原始语法，禁止统一按十进制解析 |
| F-ADDR-VALUE | 起点、位号、跨度、只读/只写/双向能力 | U32/浮点跨两字须校验尾地址；位地址不能当字地址使用 |
| F-ADDR-ROLE | 操作、监视、显现、触控、通知、触发分别绑定 | 同一字符串不代表同一职责；读取加入扫描，通知/操作写入另编码 |
| F-ADDR-INCREMENT | 多重复制行列方向、主地址和被选字段增量 | 超界、不同协议/进制、共享与独立地址分别核验 |

原生“地址输入”按钮打开嵌套窗口，确定回填、取消保持调用者草稿。必须处理对话框打开后协议/连接删除、空列表、只读地址、非法文本和跨度超界。类型改变引起字段失效时，是禁用、重置还是保留须按控件实测；不能自己统一清零。

现有[plc_address.h](../src/plc_address.h)与[阶段9](10_阶段9_PLC地址模板与通信.md)可复用目录和语法，但“能选地址”不代表C/E已支持该协议。

## 4. 显现/触控条件字段与启用矩阵

| 字段ID | 字段与当前已知典型结构 | 联动/必须补证处 |
|---|---|---|
| F-PERM-MASTER | 显现/触控有效各自总开关 | 关时子条件灰显，草稿是否保留由源/重开验证 |
| F-PERM-BIT | 受位控制、地址、目标状态1/0 | 选中才可编辑地址与目标状态；与操作地址无必然关系 |
| F-PERM-LEVEL | 受用户等级控制、有效最低等级 | 静态显现典型默认1，部分触控默认2；禁止所有列统一默认1 |
| F-PERM-WORD | 字控制、数据类型、字地址、比较符、比较值 | 16/32有符号/无符号/浮点按原生列表顺序；跨度和输入编码独立校验 |
| F-PERM-TOLERANCE | 误差 | 已观察部分公共窗口在`==`/`<>`显示，其他比较隐藏；比较公式、边界及多条件AND/OR仍需运行证据 |

实现矩阵至少包含：总关/总开无子条件/每一子条件单独/两个组合/三个组合；子条件开关前后保持地址和值；字类型切换；比较符往返；语言/对象/画面切换。每个组合记录checked、enabled、visible和保存值，不仅看像素灰色。

UI默认与逻辑应分开：帮助中的“有效最低”等字样不能直接确定`>=`或组合AND/OR。相关E问题仍沿[核销记录](复刻待验核销记录.md)、[A06](A06_运行与发布验收用例.md)补证；未证公式不进入“兼容权限模拟”的通过声明。

## 5. 通知与按压

通知含总开关、通知位、位地址/目标1或0、通知字、字地址/数据类型/值。功能按钮已补证通知位/字互斥；其他控件逐个核对。原生通知发生在按下、松开、成功后还是失败也通知，必须另测，不由字段布局推导。

按压含“启用”与数值，两者独立保存。原生功能按钮范围0..255，单位100ms，默认255；这不能覆盖其他控件已恢复校验。计时起点、释放取消、重复触发、抖动和超时在运行用例中判定。退出属性窗口与松开设备触控是不同事件。

指示灯宏/通知禁用、功能按钮宏禁用的事实已关闭，公共组件不再为这些控件开放编辑器；合法源中残留值如何保留以typed codec为准，编译不能静默启用它们。

## 6. 外观、语言、状态与资源

外观字段至少包括当前语言、当前状态、每语言文字/共享文字、字体/字号/字距/对齐、斜体/粗体/下划线/自适应、文字/背景/前景色、样式/透明度、闪烁、图片来源/路径/内嵌资源、无图、3D、透明效果和图片模式。某控件不适用的字段仍记录原因和隐藏/禁用表现。

静态文本13样式按原手册顺序：透明、纯色、横向过渡、横向对称过渡、纵向过渡、纵向对称过渡、斜上过渡、斜上对称过渡、斜下过渡、斜下对称过渡、右上角辐射、左上角辐射、中心辐射。其他控件的相似样式列表可能使用“反过渡”等不同文案，不能强制替换为这13项。

静态文本自适应已观察禁用字号和对齐，字体与字距仍可用；精确字形缩放算法未穷尽。图像控件不能因“无图”而丢失原路径：指示灯补证显示kind3/Rectangle与kind1/Pixmap结构不同，原路径仍保留。功能按钮按下图取隐藏state1，不能从当前state0简单调暗生成。

显式指示灯状态数5→2→5会删除新增状态；仅切双态/多态保留多态草稿。该规律只限已补证控件，不推广到图片列表、趋势通道或多态按钮。相同文本开关不等于删除各状态文字；同文与多语言图片数量另按设备映射。

颜色嵌套窗口至少记录基本色、自定义色、色域/亮度、RGB/HSV、添加自定义、确定/取消；色板是否跨工程/重启保持仍需探针。字体列表来自当前系统，不把截图可见几个字体写死；替换字体必须显式处理，避免编译机与编辑机像素无声不同。

## 7. 事务与数据寿命：实现设计及原生校准

以下为实现结构要求，原生未测处必须再对照，不将设计自动写成原生事实。

| 事件ID | 实现结构/核对动作 | 可判定结果 |
|---|---|---|
| EV-DRAFT-OPEN | 从正式对象复制完整草稿，创建页/隐藏页同时绑定同一草稿 | 未按确定前正式工程字节不改变；回填包括未启用字段 |
| EV-DRAFT-PREVIEW | 每次外观变更渲染当前草稿 | 预览更新，工程dirty/undo不因每个预览刷新新增条目 |
| EV-DRAFT-SUBDIALOG | 地址/颜色/图库使用子草稿，分别确定/取消 | 子取消不改变父草稿；父取消也回滚已确定的子草稿 |
| EV-DRAFT-LANGUAGE | 先保存旧语言草稿，再切新语言 | 来回切换译文独立；右侧属性不能覆盖另一语言 |
| EV-DRAFT-COUNT | 缩减状态/列表后再扩展 | 记录删项还是恢复；按各控件证据，不能自动统一 |
| EV-DRAFT-ACCEPT | 校验全部页和交叉引用；编辑已有对象时确定一次提交，新建时只保存待放置草稿 | 编辑成功只产生一个撤销事务；新建属性确定不新增正式对象或历史；失败保留草稿 |
| EV-DRAFT-CANCEL | 取消、Esc、标题关闭分别核对 | 编辑已有对象保持原值；新建不留下半对象；是否保留绘制工具按原生另验 |
| EV-DRAFT-PLACE | 新建属性确定后进入待放置，鼠标完成几何才新增对象 | 位置/尺寸与属性一起形成唯一新增事务；Esc/中断不新增对象或历史，具体工具模式按原生另核 |

源码应从现有`MainWindow::createStaticText/editStaticText/createBitButton/editBitButton`与`ScreenCanvas::beginControlPlacement/recordHistory`扩展，避免右侧面板另写一套漏字段逻辑。

## 8. 共用验收用例

| AC-ID | 步骤 | 通过层/判断 |
|---|---|---|
| AC-COMMON-01 | 新建默认→逐页截图/属性→确定绘制→双击回填 | D/U字段、页、顺序、默认和入口一致；只比较同机型/语言/DPI |
| AC-COMMON-02 | 同时改外观/权限/通知→开子窗口确定→父取消→重开 | U/P对象及工程仍为原值，无半条历史 |
| AC-COMMON-03 | 三语言分别输入不同文本→切回→同文开关往返→保存重开 | P每语言/共享草稿寿命与源一致；不能只验当前语言 |
| AC-COMMON-04 | 控制字段关开、类型/比较符往返、状态5→2→5 | U/P真实联动与保留/删除行为按变体；指示灯不得残留已删除状态 |
| AC-COMMON-05 | 编辑后复制/粘贴→撤销重做→原生源往返 | P隐藏值、资源和引用不丢；新对象ID与资源引用独立处理 |
| AC-COMMON-06 | 直接构造禁用宏/非法地址/未知资源/缺前置输入 | 模型/源/编译按已定范围明确拒绝，不发布部分包、不打开USB |
| AC-COMMON-07 | 相同输入比较预览、画布、原厂解压RGB565 | R按区域、字体/填充/透明分开报告；T/E不由此通过 |

这些是验收设计，不是本轮新执行结果。历史结果引用5类实施报告；新控件逐一绑定自己的F/EV/AC-ID。
