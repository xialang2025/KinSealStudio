### 1.1 帮助文档中的定义 [H]

- 配方：预设好供机器运行时自动调用的数据集合（表格化管理：列=配方、行=数据）。
- 注意：帮助 `Recipe/KongJian.html`“配方控件说明”讲的是**数值显示器**与**配方操作按钮**（功能按钮的配方操作类型），并**没有**“配方显示器”控件的专页；配方显示器以实测为准 [V]，帮助只提供配方体系背景。

## 2. 控件家族、入口与依赖

- 工具箱内部对象名 `btn__recipetable`（双下划线）[B]，图标文字“配方显示器”，位于工具箱“控件”页网格滚动一页后的第二行第二列 [V]。
- **依赖 [V]**：必须先在工程树建立至少一个配方，属性框的“配方名称”下拉才有内容；空白工程下点击工具箱图标的行为 [待验]（未单独复测；配方体系帮助要求“必须先建立起配方表方能使用配方功能” [H]）。
- 画布绘制出的对象在默认 230×180 尺寸下显示提示文字“**控件宽度不足，无法显示数据**” [V]，说明表格渲染有最小宽度阈值，阈值数值 [待验]。

## 3. 依赖配置：建立最小“配方” [V]

操作路径（全程实测）：

1. 菜单栏“**添加(A)**”→“**添加配方**”（下拉第一项）[V]。帮助另载：可右键系统参数树“配方”节点→新建配方 [H]（树右键路径未实测）。
2. 弹出标题“**配方**”的属性对话框（约 576×697，[assets/01](配方显示器复刻手册.assets/01-V5.1-新建配方对话框默认.png)），两页签：**一般／数据项**。“一般”页字段与默认值 [V]：
   - 名称（空，必填）、描述（空）。
   - 配方长度 `4`（行）；配方总数 `1`（列）。
   - 数据类型下拉，默认 **16位正整数**。
   - ☐写配方到PLC → 写入地址 `LW0`＋地址拾取按钮（灰）；☐从PLC读取配方 → ☑读取地址与写出地址相同（灰）→ 读取地址 `LW0`（灰）。
   - 配方记忆体（只读）：地址范围 `RW1 - RW4`。
   - 当前配方（只读）：地址范围 `RWI1 - RWI4`；配方编号寄存器 `RWI0`。
   - 按钮：导出配方（导出 .csv）、导入配方。
   - “数据项”页：配方数据表格（行=配方长度、列=配方总数，单击单元格输入数值）。
3. 名称填 `RCP1` → 确定 → 工程树“配方”节点下出现 RCP1 [V]。
4. **名称留空点“确定”**：弹出校验消息框（标题 KinSealStudio，含“配方名称不能为空”类文案 [B：`The recipe name cannot be empty.`]），对话框不关闭、不创建 [V]。
5. 帮助中的配方属性约束 [H]：名称≤48 字符；配方长度≤200（32 位数据≤100 行）；配方总数≤200；数据类型五种（16位整数/16位正整数/32位整数/32位正整数/32位浮点数）；配方容量=长度×总数（16 位最大 200*200=40000）；RW 为 HMI 内部存储地址（自动生成不可改）；RWI0 固定为配方编号寄存器且只能用于改变配方编号。

## 4. 控件的完整操作路径

1. 工具箱点击“配方显示器”→ 弹出标题“**配方显示器**”属性对话框（约 631×578）[V]。
2. 两页签：**基本属性／权限设置**（容器 `RecipeTableGenWidget`／`SecurityWidget` [B]）[V]；右下“确定／取消／帮助”。
3. “确定”→画布拖框→绘制对象 [V]（assets/10：默认尺寸显示“控件宽度不足，无法显示数据”）。
4. 画布双击重新弹框 [V（回填已验证一次）]。

## 6. “权限设置”页（SecurityWidget）

默认全部不勾选、子字段灰显 [V]（[assets/04](配方显示器复刻手册.assets/04-V5.1-权限设置页默认.png)）。**双列同构 + 通知组**（与位按钮权限页同构，与数据群组/历史数据显示器不同）：

```text
[ ] 显现                                  [ ] 触控有效
├─ [ ] 受位控制                            ├─ [ ] 受位控制
│    地址: [LB0] [拾取]                     │    地址: [LB0] [拾取]
│    显现状态: (•)1 ( )0                    │    有效状态: (•)1 ( )0
├─ [ ] 受用户等级控制                       ├─ [ ] 受用户等级控制
│    有效最低等级: [1]                      │    有效最低等级: [2]
└─ [ ] 字控制                              └─ [ ] 字控制
     数据类型: [16位正整数] [LW0] [拾取] [<] [0]  数据类型: [16位正整数] [LW0] [拾取] [<] [0]
[ ] 通知
├─ [ ] 通知位      └─ [ ] 通知字     ← 默认灰显
```

显现列默认等级 **1**，触控列默认等级 **2**（与位按钮手册一致的差异）[V]。程序内含 `setTouch(bool)`/`alowEdit(bool)` 槽 [B]；通知位/通知字展开后的界面未实测 [待验]（位按钮手册记载其字段结构 [B]）。

## 8. 复刻实现的数据与交互约束

```text
前置：工程须存在≥1个配方；配方对象（依赖）：名称(必填,≤48字符)、描述、配方长度(默认4)、
      配方总数(默认1)、数据类型(默认16位正整数)、写配方到PLC+写入地址、
      从PLC读取配方+读取地址(+与写出地址相同)、记忆体RW只读、当前配方RWI只读、
      数据项表格(长度*总数)、导出/导入csv
几何：画面 ID，x，y，width，height，层次
基本：配方名称(下拉绑定)；编辑配方(默认不选)；
      文本设置：字体(宋体)+字体大小(16)+对齐(左/居中/右默认居中)+标题文本色(蓝)+数据文本色(黑)；
      外观设置：标题背景色(#FF6666)+背景色(#FFFFFF)+使用网格✓+网格颜色(黑)；
      [编辑配方展开字段：行数/列数/使用标题/列宽/边框色/自定义键盘/键盘位置 —— 待验]
权限：显现(位/等级1/字) + 触控有效(位/等级2/字) + 通知(位/字，默认灰显)
渲染：宽度不足最小阈值时显示“控件宽度不足，无法显示数据”（阈值待验）
```

联动规则：配方名称下拉内容由工程配方列表派生；色块统一“选择颜色”窗口；使用网格关闭时网格色禁用 [推测，待验]；编辑配方勾选启用触屏编辑与键盘相关字段 [B/待验]。

## 9. 必须执行的验收矩阵

1. 添加配方最小流程：菜单第一项→名称必填校验→确定→工程树出现配方节点；数据项表格尺寸=长度*总数。
2. 工具箱图标弹出标题“配方显示器”对话框；页签只有基本属性/权限设置两个。
3. 基本属性默认值（宋体/16/居中/蓝/黑/#FF6666/白/✓网格/黑）；四个下拉的内容与项序。
4. 五个色块按钮打开“选择颜色”窗口。
5. 权限页双列同构：显现默认等级 1、触控默认等级 2、有效状态标签、通知组灰显。
6. 确定→拖框→对象显示“控件宽度不足，无法显示数据”→状态栏“配方显示器”→双击回填。
7. 加宽对象后表格渲染（阈值与样式）[待验项，实现时自行确定最小宽度并文档化差异]。
8. 编译下载后设备端配方显示/编辑、与配方操作按钮、数值显示器(RWI0 编号/RWI1.. 数据)的联动 [H→设备验证，不在本手册]。
