### 1.1 帮助文档中的定义 [H]

- 定义：画面按钮主要用于**画面的切换、改变用户等级和弹出窗口**等操作；触控设置好后的画面按钮可以使画面/窗口跳转到所设置的画面/窗口上去操作，在跳转过程中还可以选择是否改变用户等级。
- 操作类型四种语义（帮助正文，设备运行语义 [待验]）：
  - **跳转到指定画面**：组态有多个画面时切换画面，例如画面 1 上放置按钮、画面名称选画面 3，点击后直接跳转到画面 3（[帮助-跳转到指定画面演示](画面按钮复刻手册.assets/帮助-跳转到指定画面演示.png)、[帮助-跳转后画面](画面按钮复刻手册.assets/帮助-跳转后画面.png)）。
  - **返回上一个画面**：点击后返回跳转前的上一个画面（[帮助-返回上一个画面演示](画面按钮复刻手册.assets/帮助-返回上一个画面演示.png)）。
  - **打开窗口**：**只能在窗口页面中使用**，在当前画面打开指定的窗口（[帮助-打开窗口演示](画面按钮复刻手册.assets/帮助-打开窗口演示.png)、[帮助-窗口页面](画面按钮复刻手册.assets/帮助-窗口页面.png)）。
  - **关闭窗口**：**只能在窗口页面中使用**，关闭当前打开的窗口（[帮助-关闭窗口演示](画面按钮复刻手册.assets/帮助-关闭窗口演示.png)）。
- **改变用户等级**：勾选后“新用户等级”选择改变后的用户等级，画面成功跳转时自动把用户等级更改为设置值。
- **用户等级不足时要求登录**：勾选且权限设置里设置了“受用户等级控制触控有效”后，当前用户等级低于阈值时按钮显示受限状态，点击弹出**密码输入键盘**（[帮助-密码键盘](画面按钮复刻手册.assets/帮助-密码键盘.png)，MIN:0/MAX:999999999、数字键 0–9、+/-、Clr、Esc、Back、Ent），输入密码可修改当前用户等级：修改后等级大于阈值则成功跳转，小于阈值则键盘显示输入出错状态（[帮助-登录要求设置](画面按钮复刻手册.assets/帮助-登录要求设置.png)、[帮助-触控等级设置](画面按钮复刻手册.assets/帮助-触控等级设置.png)）。

## 2. 控件家族与入口

画面按钮属于“开关”家族。工具箱（右侧“工具栏／控件”面板，“控件”与“基本控件”两个标签页，见 [assets/38](画面按钮复刻手册.assets/38-V5.1-画布创建与状态栏.png) 右侧）第一、二行提供 6 个图标 [V]：

| 图标文字 | 内部对象名 [B] |
|---|---|
| 位按钮 | `btn_switch_bit` |
| 字按钮 | `btn_switch_word` |
| 指示灯 | `btn_switch_Lamp` |
| 功能按钮 | `btn_switch_Fun` |
| 画面按钮 | `btn_switch_Screen` |
| 多态按钮 | `btn_switch_Mstate`（字符串表中与 `btn_switch_MultiState`/`radio_Mstate` 并存） |

**六个入口共享同一个属性对话框**（帮助称“开关”对话框），只是打开时锁定的类型不同、窗口标题不同：从“画面按钮”图标打开的窗口标题为**“画面按钮”** [V]。“通用设置”页顶部有 6 个单选（位按钮/字按钮/画面按钮/功能按钮/多态按钮/指示灯），实测从“画面按钮”入口打开时“画面按钮”单选呈选中且灰显（锁定），点击其他单选不会切换类型、也不会改变页签内容 [V]（[assets/11](画面按钮复刻手册.assets/11-V5.1-类型单选锁定画面按钮.png)）。其他类型（位按钮、字按钮、指示灯、多态按钮、功能按钮）的专属字段见姊妹手册，不在本手册范围内。

## 3. 用户的完整操作路径

### 3.1 新建控件

1. 打开工程和画面。在右侧工具箱点击“画面按钮”图标（内部名 `btn_switch_Screen`）[V]。
2. 点击后**立即弹出标题“画面按钮”的属性对话框**，初始显示“通用设置”页；对话框尺寸 836×616（含自绘标题栏，标题栏区域属于窗口客户区）[V]。默认内容见 [assets/01](画面按钮复刻手册.assets/01-V5.1-通用设置默认.png)：操作类型 `跳转到指定画面`、画面名称 `画面1`、“改变用户等级（注销）”勾选、新用户等级 `1`、“用户等级不足时要求登录”勾选、预览为 OFF 状态方形银色按钮。
3. 配置操作类型、目标画面/窗口、改变用户等级与四个页签。点击“确定”后对话框关闭，鼠标进入画布拖框模式（十字/拖拽绘制）[V]。
4. 在画布上按住左键拖出矩形，松开完成控件绘制；控件默认显示 OFF 状态外观 [V]（[assets/38](画面按钮复刻手册.assets/38-V5.1-画布创建与状态栏.png) 画布中已生成 OFF 按钮并处于选中态，[assets/39](画面按钮复刻手册.assets/39-V5.1-画布对象与控制点.png) 为 8 个控制点特写）。
5. 画布矩形决定控件位置和宽高。

**注意**：V5.1 的“改变用户等级（注销）”和“用户等级不足时要求登录”默认都是**勾选**（实测 [V]，[assets/01](画面按钮复刻手册.assets/01-V5.1-通用设置默认.png)），而帮助属性图中两项均为未勾选 [H]。复刻默认值必须以 V5.1 实测为准。

### 3.2 修改现有控件

- 画布上左键**双击**已存在的画面按钮，重新弹出“画面按钮”对话框并回填已有值（实测回填默认 `跳转到指定画面`/`画面1`，见 [assets/41](画面按钮复刻手册.assets/41-V5.1-双击回填默认.png)）[V]。
- 画布右键菜单首项“属性”也可打开同一对话框；菜单结构与静态文本一致：属性／控件(K)▶／剪切 Ctrl+X／复制 Ctrl+C／多重复制 Ctrl+P／粘贴 Ctrl+V／删除 Del／全选 Ctrl+A／对齐▶／层次▶／组合▶／图像比例▶／网格／模拟状态▶ [V]（[assets/40](画面按钮复刻手册.assets/40-V5.1-右键菜单.png)）。

### 3.3 对话框公共部分

窗口标题“画面按钮”；左上四个页签：**通用设置／指示灯设置／外观设置／权限设置** [V]；右侧独立“预览”框（含“预览”标题，白色底，内嵌按钮外观区）[V]；右下“确定／取消／帮助”三按钮（内部 `buttonBox`，帮助槽 `on_buttonBox_helpRequested`）[B][V]。

- **确定**：新建时进入画布拖框阶段；编辑时提交修改并关闭 [V]（[assets/42](画面按钮复刻手册.assets/42-V5.1-修改确定后回填关闭窗口.png)：改为“关闭窗口”后确定，再次双击回填“关闭窗口”）。
- **取消**：编辑状态下放弃本次改动。实测：双击打开已有控件 → 修改操作类型 → “取消” → 再次双击，原值保留 [V]（[assets/43](画面按钮复刻手册.assets/43-V5.1-取消丢弃后仍保留关闭窗口.png)）。
- **帮助**：按钮存在 [V]；原厂 CHM 有对应页面（`Switch/画面按钮.html` 与 `Switch/functionnodes/sceneButton.htm`）[H]；点击后是否直达该页未实测 [待验]。
- **预览**：显示当前“选择状态”的按钮外观（状态 0 显示 OFF、状态 1 显示 ON，含图库/文字/背景色）[V]；“不使用图片”后预览变纯背景色+文字的平面矩形 [V]（[assets/23](画面按钮复刻手册.assets/23-V5.1-不使用图片后.png)）。

## 9. 复刻实现的数据与交互约束

每个画面按钮对象至少应保存以下独立状态：

```text
几何：画面 ID，x，y，width，height，层次
通用：按钮类型（画面按钮锁定）；
      操作类型（跳转/返回/打开窗口/关闭窗口，默认跳转）；
      目标画面索引或窗口索引（跳转=画面名称，打开窗口=窗口名称）；
      改变用户等级开关（默认开）＋新用户等级（1–8，默认1）；
      用户等级不足时要求登录（默认开）；
      宏指令开关；宏索引
指示灯：启用指示灯功能（默认关）；双态监视（默认开）；
        地址类型（位/字，默认位）；与操作地址相同（默认关）；
        监视地址（默认 LB0，字地址时 LW0）；字的位（默认 0）
外观（状态0 与 状态1 各一份）：
        文本（OFF/ON）；字体（微软雅黑）；大小（16）；对齐（居中）；
        粗体/斜体/下划线；文本色（黑）；文本闪烁（默认关，灰显）；
        图库路径（switch_OFF.kvg / switch_ON.kvg）；
        终端3D按钮效果（关）；使用透明效果（关）；背景色（灰）；透明度（255）
权限：显现（位控制:地址+显现状态1/0；等级控制:1–8 默认1；
       字控制:数据类型+字地址+比较符+比较值+误差）；
      触控有效（同构三条件，等级默认2，标签"有效状态"）；
      通知（通知位:地址+状态1/0；通知字:地址+数据类型+设置值）；
      按压时间:开关+数值(默认255, x100毫秒)
```

关键交互顺序：点工具箱“画面按钮”图标 → 弹“画面按钮”对话框（类型单选锁定）→ 四页签编辑、预览实时更新 → 确定 → 画布拖框 → 双击重开回填 → 修改确定更新画布与工程数据；取消丢弃本次修改 [V]。联动规则必须实现：通用页操作类型切换第 2 行显隐与标签（跳转=画面名称、打开窗口=窗口名称、其余隐藏）；“改变用户等级（注销）”启停“新用户等级”；指示灯页“启用指示灯功能”总开关；“地址类型=字地址”启用“字的位”并把监视地址切为 LW0；外观页“选择状态”切换整页内容与预览；“从N状态复制”标签随状态翻转；“不使用图片”禁用路径框；“使用透明效果”启停“透明度”；权限页各主/子复选框逐级启用字段；比较符 `==`/`<>` 增删“误差”行；“通知”启停“通知位/通知字”及其字段；“按压时间”增删数值行。

## 10. 必须执行的验收矩阵

1. 工具箱六个开关图标分别打开标题为对应类型名的同一对话框；“画面按钮”入口的单选锁定行为一致；默认值（操作类型=跳转到指定画面／画面名称=画面1／改变用户等级勾选＋新用户等级1／登录要求勾选／指示灯总开关不勾／状态0 OFF／switch_OFF.kvg／背景色灰／透明度255禁用／触控等级2／显现等级1／按压时间255）与本手册一致。
