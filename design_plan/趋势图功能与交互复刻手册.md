### 1.1 帮助文档中的定义 [H]

- 定义：对监控地址的值的变化用曲线表现出来，可以监控多个地址的值的变化；以时间为水平坐标轴、数值为垂直坐标，便于直观判断某一数值在一段时间内的变化趋势。
- 读取地址的值为曲线的 Y 轴坐标值：16 位数据连续读取、32 位数据间隔读取 [H]；触发地址由位按钮从 0→1 触发读取、清除地址触发后曲线清除并停止读取 [H]。这些设备运行语义均为帮助文字，[待验]。

## 3. 用户的完整操作路径

### 3.1 新建控件

1. 打开工程和画面。在右侧工具箱点击“趋势图”图标（`btn_trend`）[V]。
2. 点击后**立即弹出标题“趋势图”的属性对话框**，初始显示“通道设置”页；对话框窗口 rect 实测 795×584（含自绘标题栏）[V]。默认内容见 [assets/01](趋势图复刻手册.assets/01-V5.1-通道设置页默认.png)：触发地址 `LB0`、读取地址 `LW0`、清除地址 `LB0`、数据类型 `16位整数`、采样点数 `60`、采样时间 `1`、通道总数 `1`、当前通道 `1`、最小值 `0`、最大值 `1000`、线型 `—0`、显示颜色 `红色`、底色 `黄色`、边框色 `灰色`、背景色 `白色`、方向单选 `从左到右`。右上角独立“预览”框实时显示黄底红蓝双曲线示意 [V]。
3. 配置地址、数据类型、通道与三个页签。点击“确定”后对话框关闭，鼠标进入画布拖框模式 [V]。
4. 在画布上按住左键拖出矩形，松开完成控件绘制 [V]（[assets/18](趋势图复刻手册.assets/18-V5.1-画布创建与状态栏.png)：拖出 200×120 后画布出现黄底、红/橙锯齿曲线、绿色网格的趋势图控件，选中态 8 个控制点）。
5. 画布矩形决定控件位置和宽高（实测 左244.0 上112.0 宽200.0 高120.0 为本次拖框结果，非默认值）。

### 3.2 修改现有控件

- 画布上左键**双击**已存在的趋势图，重新弹出“趋势图”对话框并回填已有值（实测全部默认值原样回填）[V]（[assets/20](趋势图复刻手册.assets/20-V5.1-双击回填默认值.png)）。
- 画布右键菜单首项“属性”也可打开同一对话框；菜单结构：属性／控件(K)▶／剪切 Ctrl+X／复制 Ctrl+C／多重复制(D)／粘贴 Ctrl+V／删除 Del／全选 Ctrl+A／对齐▶／层次▶／组合▶／图像比例▶／网格／模拟状态▶ [V]（[assets/19](趋势图复刻手册.assets/19-V5.1-画布右键菜单.png)）。

### 3.3 对话框公共部分

窗口标题“趋势图”；左上三个页签：**通道设置／显示设置／权限设置**，页签条实测位于窗口内 (18,41)–(234,61)（bmp 坐标）[V]。右下“确定／取消／帮助”三按钮（内部对象名 `accept`／`cancel`／`help`）[B][V]：

- **确定**：新建时进入画布拖框阶段；编辑时提交修改并关闭 [V]。
- **取消**：放弃本次改动（实测修改采样点数、通道数、方向后点取消，重新双击控件回填的仍是原默认值）[V]。
- **帮助**：按钮存在 [V]；原厂 CHM 有对应页面（`trend/trendIndex.htm` 等）[H]；点击后是否直达该页未实测 [待验]。
- **预览**：右上角预览框（窗口像素约 141×181，含“预览”标题），实时反映底色/网格/曲线样式 [V]。

### 4.1 每通道独立性

“通道设置”组的 最小值/最大值/线型/显示颜色 属于**当前通道**：实测通道 3 的线型改为 `--2` 后，通道 1 仍为 `—0`，切回通道 3 保持 `--2` [V]（[assets/06](趋势图复刻手册.assets/06-V5.1-每通道线型与方向实测.png)）。帮助同样描述“当前通道可以进行通道曲线的修改线型和曲线显示颜色”及每通道最大/最小值 [H]。最小值/最大值的每通道独立写入因控件自绘未能自动化验证，按结构推断与线型同构 [待验]。

## 8. 复刻实现的数据与交互约束

每个趋势图对象至少应保存以下独立状态：

```text
几何：画面 ID，x，y，width，height，层次
地址：触发地址(位,默认LB0)；读取地址(字,默认LW0)；清除地址(位,默认LB0)
采样：数据类型(7项,默认16位整数)；采样点数(1–100,默认60)；采样时间(≥1秒,默认1)
填充：底色(黄)；边框色(灰)；背景色(白)
通道：通道总数(1–8,默认1)；
      每通道 { 最小值(默认0)，最大值(默认1000)，线型(0–4,默认0)，显示颜色(默认红) }
      当前通道(编辑态选择)
方向：从左到右(默认)／从右到左
显示：X轴{显示刻度,显示Y轴曲线,轴/刻度色(黑),格线色(绿),主分隔数(3–10,默认4),
        次分隔数(默认2),显示刻度标识,字体大小(12/16/24/48,默认16)}
      Y轴{同上五项, 显示X轴曲线, 最大值(1000), 最小值(0)}
      Y刻度{字体大小,总位数(4),小数位数(0–3,默认0)}
权限：显现{受位控制:地址+显现状态1/0；受用户等级控制:1–8 默认1；
      字控制:数据类型(5项)+字地址LW0+比较符(6项)+比较值+误差(==时)}
```

关键交互顺序：点工具箱“趋势图”图标 → 弹“趋势图”对话框（通道设置页）→ 三页签编辑、预览实时更新 → 确定 → 画布拖框 → 双击重开回填 → 修改确定更新画布；取消丢弃本次修改 [V]。联动规则必须实现：通道总数决定“当前通道”项数；切换当前通道切换每通道字段内容；显示刻度（X/Y）取消隐藏“轴/刻度颜色”行 [V]；“从N状态复制”类按钮本控件没有 [V]；权限页主/子复选框逐级启用字段、比较符 `==` 增删“误差”行 [V]。
