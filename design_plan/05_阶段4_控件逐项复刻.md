# 05｜阶段4：控件逐项复刻与图形补齐

日期：2026-11-10。先读[总入口](00_复刻执行总入口.md)、[A01公共规范](A01_公共属性与事务规范.md)、[A04逐控件索引](A04_31控件实施索引.md)。原31手册通过A04调用，不重复抄写；下列批次覆盖全部26个待实施控件，已有5类另做维护核验，9图形/表格另列。

## 1. 不能省略的单控件闭环

每个控件执行以下W步骤，使用该控件的F/EV/AC-ID独立追踪；不能只实现默认页，也不能把同家族的源/设备布局直接复制。

| W序号 | 实际动作与交付 | 放行判断 |
|---|---|---|
| W1 | 从A04读完整手册、最新补证、所有窗口/页签、字段、嵌套窗口及已知缺口；固定前置配置和输入身份 | 本次切片的默认/类型/启用/草稿有来源；未知不冒充原生事实 |
| W2 | 建立类型化模型、保存/迁移、引用、验证；字段逐行映射 | 全页与隐藏值可表达，未知源边界拒绝编辑或保持只读 |
| W3 | 入口→属性→确定后绘制→双击回填；完整事件/取消/子窗口 | 新建和编辑与原生等价；一个事务；不先绘制才弹窗 |
| W4 | 预览、画布和每语言/状态图，含几何/边界/资源 | 共享渲染但按变体；暂不支持组合定位明确 |
| W5 | 新建、取消、保存重开、复制/撤销、.sm往返及原厂复开 | P区分.ksp和.sm，不能只比较当前可见值 |
| W6 | 单控件默认/单变量/重复/混合原厂编译对照，恢复独立设备记录/图帧/扫描 | C通过限定类型/组合；未恢复数据在包发布/USB前拒绝 |
| W7 | 按2026-11-12用户补充要求，在目标实物屏逐控件执行下载，记录编译输入、设备身份、传输及提交结果；显示/触控另设计刺激和观察 | 下载必须有真实设备结果；T、E分别记录，下载成功不能升级为显示/触控通过 |

允许分次交付W1～4编辑器、W5源互通、W6编译、W7运行。控件D整层通过必须覆盖该控件声明的全部字段/状态；一次局部交付不能升级为“完整控件已完成”。

## 2. 有序任务和批次

### S04-01 核验已有5类，不重复实现

顺序为静态文本→位按钮→字按钮→指示灯→功能按钮。读取各实施报告、typed codec和独立编码器，再核销旧候选。静态文本后续多语言/type28不回退到旧单文本拒绝；字按钮7类型×7操作、指示灯2..32/禁用组、功能按钮18功能/隐藏ON/字符限制保留。

AC-S04-01：源/模型字段、历史样例、最新限制能对应；旧文档与新补证冲突有记录；不把USB ACK升级为E；不因共用UI改动而改变独立subtype和图帧顺序。

### S04-02 4A：消息显示、刻度、二维码

消息显示先核定文字/状态来源、监视地址/类型、状态增删和语言；刻度核定方向、刻度/数值/字体与尺寸，避免增加不存在的触控/权限页；二维码核定数据来源、编码/内容、纠错/版本/像素和权限。每类先取得单控件源和编译差分，不猜设备type。

AC-S04-A：默认→全部可选分支→最小/最大/非法→保存重开；消息状态切换的地址/文本范围、刻度非方形/边界、二维码空串/中文/过长内容各有原生期望和分层结果。

### S04-03 4B：图片显示、GIF显示

先实现工程资源与图库事务，再做图片列表/状态/监视/无图和条件切换；GIF要恢复帧序、延时、循环/处置和透明效果，不只取第一帧。列表缩减、复制、删除图及资源缺失要看源值是否保留。

AC-S04-B：一图/多图/空资源、列表增删重排、不同尺寸和透明帧；原始文件、编译索引、展开图像分开比较，动画E后续观察。

### S04-04 4C：数值显示、ASCII显示、时间显示

可共用QValueDlg外壳，但逐控件保留类型/字段差异。数值显示的输入/显示、数据类型、数位/小数/比例、上下限和键盘分开；ASCII的字符数、字节互换、换行、密码、编码和自定义键盘分开；时间的日期/时间字段、RTC/地址和格式分开。工程系统时钟与控件外观不是同一配置。

AC-S04-C：每种数据类型、输入/显示模式、负数/溢出/小数、ASCII空串/奇数字节/非ASCII、时间格式和日期边界各有用例；未测字序/BCD和容差不能按常见PLC习惯填写。

### S04-05 4D：画面按钮、多态按钮

画面按钮依赖阶段2的页面/窗口/键盘引用以及登录/等级行为；每种操作的第二行字段和类型联动按其手册独立恢复。多态按钮独立状态/操作/监视源记录，不把指示灯subtype4当通用多态布局。

AC-S04-D：不存在目标、目标删除/改名/重排、窗口开关与返回、按钮类型变更、状态数和边界、按下/松开/权限分别验证；页面标签不当设备编号。

### S04-06 4E：多功能按钮、下拉框

多功能按钮恢复命令列表三类操作、顺序、增删改、已记载7项上限、宏/延时和失败处理；执行顺序与是否短路需取运行证据。下拉框恢复基本属性、项目表/值、文本/图片、读写地址、通知/权限；索引0/1起点不能猜。

AC-S04-E：空/1/7项及超限、重排/取消、不同命令混合、下拉空/重复文本/相同写值/越界索引、键盘和触控，各有源和编译对照。

### S04-07 4F：流动块、滑动开关、滚轮、移动轨迹

分别恢复流动块的块宽/间隙/方向/速度与显现；滑动开关的手势、范围/方向/数值映射及写入时点；滚轮的步进/范围/显示/读写节奏；移动轨迹的坐标/范围/资源/路径引用。鼠标移动、松开提交、设备周期写入不可混为一条事件。

AC-S04-F：起点/终点、反向、边界超出、拖动取消、连续快速输入、地址外部变化、权限变化；单变量设备刺激与视觉/寄存器观测独立。

### S04-08 4G：图表

柱状图、仪表、圆环三形态分别恢复基本/外形页及形态切换草稿。通道、数据类型、比例、刻度、角度、颜色等完整调用图表手册；不能用单一QChart默认外观替代原生三套字段。

AC-S04-G：三形态来回切换、最小/最大/越界数据、负范围、非方形、每通道独立性、无效组合及保存重开；设备资源和记录按形态验证。

### S04-09 4H：趋势图、历史趋势图、X-Y曲线、数据群组

区分实时通道/取样方式、绑定采集记录的历史数据、成对X/Y数据和数据群组。通道增删、地址跨度/类型、缓存与采样周期、XY轴/缩放/滚动、时间与历史检索分别实现。历史控件先取得阶段2采集配置的正确引用和生命周期。

AC-S04-H：1/多通道、不同类型/地址、取样开始停止与取满、页面离开重入、空历史文件/断电恢复、XY不同步及时间范围；只显示一条静态曲线不能计完成。

### S04-10 4I：动态报警条、报警显示、历史报警显示、历史数据显示器、配方显示器

先验证原生前置门槛：报警登录、采集记录、配方为空时的提示和阻止路径；建立配置后再创建控件。当前/历史报警在发生/确认/恢复/清除、排序/筛选、时间/存储上分别处理；历史数据读采集定义；配方显示/编辑、读写PLC、CSV/键盘和表格宽度提示分开。

AC-S04-I：无前置/最小前置、配置改名/删除、多条并发、历史为空/损坏、权限、列表重排和多语言；配方编辑勾选后的不稳定旧调查是待复核，不以静态字符串补出未经观察的窗口。

### S04-11 4J：9类基础图形与表格

调用A03逐类完成入口/属性/创建/控制点、源/设备和几何差分。9图形为直线、自由直线、曲线/圆弧、折线、圆角矩形、圆/椭圆、扇形、矩形、多边形；表格为纯图像底盘，没有单元格数据绑定。刻度/静态文本已在31类计数，不重复计算。

AC-S04-J：每类最小/零尺寸/非方形/顶点或弧度/线型/填充/透明度及取消；表格行列/水平垂直线/描边分别验证。连接线或bitmap等静态名称只是候选，需确认真实入口再新增范围。

### S04-12 混合工程和统一回归

每完成一类，加到“5既有类+新类”的新建混合工程中；检验源导出是否拒绝未注册类型、地址/图片/语言/扫描索引是否重排、复制/撤销/重开是否保留所有类型。先分离逐类型拒绝，再开放已恢复类型，不用某个原厂模板中的未知对象当通用结构。

AC-S04-MIX：调序、删除、两语言/多状态、引用同资源、混合读写跨度都可判断；新对象不改旧对象字节/语义；C只对声明范围通过，E由阶段10接续。

## 3. 完成声明和下一阶段

每类更新覆盖矩阵对应D/U/P/R/C/T/E及范围，提供原生样例、变更后样例、字段表、联动矩阵、源/设备差分和限制。没有真实结果的AC写“待执行”，不要给新的用例编号借用旧测试数量标通过。

A04逐项对应31份原手册、章节、批次和候选；共26类批次数为3/2/3/2/2/4/1/4/5，无漏项或重复。设备记录恢复与[阶段5](06_阶段5_设备编译与格式差分.md)交错进行，不必先做完26对话框。

## 4. 阶段清理

每控件W切片结束即归档最小证据，删除本切片可再生成的私有副本、重复图、展开像素和缓存，再开始下一控件。保留原始.sm/.ksp、原厂.dat、关键图帧/状态差分和复现配方；不删31手册assets或历史报告。当前文档索引从现有文件直接生成，没有临时大文件，实际清理量见[交付记录](分阶段文档证据/阶段交付与清理记录.json)。


## 5. 2026-11-12用户补充：实物下载闭环

先完成当前C20滚轮，再逐项补验前面阶段尚未实物下载的控件，并同步协议。以后每个控件都增加实物下载，不能仅凭编辑测试或离线编译成功判定可交付。此要求替代原W7“本轮不写屏”的安排；旧记录中的未执行状态仍保留，只有真实新结果才能更新。

每次区分复刻版独立生成、原厂兼容编译和原厂基线三种输入来源；原厂样例下载成功不能替代复刻版编译兼容通过。未恢复编码不得去掉现有拒绝门槛。记录设备身份、源/包哈希、编译器身份、最终应答、提交/重启及错误；USB传输、显示、触控和PLC运行分别判定。准备阶段已只读识别Smart Control Device（7365:616C，libusb0，状态OK），实际写入前重新核验。
