### 1.1 帮助文档中的定义 [H]

- 定义：GIF 显示器（GIF显示器）用于显示 GIF 动画图片。
- 操作：控件栏点图标 → 属性框 → 确定后光标变十字，点击起点拖动确定区域 → 绘制控件；双击控件或点工具栏图标可再弹出属性界面。
- 受位控制语义（帮助正文，设备运行语义 [待验]）：控制位为 LB10、显现状态 1 时——位为 0/OFF 时 GIF 停在静止状态，位为 1/ON 时 GIF 播放动画（assets/23）。
- 权限设置语义：显现＝控制 GIF 显示器显示/隐藏；受位控制（显现状态 1：位 ON 显示、OFF 隐藏；显现状态 0 反之）；受用户等级控制（等级低于有效最低等级隐藏）[H]，设备端效果 [待验]。

## 3. 用户的完整操作路径

### 3.1 新建控件

1. 打开工程和画面。在右侧工具箱点击「GIF显示」图标 [V]。
2. 点击后**立即弹出标题「GIF显示器」的属性对话框**，初始显示“基本”页 [V]。对话框窗口约 850×580（实测 rect 258,74–1108,654，自绘标题栏属于客户区）[V]。默认内容见 [assets/01](GIF显示复刻手册.assets/01-V5.1-基本页默认.png)：选择图片为空（大按钮显示“运行测试”）、受位控制不勾选、控制位 LB0 与有效状态 1 灰显、预览空白。
3. 选择 GIF（见 §6 工程图库流程）、配置控制位与权限页。点击“确定”后对话框关闭，进入画布拖框模式 [V]。
4. **未选 GIF 时“确定”被拒绝**：对话框不关闭并弹出标题 KinSealStudio 的消息框“**没有选择图片或图片已损坏！**”（确定）[V]（assets/18）。
5. 在画布上按住左键拖出矩形，松开完成绘制；控件按拖框尺寸显示 GIF 首帧（等比拉伸铺满矩形）[V]（assets/19，本次拖框 500,300→620,360 得 120×60 对象）。
6. 画布矩形决定控件位置和宽高。

### 3.2 修改现有控件

- 画布上左键**双击**已存在的 GIF 显示器，重新弹出「GIF显示器」对话框并回填：GIF 预览恢复显示、受位控制/控制位/有效状态与权限页各字段按保存值恢复 [V]（assets/20）。
- 画布右键菜单首项“属性”也可打开同一对话框；菜单结构为通用画布菜单：属性／控件(K)▶／剪切 Ctrl+X／复制 Ctrl+C／多重复制／粘贴 Ctrl+V／删除 Del／全选 Ctrl+A／对齐▶／层次▶／组合▶／图像比例▶／网格／模拟状态▶ [V]（assets/21）。

### 3.3 对话框公共部分

窗口标题“GIF显示器”；左上两个页签：**基本／权限设置** [V]；右上独立“预览”框（约 171×200 窗口像素，白色底）实时显示当前 GIF 画面 [V]；右下“确定／取消／帮助”三按钮（内部 `m_okBtn`／`m_cancelBtn`／`m_helpBtn`）[B][V]。

- **确定**：新建时进入画布拖框阶段；编辑时提交修改并关闭。未选 GIF 时被校验拒绝（见 3.1 第 4 条）[V]。
- **取消**：放弃本次改动并关闭 [V]。
- **帮助**：按钮存在 [V]；实测点击后沙盒内无任何窗口弹出（程序含 `loadHelp()` 槽 [B]）；在完整安装环境下是否拉起 CHM [待验]。
- **预览**：无图时空白；加载 GIF 后显示当前帧；“运行测试”播放时动态刷新 [V]。

## 6. 工程图库选图流程（GIF 的唯一选图入口）

点基本页小按钮 `m_pathbtn` → 打开标题“**工程图库**”窗口（约 887×495）[V]：

```text
左侧大图片网格（绿色底，缩略图块）
右侧元数据: 图片名称 / 描述 / 类型 / 尺寸（只读回显）
底部: [添加图片] [删除图片] [批量添加图片]        [确定] [取消]
右上: X 关闭
```

操作序列（实测 [V]，assets/11–13）：

1. 点“**添加图片**”（`pbtn_add`）→ 弹出原生“**选择图片文件**”对话框（#32770，文件名输入＋“打开”）[V]（assets/12）。
2. 选 GIF（测试用 219 字节 24×24 双帧 GIF）：文件进入网格并自动选中，右侧元数据回显——图片名称=**程序生成的 13 位内部名**（如 `m7zvq5ar6f2dn11`）、描述=原文件名、类型=GIF、尺寸=24x24 [V]。
3. 点“**确定**”→ 回到 GIF 显示器对话框，预览显示 GIF 首帧 [V]（assets/14）。取消/X 则不回填。
4. 空库直接确定：不回填（无图时确定仍会被基本页校验拦截）[V]。

约束 [B]（程序字符串，部分经实测印证）：GIF 超过 1M 拒绝添加（`GIF size over 1M, Add failed!`／`GIF size exceeds 1M, unable to add`）；非 GIF 格式拒绝（`The selected image is not in GIF format and cannot be added`）；图片损坏/不存在拒绝。批量添加（`pbtn_addbatch`）支持一次多选（字符串 `Select one or more files to open`）；导出（`pbtn_export`）写 `ProPicLib.klib` [B]，添加图片是否即时落盘未实测（实测添加后未出现该文件，工程保存行为 [待验]）。1M 边界与格式校验的实测触发 [待验]。

## 8. 复刻实现的数据与交互约束

每个 GIF 显示器对象至少应保存：

```text
几何：画面 ID，x，y，width，height，层次
内容：GIF 图片引用（工程图库内部名；描述/类型/尺寸随库）
控制：受位控制开关；控制位地址（默认 LB0）；有效状态 1/0（默认 1）
权限：显现（位控制:地址+显现状态 1/0；等级控制:1–8 默认 1；
      字控制:数据类型+字地址+比较符+比较值[+误差]）
```

关键交互顺序：点工具箱“GIF显示”图标 → 立即弹“GIF显示器”对话框 → 小按钮进工程图库加/选 GIF → 运行测试试播 → 配置受位控制与权限页 → 确定（无图被拒）→ 画布拖框 → 双击重开回填 → 取消丢弃 [V]。必须实现的联动：受位控制勾选启用控制位/拾取/有效状态；权限页“显现”逐级启用三个子组；工程图库确定后预览刷新；运行测试与停止运行按钮文字切换。

## 9. 必须执行的验收矩阵

1. 工具箱“GIF显示”图标 → 立即弹“GIF显示器”对话框；默认值（无图/运行测试/LB0/有效状态 1/权限全关）与本手册一致。
2. 未选图点“确定”→ “没有选择图片或图片已损坏！”且对话框不关闭；未选图点“运行测试”→ “GIF数据为空，请重新选择。”。
3. 工程图库：添加图片→原生选择对话框→元数据回显→确定后预览显示 GIF；取消不回填。
4. 运行测试/停止运行切换与预览动画；受位控制勾选联动；有效状态 1/0；控制位地址输入窗口。
5. 权限页：显现单列；受位控制 1/0；等级 1–8（默认 1）；字控制五数据类型、六比较符。
6. 确定→拖框生成；双击重开回填；取消丢弃；右键菜单全项；状态栏“GIF显示器”类型与坐标。
7. 下载到触摸屏：受位控制 0/1 的静止/动画切换、显现/隐藏、字控制联动。此步验证设备兼容，不可只凭 PC 预览通过。

## 10. 已知缺口，不应擅自补成“已确认”

1. “帮助”按钮在沙盒实测无任何反应；`loadHelp()` 在完整安装环境的行为 [待验]。
2. 受位控制的设备端播放/静止语义仅来自帮助文字 [H]，未做设备对照；“有效状态”与控制位组合的边界（位恰为该状态）[待验]。
