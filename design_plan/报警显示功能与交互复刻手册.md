# KinSealStudio V5.1「报警显示」功能与交互复刻手册

版本：2026-11-09。目标是让另一个会话仅凭本手册实现报警显示（报警显示器）控件的创建、属性窗口（两个页签）、画布编辑、预览和权限体系，以及它依赖的工程级“报警登录”前置配置。本文只描述**金玺 KinSealStudio V5.1**；界面证据来自原生程序的隔离桌面运行和随安装程序提供的中文帮助，未使用本项目的复刻版或“参考程序”作为行为依据。

### 1.1 帮助文档中的定义 [H]

- 定义：报警显示器监视**所有的报警地址**，只要触发报警，产生的报警消息都会在报警显示器中显示（表格形式）。
- 属性分组：标题填充（语言/背景色/文本颜色/字体/大小/消息列名）、边框填充（边框色/背景色）、文本属性（文本色/行数 ≤20/日期显示+列名/时间显示+列名）。
- 操作：控件栏选图标 → 属性框 → 确定 → 十字光标拖矩形绘制；双击控件再次打开属性框。

## 2. 控件家族与入口

右侧工具箱“控件/基本组件”页第 6 行的第三个报警图标 [V]：

| 图标文字 | 内部对象名 [B] | 工具箱矩形（1366×728 桌面实测） [V] |
|---|---|---|
| 报警显示 | `btn_alarmDisplay` | (1233,493)–(1323,523) |

同排还有“动态报警条”（`btn_alarmbar`）与“历史报警显示”（`btn_hisalarmDisplay`）。exe 字符串证据：`QAlarmControlGenDlg`（对话框类）、`createalarmcontroldlg()`、`alarmcontrol.ico`、`AlarmDisplay` [B]。

**重要结构发现 [V]**：报警显示与历史报警显示**共用同一个属性对话框类** `QAlarmControlGenDlg`——两者的“基本设置”页字段名（`lanCombox`、`m_rowspin` 等）、数量、布局完全相同（两份枚举 JSON 逐字段一致），仅窗口标题不同（“报警显示器” vs “历史报警显示器”）。二者的差异在**设备端数据来源**（当前报警 vs 历史报警记录），不在编辑器字段。

## 3. 前置条件：工程必须已有报警登录

与动态报警条相同的实测门槛：空白工程点击工具箱图标会先弹出提示框（动态报警条入口实测：标题“动态报警条”，正文“**位报警和条件报警都不存在**”，仅“确定”，确定后无属性框）[V]；报警显示入口的独立复测未做，推定同一提示（标题应为“报警显示器”）[待验]。配置方法与字段逐项说明见《动态报警条功能与交互复刻手册》§3.1（数位地址报警：类型 连续位/连续字的位/字的值、读取地址、报警条数、表格五列 地址|使用|报警消息|跳转画面|跳回画面、扫描时间、语言选择、触发/清除跳转画面）[V]。帮助的报警登录总述见 `ALarm/AlarmLogin/报警登录.html`：“只有配置了数位地址报警和条件报警，配合报警显示器、历史报警显示器和动态报警条才能正常使用” [H]。

## 4. 用户的完整操作路径

1. （前置）配置报警登录 [V]。
2. 点击工具箱“报警显示”图标 → **立即弹出标题“报警显示器”的属性对话框**，初始“基本设置”页；对话框尺寸约 834×565 [V]（[assets/02](报警显示复刻手册.assets/02-V5.1-基本设置默认.png)）。
3. 配置两页签；右侧“预览”框实时显示表格效果（黄色标题行＋若干行）[V]。
4. 点击“确定”→ 画布十字拖框 → 松开生成控件 [V]（[assets/11](报警显示复刻手册.assets/11-V5.1-画布创建与状态栏.png)）。
5. 画布双击控件重新打开对话框并回填 [V]（实测双击后标题“报警显示器”重新出现）。

## 6. “权限设置”页（SecurityWidget）

与动态报警条完全同构（同一 `SecurityWidget` 页容器）[V]：

```text
[ ] 显现
├─ [ ] 受位控制（地址 LB0＋拾取；显现状态 1/0）
├─ [ ] 受用户等级控制（有效最低等级 1–8，默认 1）
└─ [ ] 字控制（数据类型五项＋LW0＋比较符六项＋比较值＋误差（==/<>））
```

- 显现总开关勾选后三个子复选框可勾选，子字段仍禁用至对应子复选框勾选 [V]（[assets/10](报警显示复刻手册.assets/10-V5.1-显现勾选后字段仍禁用.png)）。
- 有效最低等级下拉 1–8 默认 1；数据类型 16位正整数/32位正整数/16位整数/32位整数/32位浮点数；比较符 <、>、==、<>、<=、>=，默认 <；`==`/`<>` 出现“误差”输入框 [V]（与《动态报警条复刻手册》§6 同一批实测证据）。
- 帮助的权限页定义与示例（受位控制 LB10、等级 4→5、字控制 LW0<5）见 `ALarm/AlarmIndex.files/权限设置.html` [H]。
- 本控件无触控/通知/按压时间字段 [V]。

## 8. 复刻实现的数据与交互约束

```text
几何：画面 ID，x，y，width，height，层次
标题填充：语言索引（默认中文）；标题背景色（默认黄）；标题文字颜色（默认黑）；
          字体（宋体，唯一项）；标题字号（默认 16）；消息列名（默认"消息"）
边框填充：边框色（默认黑）；背景色（默认浅灰）
文本属性：文本色（默认黑）；行数（默认 5，1–20）
日期显示：开关（默认开）；日期列名（默认"日期"）
时间显示：开关（默认开）；时间列名（默认"时间"）
权限（显现）：与动态报警条同构（受位控制/受用户等级控制 1–8 默认1/字控制+误差）
```

关键交互顺序：工具箱图标 → 报警登录门槛检查 → 属性对话框 → 确定 → 拖框 → 双击重开回填；日期显示/时间显示复选框↔列名输入框的启用联动；行数 1–20 边界；颜色按钮共享“选择颜色”窗口。

## 9. 必须执行的验收矩阵

1. 报警登录前置：空白工程被“位报警和条件报警都不存在”拦截；配置数位地址报警后可打开属性框。
2. 标题填充六字段默认值（中文/黄/黑/宋体/16/消息）；语言与字体下拉的实测项数；大小下拉含 12。
3. 五个颜色按钮全部打开共享“选择颜色”窗口。
4. 行数默认 5、上限 20、21 回退行为；消息/日期/时间列名可编辑。
5. 日期显示/时间显示复选框与列名输入框的联动禁用/恢复。
6. 权限设置页与动态报警条一致（等级 1–8、数据类型五项、比较符六项、误差行）。
7. 确定→拖框→状态栏“报警显示器”类型与坐标；双击重开回填；取消丢弃；右键菜单全项。
8. 下载到目标触摸屏：报警消息实时显示、分页/翻页（exe 字符串 "Alarm control up page/down page/move up/move down" [B]）、清除报警、多语言消息。设备语义 [待验]。

## 10. 已知缺口，不应擅自补成“已确认”

1. 报警显示入口的空白工程拦截提示框未独立截图复测（推定与动态报警条一致，标题不同）[待验]。
2. “大小”下拉的完整项列表未滚动展开（实测含 12、16）[待验]。
3. 行数键入 0 导致对话框消失：仅观察到一次，进程是否整体崩溃、是否可复现未确认 [待验]。
4. “确认功能”（报警确认按钮/确认位）在 V5.1 编辑器中**不存在**对应字段（对话框字段已全部枚举）；exe 有 "Confirm alarm"/"Clear alarm" 字符串 [B]，属设备端运行语义 [待验]。
5. “历史查询条件（时间范围/类别过滤）”在 V5.1 编辑器中**不存在**对应字段 [V]（属运行/历史数据检索语义）。
6. 报警类别（数位/条件）在显示器侧没有过滤选项；表格列顺序的设备端实际渲染 [待验]。
7. 多语言工程中“语言”下拉的实际条目、消息多语言列名 [待验]（帮助 [H]）。
