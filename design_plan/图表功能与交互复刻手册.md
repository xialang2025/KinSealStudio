### 1.1 帮助文档中的定义 [H]

- 帮助将本控件称为「图/仪表」（目录页 `Graph/Graph.htm`），V5.1 工具箱图标文字为「图表」，属性窗口标题实测为「**图表**」。
- 三种形态的定义（帮助正文）：
  - **柱状图**（又叫棒图）：把数值的实时变化以柱状增减形式表现，可反映 PLC 数据寄存器数值或工艺流程模拟量的实时变化。
  - **仪表**：以指针位置显示关联变量数值，通常为半圆型或圆形。
  - **圆环**：以圆弧弧度实时显示数值变化，通常为圆环或圆弧。
- 权限页帮助明确：“**图表不可触控所以只有显现权限设置**”——这解释了 V5.1 权限页只有“显现”列、没有“触控有效”列 [H+V]。

## 3. 用户的完整操作路径

### 3.1 新建控件

1. 打开工程和画面，在工具箱点击「图表」图标 `btn_metre` [V]。
2. 弹出「图表」属性对话框，初始停在“基本”页、形态=柱状图（默认内容见 [assets/02](图表复刻手册.assets/02-V5.1-图表对话框默认.png)／[03](图表复刻手册.assets/03-V5.1-柱状图基本页.png)：数据类型 `16位正整数`、监控字地址 `LW0`、显示范围 0~100、源范围 常量 0~100，预览为黄/红双色柱）。
3. 选择形态、配置地址与范围、外形、权限。点击“确定”后对话框关闭，鼠标进入画布拖框模式 [V]。
4. 在画布上按住左键拖出矩形，松开完成绘制；控件立即按当前配置渲染（默认柱状图=上黄下红双色块，见 [assets/24](图表复刻手册.assets/24-V5.1-画布放置与状态栏.png)）[V]。画布矩形决定控件位置和宽高。
5. “帮助”按钮指向安装目录 `KinSealStudio.chm` 的 `Graph/Graph.htm` 页（沙盒内无 CHM 注册，弹出“无法打开文件： mk:@MSITStore:KinSealStudio.chm::/Graph/Graph.htm。”错误框，见 [assets/26](图表复刻手册.assets/26-V5.1-帮助按钮指向Graph页.png)）[V]；“取消”放弃本次创建 [V]。

### 3.2 修改现有控件

- 画布上左键**双击**已存在的图表控件，重新弹出「图表」对话框（实测双击后窗口重新出现 [V]；回填字段值的逐项核对 [待验]）。
- 画布右键菜单首项“属性”也可打开同一对话框（菜单结构与位按钮一致：属性／控件(K)▶／剪切 Ctrl+X／复制 Ctrl+C／多重复制 Ctrl+P／粘贴 Ctrl+V／删除 Del／全选 Ctrl+A／对齐▶／层次▶／组合▶／图像比例▶／网格／模拟状态▶，见 [assets/25](图表复刻手册.assets/25-V5.1-画布右键菜单.png)）[V]。

### 3.3 对话框公共部分

- 窗口标题「图表」；左上三个页签：**基本／外形／权限设置** [V]（内部：`qt_tabwidget_tabbar`，页容器按形态整套切换，见 §4 注）。
- 右侧独立“预览”框（`groupBox_2`＋`MainView` [B]），随形态与字段实时刷新 [V]。
- 右下“确定／取消／帮助”三按钮：`m_okBtn`／`m_cancelBtn`／`m_helpBtn` [B][V]。
- 形态单选（每形态页各自带一份，当前形态单选灰显锁定、其余可选）：`m_CommonButton_2`（柱状图）／`m_MeterButton_2`（仪表）／`m_DonutBtn`（圆环）[B][V]。切换形态即整体切换“基本/外形”页内容；“圆环”形态下**“外形”页签被隐藏**，页签条只剩 基本／权限设置 [V]（对比 [assets/15](图表复刻手册.assets/15-V5.1-圆环基本页.png) 与 [assets/03](图表复刻手册.assets/03-V5.1-柱状图基本页.png) 页签条宽度）。
- 页容器名随形态变化 [B][V]：柱状图=`QChartCommon`＋外形页`QChartCmColor`；仪表=`QChartMeter`＋外形页`QChartMeColor`；圆环=`DonutDlg`（外形页无）；权限页恒为 `SecurityWidget`。

## 12. 复刻实现的数据与交互约束

每个图表对象至少应保存以下独立状态：

```text
几何：画面 ID，x，y，width，height，层次
形态：shape ∈ {柱状图(默认), 仪表, 圆环}

```

关键交互顺序：点工具箱“图表”图标 → 弹「图表」对话框（形态单选锁定当前）→ 基本/外形/权限设置编辑、预览实时更新 → 确定 → 画布拖框 → 双击重开回填 → 取消丢弃 [V]。必须实现的联动规则：

1. 形态单选切换整套“基本/外形”页内容；“圆环”形态隐藏“外形”页签 [V]。
2. 数据类型变更 → 显示范围/源范围自动改为该类型满量程，两极柱复位、中点重算 [V]。
3. 两极柱勾选 → 中点启用并自动填 (min+max)/2 [V]。
4. 源范围 范围类型=地址 → 极值框禁用、地址框+拾取启用 [V]。
5. 圆圆环/圆圆弧互换“属性”组字段（线型/线宽/半径 ↔ 起始角/跨度）[V]。
6. 线型=透明线 → 圆环预览不可见 [V]。
7. 显示次刻度取消 → 次刻度分割数禁用 [V]。
8. 权限页 显现→子复选框→字段 逐级启用；比较符 ==/<> 增删“误差”行 [V]。
9. 确定时显示范围 max<min → 弹「显示范围最大值小于最小值」[V]；源范围极值/两极柱中点的同类校验 [B]（弹窗文案复现 [待验]）。
