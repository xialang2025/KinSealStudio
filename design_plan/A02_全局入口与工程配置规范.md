## 3. 所有配置窗口共用的事务与补证规程

下面P编号是可重复操作的调查规程。各字段行给出需执行的P编号，必须对行中**每个字段**分别执行；未知默认/范围不由开发者自由选值。

| 探针 | 具体动作与输出 |
|---|---|
| P0 身份/默认 | 新建同型号默认工程；进入指定窗口、页签、嵌套框；记录QObject名、类型、标签顺序、value/text、minimum/maximum/singleStep/decimals/maxLength、enabled/visible/checked及初始焦点。帮助缺少配图不能代替这一步 |
| P1 枚举/边界 | 下拉逐项读取itemText/data/顺序；微调输入min−1/min/min+1/max−1/max/max+1及空/负/小数；文本用ASCII/中文/代理对各短串、边界长串；记录编辑中、失焦、确定、重开四个结果与错误原文 |
| P2 联动/草稿 | 每个控制开关OFF→ON→OFF→ON、单选A→B→A；被禁用字段先写唯一标记值，查看hidden/enabled、保留/清空/归一、预览是否即时；对子窗口确定/取消和外层取消分别试 |
| P3 持久化/引用 | 写唯一标记→确定→保存.sm→关闭重开→getter；再复制/改名/删除被引用实体，分别取消与确认；检查名称、稳定ID、索引、关联控件列表与源差分；错误时原文件/原模型不变 |
| P4 源/编译 | 同输入重复保存/编译；仅改单字段，比较typed .sm和所有产物；写映射/活动条件/计数/地址跨度，未知偏移不得填猜测；遵守A05配置默认守卫 |
| P5 运行 | 先取得原生期望，再按指定固件及独立编译工程作相同刺激/观测，记录T/E；本轮不执行、不写屏，只有P0..4不能关闭E |

产品事务要求：打开窗口使用草稿；嵌套地址/色板/图库确定只更新外层草稿；外层确定一次提交并标脏/记历史，取消/ESC/右上关闭按原生证据回滚。若原生某字段取消后保留或缩减即删除，逐项列差异取舍，不用“所有窗口取消都一样”覆盖。工程保存是另一步，配置确定不等于已写磁盘。

所有引用以稳定ID保存，显示名可改；文件/设备索引在导出时派生。被引用节点删除前收集引用：控件、启动/屏保/报警跳页、键盘、宏、采集通道、配方/传输。原生是拦截、确认删除引用、置未使用还是保留坏引用，分别P3核定。取消不能先改控件下拉或回填草稿。
