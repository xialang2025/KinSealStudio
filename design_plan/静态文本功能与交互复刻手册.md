## 2. 用户的完整操作路径

### 2.1 新建控件

1. 打开工程和画面。在右侧“工具栏／基本控件”区域选“静态文本”图标；原生窗口中的对应内部控件名为 `btn_text`。[V] 主窗口布局参见原生画布截图证据说明。
2. 点击图标后，**立即弹出标题为“静态文本”的属性对话框**，初始显示“外观设置”页。[V] 初始内容为 `TEXT`；见 [默认外观](静态文本复刻手册.assets/01-V5.1-外观默认.png)。
3. 在对话框配置文本、外观和权限。点击“确定”后，对话框关闭，鼠标变成十字光标。[H]
4. 在画布上用左键按下起点，保持按下并拖出矩形，松开左键完成控件绘制。[H] 原生已留有画布上选中 `TEXT` 的截图，可见选框和四角/边中控制点。[V]
5. 画布中的矩形决定控件位置、宽、高；设置了“自适应”时，预览中的文字会随该区域宽高缩放。[H][V]

**不要把点击图标后先在画布点一次才弹属性窗口实现成默认流程**；V5.1 实测表明属性窗口在点击图标后已出现。

### 2.2 修改现有控件

- 在画布上对已有静态文本**左键双击**，重新弹出同一“静态文本”对话框，并加载该对象已有值。[H][V] 已用保存过的原生测试工程实测双击；见 [双击重开截图](静态文本复刻手册.assets/02-V5.1-双击重新打开.png)。
- 帮助另称选中控件后点击工具栏对应属性图标也会打开属性窗口。[H] 工具栏图标位置尚未在 V5.1 单独核实。
- 画布右键菜单首项为“属性”，另含“控件”子菜单、剪切 `Ctrl+X`、复制 `Ctrl+C`、多重复制、粘贴 `Ctrl+V`、删除 `Del`、全选 `Ctrl+A`、对齐、层次、组合、图像比例、网格、模拟状态。[V] 见 [右键菜单](静态文本复刻手册.assets/09-V5.1-画布右键菜单.png)。其中“层次”子菜单实际看到“移到最上层／移到上一层／移到最下层／移到下一层”；其他子菜单与静态文本专用性未逐项核实。复刻时应复用编辑器的通用画布操作。
- 原生画布选中后底部状态栏显示控件类型、左坐标、上坐标、宽、高；已有示例截图为 `左 244.0、上 112.0、宽 150.0、高 50.0`。[V] 这些是示例值，不是默认值。

### 2.3 对话框公共部分

窗口标题“静态文本”，左上有“外观设置／权限设置”两个页签，右侧独立“预览”框，右下为“确定／取消／帮助”。切换页签时预览保留。[V] 见 [外观](静态文本复刻手册.assets/01-V5.1-外观默认.png) 和 [权限](静态文本复刻手册.assets/03-V5.1-权限默认.png)。

- **确定**：新建时进入画布拖框阶段；编辑时应提交对当前控件的属性修改。[H] 编辑后实际保存/撤销边界仍需回归验证。
- **取消**：编辑已有静态文本时，勾选“粗体”使预览变化，再按“取消”并双击重开，原来的未勾选状态保留；这是 V5.1 实测。[V] 见 [取消前](静态文本复刻手册.assets/25-V5.1-取消前粗体已勾选.png) 与 [取消后重开](静态文本复刻手册.assets/26-V5.1-取消后重开未勾选.png)。新建流程中按取消是否保留绘制模式仍需核实。
- **帮助**：窗口提供此按钮。[V] 原厂 CHM 有对应“静态文本”帮助页。[H] 点击后是否直达具体页尚未实测。
- **预览**：所有外观示例截图均在编辑值变动时显示对应文字效果；包括斜体、字距、字号、颜色、渐变及自适应。[H] V5.1 默认预览为居中的 `TEXT`。[V] 预览必须使用当前未提交的设置实时更新，不能只在按“确定”后更新。

## 4. “权限设置”页：完整层级和条件

静态文本只显示信息，**没有触摸响应**，所以其对话框只出现“显现”权限，没有其他可触控控件的“触控有效”设置。[H][V] 默认页见 [03](静态文本复刻手册.assets/03-V5.1-权限默认.png)。

界面层级：

```text
显现 [总复选框]
├─ 受位控制 [复选框]
│  ├─ 地址 [文本框，默认 LB0] [地址选择按钮]
│  └─ 显现状态 [单选 1 / 0，默认 1]
├─ 受用户等级控制 [复选框]
│  └─ 有效最低等级 [下拉 1..8，默认 1]
└─ 字控制 [复选框]
   ├─ 数据类型 [下拉，默认 16位正整数]
   ├─ 字地址 [文本框，默认 LW0] [地址选择按钮]
   ├─ 比较运算符 [下拉，默认 <]
   ├─ 比较值 [输入框，默认 0]
   └─ 误差 [输入框，默认 0；仅 == 或 <> 时出现]
```

### 4.1 地址输入按钮

“受位控制”和“字控制”的地址框旁都有小键盘图标按钮。点击后弹出标题“地址输入”的共享窗口，包含存储器下拉、地址种类下拉、输入类型、地址范围、地址数值框、数字/十六进制键盘，以及“清除／后退／离开／输入”。[V] 见 [位地址](静态文本复刻手册.assets/21-V5.1-位地址输入.png) 和 [字地址](静态文本复刻手册.assets/22-V5.1-字地址输入.png)。

在本次测试工程里，位地址默认“内部存储器／LB”，字地址默认“内部存储器／LW”，输入类型为“10进制”，展示范围 `0~4096`；存储器下拉还出现 `COM1`。[V] 见 [存储器下拉](静态文本复刻手册.assets/23-V5.1-存储器选择.png)。外部设备型号及通信配置会改变可用地址家族，不能把这一工程的列表当作所有工程的固定全集。输入按钮的提交/取消细节和地址合法性边界待专项验证。

## 5. 复刻实现的数据与交互约束

另一个会话实现时，建议将每个静态文本对象至少保存以下独立状态，而非只保存画布最终像素：

```text
几何：画面 ID，x，y，width，height，层次
文字：每种工程语言的文本，字体，字距，字号，水平对齐，
      斜体，粗体，自适应，下划线
填充：文字颜色，背景色，前景色，样式索引，透明度
显现：总开关；
      位控制开关、位地址、显示状态 1/0；
      用户等级控制开关、最低等级；
      字控制开关、数据类型、字地址、比较符、比较值、误差值
```

关键交互应按以下顺序实现：点工具箱图标 → 弹属性窗口 → 可切页编辑并实时预览 → 确定 → 画布十字光标拖矩形 → 新对象选中 → 双击或属性命令再次打开并回填 → 修改确定后画布和工程数据更新。自适应勾选时要同步禁用“大小”“对齐”；权限总开关关闭时禁用三个子条件；每个子条件的复选框只控制自己的字段；比较符切换要实时增删“误差”行。勾选状态和输入值应分开存储，便于关掉某条件后再次打开仍能按原生方式回填；这一“关掉后保留旧值”的细节还需原生对照验证。

画布静态文本应作为普通可选对象响应选中、移动、拖动控制点改变矩形、右键通用编辑菜单和层次调整；运行态只显示、不响应触摸。文字是否因裁剪换行、超界溢出、抗锯齿、字体缺失而变化，必须用原生画布预览及目标触摸屏逐一比对，当前证据没有给出确切算法。

## 6. 必须执行的验收矩阵

另一会话完成实现后，至少逐项对照 V5.1：

1. 点击右侧“静态文本”图标即开窗口；“外观设置”默认页、两个页签、右预览、底部三按钮的位置与行为一致；默认值与本手册一致。
2. 输入汉字、英文、数字、空文本、多行文本；切斜体、粗体、下划线及组合；切自适应时字号/对齐变灰并在画布不同宽高下预览。
3. 字体列表跟随系统字体；字距、字号、三种对齐；对话框即时预览；“确定/取消/再次双击”回填一致。
4. 三个色块分别改变；颜色选择窗口的“确定/取消”生效；13 个背景样式、透明度和预览颜色与原生逐像素或容差比对。
5. 显现总开关、位控制 1/0、地址输入、用户等级 1–8、字控制五种数据类型、六种比较符、比较值；`==`/`<>` 显示“误差”，切回关系运算符隐藏。
6. 多个显现条件同时勾选后保存/重开，确认 AND/OR 与优先级；最低等级恰等于阈值时确认显示边界；比较误差公式与字地址数据格式通过模拟器/设备确认。
7. 确定后十字光标拖框，新建及双击编辑；选中控制点、移动/缩放、右键属性、剪切/复制/多重复制/粘贴/删除、层次操作以及工程保存后重开。
8. 将含中文字体及各样式的工程编译下载到目标触摸屏，核查字库、颜色、渐变、透明度和权限动态切换。此步验证设备兼容，不可只凭 PC 预览通过。

## 7. 已知缺口，不应擅自补成“已确认”

1. 透明度、字距、字号和比较值的精确输入上下限、负数/小数/越界处理未证实。
2. 13 种样式的精确像素插值、透明叠加、跨分辨率效果未证实。
3. 多语言文本在工程文件中的保存结构及运行时切换规则未证实。
4. 多个权限条件同时满足/冲突时的逻辑、等级等于阈值时的边界，以及“误差”运算公式未证实。
5. 对话框“取消”在**新建**状态下对绘制模式的处理、“帮助”直达页、“属性”菜单与双击是否完全同一调用链未证实；编辑状态下取消会放弃本次改动，已实测。
6. 地址选择器完整地址家族及其与不同 PLC/芯片型号的联动、32 位字序、浮点字节序未证实。
7. 原生工程和下载文件的序列化格式及目标屏固件的静态文本解析规则不在本次 UI 调查证据内；实现设备兼容需要另做文件/固件比对。

上述缺口保留在手册中，是为了避免下一会话把帮助中的旧截图或界面名称误当成运行算法。已确认的**可见字段、选项和主要操作路径**均在前文逐项列出。
