## 2. 运行契约字段

下表为必须形成的规格字段，默认、单位和时序未核前不得填推测值。建议运行状态保存在独立session，不回写编辑工程；是否与原生一致须S07-01实测，差异记账。

| 字段ID | 必须保存/解释的含义 | 验证方式 |
|---|---|---|
| S07.session.identity | 工程/程序/模型版本、型号、分辨率、启动画面/语言 | 启动前manifest与首帧匹配 |
| S07.session.addressStore | LB/LW及外部影子值、字位别名、16/32位/BCD/浮点、边界 | 相邻/跨字读写互证；字序待实证 |
| S07.session.events | press/move/release/cancel、持续按压、键盘输入、窗口开关 | 事件顺序记录及原生对照 |
| S07.session.scheduler | 扫描、闪烁、采集、报警、宏调度适用范围 | 分时钟域记录；未支持宏不偷偷执行 |
| S07.session.transport | offline内存/online连接、连接ID、待写队列/故障状态 | 离线无物理I/O；在线受控端点日志 |
| S07.session.lifecycle | 未保存提示、重复启动、暂停/退出、父窗关闭、异常退出 | 工程字节/dirty状态、句柄/进程清理 |
| S07.session.limit | 原生时限/支持协议/不支持功能、产品采用值 | 当前版本后台观察，不按旧帮助硬编码 |

## 3. 顺序任务

### S07-01 · 恢复启动与退出协议

1. 后台私有桌面用同一原生受支持工程测试三个入口，记录菜单/工具栏/快捷键、enabled条件、保存提示、取消、保存失败、进程命令行、工作目录、读写文件、帮助页和退出行为。
2. 首个样本只用内部LB/LW，离线启动必须不接硬件。在线窗口先调查到配置就停止，不与生产端口连接。
3. 记录画面编号、窗口层次、当前编辑语言与启动语言差别；关闭后原工程是否被改写，保留前后SHA256。
4. 重复启动/关闭父进程/子进程崩溃分别检查。原生30分钟限制如需核验，在私有桌面无人值守记录启动/退出单调时间与原因；不抢焦点，不靠长阻塞等待，未知时标待验。
5. 形成命令行/文件契约与窗口字段字典；不能据文件名猜IPC格式。输入格式未恢复时阻塞直接启动相应模拟器，但可实施独立受限模型模拟。

### S07-02 · 内部地址和事件执行器

1. 从[位按钮手册](位按钮功能与交互复刻手册.md)、[字按钮手册](字按钮功能与交互复刻手册.md)、[指示灯手册](指示灯功能与交互复刻手册.md)整理最小动作：置位/复位/交替/点动、字赋值/运算、监视/权限与通知；已知时序未现场证实的仍保留设备E未知。
2. 建独立address store，区分地址空间、连接、节点/站号、位/字/双字。复用[plc_address](../src/plc_address.h)解析，不能依字符串相似合并地址。
3. 纯内存执行写入→相关监视变更→渲染失效；读取旧值的运算与纯写动作分开。多控件依赖同地址应同一快照解释。
4. press/release包括移出/失去捕获/窗口关闭；点动不能因缺release永久置位，采用规则必须有原生观察或明确差异。按压阈值/权限/通知先后由专题补证，不能自行定帧率推导。
5. 运行时拒绝未支持对象/配置并列名；不能将未实现控件显示成静态图后声称可模拟。

### S07-03 · 复用渲染与窗口模型

1. 将静态图、动态状态图、语言和字体引用走同一资源解析入口；复用[static_text_renderer.cpp](../src/static_text_renderer.cpp)、[bit_button_renderer.cpp](../src/bit_button_renderer.cpp)作为当前已实现基础。
2. 按阶段3规则处理层次/透明、裁剪和命中；奇数宽RGB565仅用于设备图像，对PC QImage内存步长另作处理，不互相套用。
3. 画面跳转、弹出窗口、键盘窗口、关闭时触点、权限隐藏后的重绘分别测试。不依赖尚未实现的多画面时，只声明单画面子集。
4. 首帧/状态帧与原生截图、解压设备图分层比较：字体环境造成差异单列；不能把PC渲染近似当E正确。

### S07-04 · 配置型功能与离线限制

依次接入已恢复配置的采集→报警→历史→配方→资料传输，每项要有地址输入、触发、时序、状态、持久化边界和失败。未完成前在能力表禁用该项，不默认原生全支持。系统时钟使用可控制测试时钟，真实时钟行为再核。

宏按帮助明确“离线不支持”处理：兼容模式不执行宏，必要提示的位置/内容需原生核验。未来若提供宏模拟，列独立产品扩展，不混进原生一致性结果。初始化/全局宏也不凭名称豁免此限制。

### S07-05 · 在线传输与断线恢复

1. 先由阶段9提供默认Modbus RTU的PC传输接口、端点身份及响应规范，模拟器只负责runtime事件与地址映射。
2. 用受控模拟从站离线回放/本地测试，确认读扫描/写队列、超时、异常响应、重连、写失败后的显示与通知；不连用户现用PLC。
3. 确定哪些配置影响模拟器而非HMI固件，如PC端口与HMI COM1映射；原生在线配置窗口必须另核，不能把设备站号和PC端口号混合。
4. 在线退出/取消清空未发送队列并释放端口；已发送写的远端状态不能承诺回滚。排队/重试/合并策略作为设计选择，未经实测不得标“与原生一致”。
5. 缺授权端点时只关闭D和无I/O部分；实际T/E留待阶段10。

### S07-06 · 收口

用例按SIM组逐项执行，交付`S07-capabilities`，行键为“功能×offline/online×模型范围”。每行包含D/U/P/R、PC传输状态与HMI E边界。离线运行没有设备传输则T=N/A（明确无物理I/O）；在线PC通信成功不能关闭HMI固件E。
