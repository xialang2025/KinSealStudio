### 1.1 帮助文档中的定义 [H]

- 定义：多态按钮的功能和多态指示灯基本相同，唯一不同的是多态按钮**可以输入数值**，而不是单纯的指示功能。
- 数据类型：包含 **16位正整数、32位正整数**，是写入地址和监控地址的数据类型。
- 监控地址：监视的数据所存储的寄存器地址；“写入地址和监控地址相同”即两者为同一地址；写入地址是数值写入地址。
- 总状态数：显示的状态数目，**最多可设置 32 个状态（即状态 0–31）**；例如监控地址数值为 2 时按钮显示对应状态图片。
- 功能键（六种触摸语义，设备端行为仅来自帮助文字，[待验]）：
- **键盘输入**：触摸该按钮时弹出键盘，用户输入想要显示的状态（[assets/42](多态按钮复刻手册.assets/42-帮助-键盘输入语义.png)）。
- **递增**：每触摸一次状态加 1，到达设置的状态数最大值后不再增加（[assets/43](多态按钮复刻手册.assets/43-帮助-递增语义.png)）。
- **递减**：每触摸一次状态减 1，到达状态 0 后不再减少（[assets/44](多态按钮复刻手册.assets/44-帮助-递减语义.png)）。
- **递增（绕回）**：加 1，达到最大值后绕回状态 0（[assets/45](多态按钮复刻手册.assets/45-帮助-递增绕回语义.png)）。
- **递减（绕回）**：减 1，到状态 0 后绕回设置的最大状态继续递减（[assets/46](多态按钮复刻手册.assets/46-帮助-递减绕回语义.png)）。
- **保持**：固定为当前状态（[assets/47](多态按钮复刻手册.assets/47-帮助-保持语义.png)）。

## 2. 控件家族与入口

多态按钮属于“开关”家族。工具箱（右侧“工具栏／控件”面板，[assets/30](多态按钮复刻手册.assets/30-V5.1-画布创建与状态栏.png) 右侧）前两行提供 6 个图标 [V]：

| 图标文字 | 内部对象名 [B] |
|---|---|
| 位按钮 | `btn_switch_bit` |
| 字按钮 | `btn_switch_word` |
| 指示灯 | `btn_switch_Lamp` |
| 功能按钮 | `btn_switch_Fun` |
| 画面按钮 | `btn_switch_Screen` |
| 多态按钮 | `btn_switch_MultiState`（单选组里为 `radio_Mstate`；帮助旧目录亦称 `btn_switch_Mstate`） |

**六个入口共享同一个属性对话框**（内部类 `SwitchDlg`，字符串表中窗口标题还有 "Bit Button"/"Word Button"/"Screen Button"/"Function Button"/"Poly Button"/"Poly Lamp"/"Bit Lamp" [B]），只是打开时锁定的类型不同、窗口标题不同：从“多态按钮”图标打开的窗口标题为**“多态按钮”** [V]。“通用设置”页顶部有 6 个单选（位按钮/字按钮/画面按钮/功能按钮/多态按钮/指示灯），从“多态按钮”入口打开时“多态按钮”单选呈选中且灰显（锁定），点击其他单选不会切换类型 [V]。

多态按钮与位按钮家族的差异总览 [V]：

1. “通用设置”页不复用 `BitWidget`（位地址/操作类型那套隐藏不显示），换成了专用容器 `QMStateBtn`：数据类别、监视地址、写入地址、总状态数、功能单选组。
2. “指示灯设置”页是**空页**（见 §5）。
3. “权限设置”页的“通知”子项**可勾选展开**且**通知位/通知字互斥**（位按钮中两者保持禁用，见姊妹手册）。
4. “外观设置”页结构与位按钮一致，但状态数随“总状态数”可扩到 2–32 个。

## 3. 用户的完整操作路径

### 3.1 新建控件

1. 打开工程和画面。在右侧工具箱点击“多态按钮”图标 [V]。
2. 点击后**立即弹出标题“多态按钮”的属性对话框**，初始显示“通用设置”页；窗口为 QWidget，尺寸约 836×616（含自绘标题栏）[V]。默认内容见 [assets/01](多态按钮复刻手册.assets/01-V5.1-通用设置默认.png)：数据类别 `16位正整数`、监视地址 `LW0`、“写入地址和监视地址相同”不勾选、写入地址 `LW0`、总状态数 `3`、功能 `键盘输入`；预览为 OFF 灰色金属边方块。
3. 配置数据、功能、宏指令与四个页签。点击“确定”后对话框关闭，鼠标进入画布拖框模式 [V]。
4. 在画布上按住左键拖出矩形，松开完成控件绘制；控件默认显示状态 0（OFF）外观并处于选中态（8 个控制点）[V]（[assets/30](多态按钮复刻手册.assets/30-V5.1-画布创建与状态栏.png)）。
5. 画布矩形决定控件位置和宽高。

### 3.2 修改现有控件

- 画布上左键**双击**已存在的多态按钮，重新弹出“多态按钮”对话框并**回填已有值**（实测：以总状态数 8 创建 → 确定 → 拖框 → 双击后总状态数回填 8）[V]（[assets/32](多态按钮复刻手册.assets/32-V5.1-双击重开回填.png)）。
- “取消”丢弃本次改动：双击打开（回填 8）→ 把总状态数改为 5 → “取消” → 再次双击，总状态数仍为 8 [V]（[assets/34](多态按钮复刻手册.assets/34-V5.1-取消丢弃后重开.png)）。
- 画布右键菜单首项“属性”也可打开同一对话框；菜单结构与位按钮一致：属性／控件(K)▶／剪切(T) Ctrl+X／复制(C) Ctrl+C／多重复制(D) Ctrl+P／粘贴(P) Ctrl+V／删除(D) Del／全选(A) Ctrl+A／对齐▶／层次▶／组合▶／图像比例▶／网格／模拟状态▶ [V]（[assets/31](多态按钮复刻手册.assets/31-V5.1-画布右键菜单.png)）。

### 3.3 对话框公共部分

窗口标题“多态按钮”；左上四个页签：**通用设置／指示灯设置／外观设置／权限设置** [V]；右侧独立“预览”框（白色底，实时显示当前“选择状态”的按钮外观）[V]；右下“确定／取消／帮助”三按钮（容器 `buttonBox`，三按钮窗口矩形 x 分别为 747/828/909，y 621–644 [B][V]）。

- **确定**：新建时进入画布拖框阶段；编辑时提交修改并关闭 [V]。
- **取消**：编辑状态下放弃本次改动（见 3.2）[V]。
- **帮助**：按钮存在 [V]；原厂 CHM 有对应页面（`Switch/多态按钮.html`）[H]；点击后是否直达该页未实测 [待验]。
- **预览**：显示当前“选择状态”的外观：状态 0 为灰色金属边 OFF 方块（文字 OFF）；状态 ≥1 为橙色方块（switch_ON.kvg），状态文字非空时叠加显示 [V]（[assets/15](多态按钮复刻手册.assets/15-V5.1-状态31内容.png)、[assets/13](多态按钮复刻手册.assets/13-V5.1-状态1默认ON.png)）。

### 4.1 按钮类型单选组 [V]

多态按钮锁定选中（灰显）；其余 5 个可选但点击无效。内部对象名：`radio_bit`／`radio_word`／`radio_scene`／`radio_function`／`radio_Mstate`／`radio_indicator`，容器 `RedioGroup`/`buttonGroup` [B]。复刻时：从哪个工具箱图标进入，就锁定对应单选，并以此决定各页签内容（多态按钮用 `QMStateBtn` 替换位按钮的 `BitWidget`，清空 `Monitorwidget` 页）。

## 5. “指示灯设置”页（Monitorwidget）：空页

多态按钮对话框中该页容器 `Monitorwidget` **没有任何子控件**，整页空白 [V]（[assets/02](多态按钮复刻手册.assets/02-V5.1-指示灯设置空页.png)）。这是与位按钮最大的页签差异之一：多态按钮本身即按监控地址值多态显示，无需再配双态监视。

注意 [B]：exe 字符串中 `Monitorwidget` 类还带 `spin_statusCount`、`on_spin_statusCount_valueChanged(int)`、`btn_customValue`、`combo_condition`、"Monitoring address" 等对象——这些属于**多态指示灯**（Poly Lamp）对话框的指示灯设置页；在多态**按钮**对话框中不可见。复刻多态按钮时不要把这些字段放进本页。

## 9. 复刻实现的数据与交互约束

每个多态按钮对象至少应保存以下独立状态：

```text
几何：画面 ID，x，y，width，height，层次
通用：按钮类型（多态按钮锁定）；
      数据类别（16位正整数/32位正整数，默认16位正整数）；
      监视地址（默认 LW0）；写入地址（默认 LW0）；
      写入地址和监视地址相同（默认否）；
      总状态数 N（2..32，默认 3）；
      功能（键盘输入/递增/递减/递增绕回/递减绕回/保持，默认键盘输入）；
      宏指令开关；宏索引
指示灯设置：无（空页，不保存）
外观（状态 0..N-1 各一份）：
      文本（状态0默认OFF、状态1默认ON、≥2默认空）；字体；大小；对齐；
      粗体/斜体/下划线；文本色；文本闪烁；语言；
      图库路径（状态0 switch_OFF.kvg、≥1 switch_ON.kvg）；
      终端3D按钮效果；使用透明效果；背景色（默认白）；透明度（默认255）
权限：显现（位控制:地址+显现状态1/0；等级控制:1–8 默认1；
       字控制:数据类型+字地址+比较符+比较值+误差）；
      触控有效（同构三条件，等级默认2，标签"有效状态"）；
      通知（通知位 XOR 通知字：位→地址+状态1/0；字→地址+数据类型+设置值）；
      按压时间:开关+数值(默认255, x100毫秒)
```

关键交互顺序：点工具箱“多态按钮”图标 → 弹“多态按钮”对话框（类型单选锁定）→ 四页签编辑、预览实时更新 → 确定 → 画布拖框 → 双击重开回填 → 修改确定更新画布与工程数据；取消丢弃本次修改 [V]。必须实现的联动规则：

1. **总状态数 → 选择状态范围**：外观页“选择状态”上限恒为 总状态数-1；总状态数缩小把当前选择状态钳回新上限（31→2、9→7 实测）。
2. **状态切换 → 整页刷新**：文本区/图库路径/复制按钮标签/预览随“选择状态”联动；复制按钮在状态 0 与状态 ≥1 间翻转（“从1状态…”↔“从0状态…”）。
3. **写入地址和监视地址相同**：勾选时写入地址镜像监视地址并禁用；取消时保留镜像值并恢复编辑。
4. **不使用图片** → 图库路径禁用、预览平面化。
5. **权限页逐级启用**：显现/触控有效 → 三个子复选框 → 各字段；比较符 `==`/`<>` 增删“误差”行；“按压时间”增删数值行。
6. **通知位/通知字互斥**：勾一个自动取消另一个，并各自展开对应字段组。
